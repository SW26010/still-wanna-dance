## 失败及修正

- [main check #64](https://github.com/SW26010/still-wanna-dance/actions/runs/42395979511)的真实双页面设置检查查找旧文案“最佳约命中 65% 的歌曲请求”。本机六项联调复现相同失败，页面快照实际为“预计请求命中率：约 65%”；仅同步 `settings-live.mjs` 的定位器后六项通过。双页面部分更新、持久化、重启和过期目录策略确认断言保持不变。
- 完整浏览器首轮的 ownership 用例仍期待“请求失败 · HTTP 502”，实际页面已经使用“处理异常 · HTTP 502”；favorite-retention 用例查找设置整理时已移除的解释文案。分别更新现行摘要定位器、检查仍保留的收藏控件可见；保留收藏保存、放弃、重载、active/saved 区分、不自动下载，以及错误摘要和所属页面导航检查。两文件共 11 项定向检查通过。修正集中于 [PR #48](https://github.com/SW26010/still-wanna-dance/pull/48)，在 [check #65](https://github.com/SW26010/still-wanna-dance/actions/runs/42397216887)和仓库产物检查通过后合并为 `c00d7082370c71bc670109e6289331f4a4b159ea`。冻结审计确认仅三个测试文件改变，不修改业务实现、界面产物或依赖。
- 最初 Python 检查误用默认沙箱临时目录，目录操作被拒绝；失败日志 `python-evidence.log` 保留。改经仓库规定的临时目录包装器和 D 盘隔离环境后，原测试 2/2 通过，未修改 Python 产品或测试实现。
- 初始本地克隆在沙箱内被 Git/MSYS 命名对象权限拒绝，未创建有效检出；普通用户环境以绝对本地路径完成两个独立克隆。
