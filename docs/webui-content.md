# WebUI 内容分类

## 程序与界面术语

用户文案和技术文档统一使用「程序／SWD」指后台运行的整个应用，使用「WebUI」指浏览器中的操作界面。启动程序、打开 WebUI 和开启视频加速是三个不同动作。关闭网页不会等同于退出程序；打开或刷新网页不会重新触发启动时的自动加速。条款未确认时关闭页面的退出规则仍以[配置生命周期](settings-lifecycle.md)和[使用说明](console.md)为准。

「终端」「命令行」只用于实际的命令行操作、参数及独立命令行服务；只有明确指 Windows console 窗口时才称「控制台窗口」。产品界面不再用泛指的「控制台」。内部 `console` 包、类型、命令入口、协议标识、日志事件及历史文件名保持不变；历史报告保留当时文案。

| 场景 | 统一文案及含义 |
| --- | --- |
| 托盘打开入口 | 打开 WebUI |
| 常规设置分组 | 程序启动 |
| 启动选项 | 启动程序时自动打开 WebUI／启动程序时自动开启视频加速 |
| 网页首次读取状态 | 后台程序：连接中；正文首次读取显示「正在读取程序状态…」 |
| 状态读取成功 | 后台程序：已连接；只表示网页最近成功读取后台状态，不表示游戏已接入、加速已开启或播放成功 |
| 退出或重启后停止读取状态 | 后台程序：未连接；使用中性色，不另设退出／重启中的状态文案 |
| 状态读取失败 | 没有已有状态时显示「后台程序：读取失败」；已有状态时显示「后台程序：更新失败」。详情提示无法读取程序状态并说明保留上次状态；不据此断言程序已退出 |
| 游戏连接就绪 | 游戏连接：已接入；表示连接配置就绪，游戏请求与播放结果另行展示 |
| 视频服务运行 | 视频服务：运行中；表示本地服务正在运行 |
| 房间队列运行 | 房间队列：监控中；表示队列监控已运行，等待同步／准备歌曲仍单独说明 |
| 引导或文档返回主页 | 返回首页 |
| 主导航的无障碍名称 | 页面导航；展开／收起按钮使用同一名称 |

四项状态共用 Fluent Badge 的尺寸、图标和颜色规则：绿色正常、红色故障、黄色待处理、主题色处理中、中性灰未启用或待确认；文案与图标始终可见。状态接口读取失败或程序正在退出／重启时，游戏连接、视频服务和房间队列显示“待确认”，不继续用绿色标记旧快照。操作失败由操作反馈报告，不改变仍然正常的后台连接状态；后台存储故障和读取失败保留详情入口。

页头只展示后台程序状态，与“退出程序”相邻排列；加速总状态、游戏连接、视频服务和房间队列集中在首页“加速”。历史、曲库、网络、设置和关于的标题旁不重复展示加速状态。“退出程序”点击即提交退出，不再二次确认；停止服务和游戏接入处理说明由 Fluent Tooltip 在悬停或键盘聚焦时显示。

## 内容与交互

功能页面和文档统一从左侧导航访问。`207e431` 为历史迁移文案基准，现行体验修订见下文；存储术语按 2026-10-19 确认的[术语与命名](download-resource-design.md#术语与命名)统一；组件迁移本身不改变内容，2026-10-21 已授权的体验修订统一调整文案和层级。组件选择和业务保留边界见 [Fluent UI](fluent-ui-migration.md)。

侧栏提供加速、历史、曲库、网络、设置、关于六个入口。默认打开加速；首次条款门禁进入引导，之后从帮助主动重进，手动引导进度不改变日常启动落点。功能页面与文档共用 Hash 路由和持续挂载的应用外壳；侧栏、页脚及文档内的站内链接使用同一地址规则，往返文档保留表单草稿和选择。文档正文直接使用启动数据，不等待状态接口；帮助中的本地存储目录以当前生效配置为准。原 `/help`、`/about`、`/terms` 可直接打开，已同意时在当前文档内规范为对应的 `/#/…` 地址，不增加重定向请求；未同意时帮助、关于仍独立可读，条款入口继续打开确认流程。导航使用 Fluent NavDrawer/NavItem/Hamburger，桌面默认展开、可收起，窄屏保持抽屉交互。

设置和引导先问“是否保留下载的视频”，共用“不保留 / 限制为 / 不限制”单选（默认“不保留”）与“视频存储预算（GiB）”。不保留时直接说明适合边播边下载、普通视频不长期保存，开启收藏保留时完整收藏视频仍可保存，房间队列准备不受影响；实际占用超预算的补充说明使用 Tooltip。位置设置统一称“本地存储目录”，完整视频在“曲库 → 按资源”管理，队列提前准备称“房间队列预加载”。请求 HIT 展示为“本地视频命中”，仅表示完整本地视频命中，不将运行期块复用混入该统计。

“激进的缓存回收策略”仅在设置的存储标签提供“自动（默认）／开启／关闭”单选，简短说明减少占用与重复下载的取舍。自动状态同时展示当前结果，随“不保留／限制为／不限制”草稿更新；手动选择保留。补充说明关闭后仍受视频存储预算约束，“不保留”下普通资源仅复用本次运行内的视频块缓存，开启收藏保留时预算例外仍有效。使用引导不展示该选项及说明，新配置沿用默认 auto；重新引导、切换预算和恢复本页默认均保留已保存策略。最终核对仅在该策略存在此前已保存、尚未生效的更改时展示差异。

两个入口均先展示视频存储预算，再直接展示本地存储目录。选择“不保留”时禁用路径、目录选择及默认位置操作，目录检查和错误反馈仍可用；选择保留模式后恢复编辑。切换仅改变编辑状态，保留路径及自定义选择，不重置或搬迁数据。回收策略和延续保护时长直接可见，不再放入高级折叠。

曲库和历史以紧凑 Table 每例一行展示，主次文字复用 TableCellLayout；补充资料通过非模态 Popover 查看，短说明使用 Tooltip。曲库概览只展示占用、覆盖率与预算；导入视频、VRCX 历史及按 ID 标记通过明确按钮进入任务区域。

“曲库 → 按歌曲”使用标准选择控件设置普通、收藏、屏蔽；支持本地查找、筛选及按 ID 标记。收藏标记与完整文件存在状态分开展示，明确标记不开始下载；屏蔽只影响新请求和新准备。零预算下保留手动补齐入口，预算提示按收藏保留设置说明实际资格。详情中的共享资源和临时块说明遵循[业务设计](download-resource-design.md#8-歌曲屏蔽与收藏)，不在需求或块调度界面新增偏好操作。

存储设置在回收策略旁提供“本地延续保护时长（秒）”，使用标准数值输入，默认 300，范围 0～10000 的整数。说明最后一份需求结束后的保留用途、0 表示不延续保护，以及较长时长可能增加空间占用。使用引导保留该设置，最终核对显示此前保存但尚未生效的差异；运行语义以[本地保护](download-resource-design.md#本地保护)为准。

| 页面 | 内容 |
| --- | --- |
| 加速 | 加速总状态、一键启用入口、是否收到游戏请求、最近已结束请求结果、异常与检查连接入口；当前 GET、下载速度与进度、实际房间队列、按需块需求时间轴 |
| 历史 | 最近 72 小时的首正文分组分位数与样本数；GET 请求的时间范围查询、游标分页、处理时身份、结果及有效响应交付比例 |
| 曲库 | 曲库清单更新和实际文件占用；歌曲／资源标准标签、搜索排序筛选、有界分页；收藏屏蔽、共享文件删除／定位、单项下载、全库补齐、视频和 VRCX 历史导入 |
| 网络 | 当前连接与线路观测、连通性检测、测速、接入诊断和修复；通过链接返回网络设置 |
| 设置 | 常规、存储、预加载与下载、网络四个标准标签；各字段唯一编辑位置，保留代理、回源线路与测速间隔等配置 |
| 关于 | 介绍、使用帮助、用户协议、许可证与声明四个标准标签；保留版本、路径、常见问题与重新进入引导。许可原文可离线查看／保存 |
| 使用引导 | 开始 → 存储 → 网络 → 启用；独立草稿、明确同意、手动检测；后端核对重启和自动启动动作后再确认，完成时读取实际运行状态反馈 |

侧栏名称与页面主标题一致。取消独立运行状态页，其内容分别归属下载和网络；旧监控地址进入网络页，明确的下载／队列／参数锚点进入对应任务页并展开目标。完整操作只出现在所属页面，其他入口以摘要和链接连接。同一份存储、下载、网络字段仍由共用组件渲染，使用引导保留独立草稿。

各配置位置只保存本处草稿，将其合并到最新已保存配置，不提交其他位置的草稿。所有位置等待保存后的新状态再解锁；任何位置尚有草稿时禁用重启，提示先保存或放弃。退出策略保存即用于本次退出；其他运行配置保持重启生效，启动配置生效规则见配置生命周期。

首页的游戏请求提示按检测阶段区分尚未检测、准备中、等待请求、已收到、检测停止与启动失败。自动与手动一键加速共用请求检测窗口，hosts 与网关均就绪后才开始等待请求；后台独立启动网关不创建检测窗口。历史请求结果单独呈现。首页提供到高级接入的诊断和重新检测入口，统一调用一键加速。高级接入、引导、帮助及条款均不提供独立网关启停、队列启停或 hosts 恢复操作；退出恢复是配置，结束运行使用退出程序。

技术数据在紧凑表格中扫读，补充明细通过标准 Popover 查看，不改变下载、检测、存储或保护规则。当前文件摘要独立于搜索/分页；请求次数不等于播放次数，历史按独立请求展示，交付比例不代表播放进度；网络成功样本不保证每首歌曲可播放。只保留帮助判断的短说明；永久删除等重要后果在操作确认时明确展示。

页面标题下不复述导航或功能清单。读取状态在所属区域显示一次；测速未开始时不叠加空样本提示，无历史批量任务时不显示空详情入口。设置操作区使用简短的未保存／同步中／待重启／已生效状态，重启中断等后果由原确认流程说明。曲库文件操作完成且无异常时使用 Toast；有跳过或失败项时，在列表前显示唯一的 MessageBar 与结果表，并将焦点移到结果区，保留原因供核对。

块需求时间轴默认收起，只保留这一层按需展示。展开且处于可见页面、可见视野时订阅 SSE；收起、切页、标签隐藏、整个面板滚出视野或勾选暂停展示后断开订阅并停止动画。恢复时重新取得完整状态。主时间轴画布单独滚出视野、下方需求视图仍可见时，停止主画布动画及事件重绘，保留共用 SSE 更新需求视图；滚回后按最新状态和时间恢复绘制。现有下载与请求列表仍按原间隔刷新，时间轴不采样这些接口。

保持展开期间，暂时不可见、暂停展示或连接中断只隐藏固定详情并释放详情订阅，保留固定选择；恢复连接并收到完整状态、确认块仍存在后再显示详情。暂停及其他工具栏操作不取消固定，关闭按钮和 Escape 仍可主动关闭。仅悬浮的详情不自动恢复。块退出最新状态、主动关闭详情或收起时间轴会清除选择；不会为最新状态中已移除的块重新请求详情。保留选择不延长核心观测、文件保护或历史记录的生命周期。

有期限的块按 need-by 映射到连续时间轴，允许覆盖；现在指针在跟随模式默认居中，左右分别标示下载延续和提前窗口。块始终是正方形，边长可调为 4–36 px；缩小块或放大时间轴可减少覆盖，时间完全相同的块仍保持真实位置，通过浮层切换，不为防重叠挪动时间坐标。重叠时，定位时间较小的块在上层；相同时按块标识保持稳定顺序，选中不改变层叠顺序。可切换单层或三层，上到下为未安排、下载中（含正在结束）、本地／已完成，层名称背景透明；无期限区域也沿用这一分层，不制造时间值。

同一歌曲使用稳定配色，没有歌曲标识时按视频资源标识配色。视频仍在视图中时沿用首次分配的颜色，需求来源变化、歌曲标识补齐或断线重连不重新配色。颜色表示视频归属，状态使用空心、斜纹、实心；每块带略深于主色的细描边，区分同色重叠边界，不使用模糊阴影。需求结束后的本地延续保护保留视频配色，以 35% 不透明度绘制填充和边框，取代早期灰色表示。选中轮廓与读取急需标记保持清晰，读取急需另加边框与圆点。时间窗口颜色带只是参照，真正下载资格在属性中说明；本地可用不等于完整视频已校验发布。详情同时显示视频标题（无标题时歌曲／资源标识）及视频内编号 `13/45`，表示从 1 开始的第 13 块、完整视频共 45 块；总数未知时显示 `13/?`。时间轴选中标注和键盘选择使用同一编号，底层块索引和字节范围仍从 0 开始。

时间轴下方是需求视图，每个矩形对应一个来源对一个视频的需求；按 GET、短期交接、队列位置 #1/#2…、手动下载排列。同一歌曲的矩形边框同色，交接矩形外框固定白色，内部块及时间轴继续保留视频原色（forced-colors 仍由系统颜色优先）。交接标题复用观测期间已有的歌曲信息，首次打开时可从本地歌曲资料补齐。内部以完整视频总块数建立等距位置，方块放在其原始块号对应的位置，无需求的前缀、中间区间和尾部留空；需求撤销不让剩余块左移。同一视频的不同需求行共用相同位置规则。方块保持所选大小，位置随矩形宽度缩放，首尾方块保留内边距且完整可见，不设行内横向滑条；块间距不足时允许重叠，视频内位置较早的块在上层，选中不改变层叠顺序。总块数未知时暂按该行观测到的最大块号缩放，仍明确标注总数未知，待总数补齐后更新位置。悬浮或键盘查看同一套详情，空档不产生详情请求；重叠处先命中上层块，并可通过共用浮层切换被覆盖的块。相同块可以出现在多项需求中，容量仍按唯一块计算。只为可见需求行绘制 Canvas，复用时间轴 SSE 和单一选中块详情订阅；不为每行或每块建立订阅。

需求行的测量与绘制在浏览器显示前完成，标题、外框和块同时按实际宽度出现；列表缩短时同步修正滚动范围，避免先显示空白再补齐。列表与画布尺寸不做过渡，减少动态效果模式也遵守同一规则。需求内容仍随事件及时更新，不延迟真实的新增、撤销或状态变化。获得键盘焦点的需求行被移除、焦点落到 body 时，将焦点恢复到需求视图区域；下一次 Tab 可继续进入剩余行，不抢走区域外控件的焦点。

纵向滚轮围绕视图中心缩放时间范围，保持原有跟随／固定状态；按钮与键盘加减缩放采用相同规则。横向滚轮（或 Shift + 滚轮）左右平移，不改变时间缩放或跟随／固定状态；跟随时保留相对现在的时间偏移，时间继续移动。按住拖动或横向滑条浏览时切为固定，“回到现在”恢复跟随并清除偏移、重新居中。悬浮查看属性及当前来源，点击固定详情；被覆盖的块通过浮层切换按钮逐个选择。两个视图的未固定详情均随鼠标进入、退出重叠区同步完整命中集合，默认选择最上层块；集合不变时保持浮层稳定，已固定的详情不随悬浮移动改变。所选块上方显示时间性质与对应时间；need-by、下载截止、本地保护、读取者和来源详情保留准确语义。保护期块的历史定位规则以[按需块观测](block-scheduler-design.md#按需块观测2026-10-20)为准。

本地存储故障通过 WebUI 公共后台状态及详情显示，切页仍保留首个原因、影响和恢复步骤；生命周期以[配置与运行约定](settings-lifecycle.md)为准，不依赖请求明细中的 HTTP 状态码解释故障。

业务页面保留草稿及选择；普通导航（包括帮助、关于和历史前进／后退）回到页面顶部，明确的定位链接才滚到对应区域并移动焦点，旧锚点继续可用。操作反馈说明具体动作，只属于发起操作的页面，离开后清除；迟到的响应不把反馈带到新页面。连接中断、本地存储故障等全局状态仍持续展示。设置以实际差异判断未保存状态，放弃更改恢复已保存值；保存成功后等新状态同步再解锁。真实游戏和系统集成仍见[待验收台账](live-acceptance-backlog.md)。

引导的“阅读并同意条款”打开确认弹窗，成功后显示“条款已确认”；入口说明立即保存。退出说明按已保存的恢复直连选项更新。放弃入口明确称“放弃草稿并退出引导”。存储、网络与导入选择最后应用，摘要列出是否重启、服务与队列会启动还是保持当前状态，以及当前游戏连接配置；服务启动遵循[配置生命周期](settings-lifecycle.md)。

引导正文在可用窗口内独立滚动，底部操作栏保持位置；切换步骤时正文回到顶部，标题获得焦点。上一步与主操作按钮保持相同宽度，无恢复操作的步骤也保留其布局空间，窄窗口换行不随步骤变化。校验错误显示在操作栏上方，不推动按钮。应用层的操作反馈、断连和存储故障提示在引导内部参与高度分配，出现时压缩正文区域，不额外增加页面高度；其他页面仍使用原公共提示位置。

设置表单顶部的操作栏滚动时固定显示状态、保存、放弃与重启按钮；无需重启时按钮禁用。字段直接可见，原生校验定位无效输入。各配置位置只呈现所属字段，补充技术说明按需提供。“同时下载数量”“提前准备时间（秒）”使用任务语言，技术边界保留在提示中。

帮助按开始使用、播放失败、空间不足与视频保留、停止与卸载、日志与当前路径组织；目录明确定位各节，安装、代理、搬迁和升级以直接可见的步骤说明。帮助目录及内容在状态接口不可用时仍可访问。

下载速度测试默认展示单连接／多连接速度与可用性，CF 接口、连接数及 CPU 分位值在技术详情中。准备样本失败说明缺少在线测速样本，先检查连通性再重试，不要求本地视频或预算；失败仅展示在对应连接方式下。

批量任务分别呈现本地检查进度、上次完成记录和在线曲库更新结果；使用已有清单时明确标注，原始在线错误收进详情。“重试更新”复用缺失检查入口，更新曲库并检查本地文件，不下载视频。没有可用清单时明确未开始本地检查，不把在线错误混入逐曲失败数量。

游戏接入退出策略只在「设置 → 常规 → 退出」中编辑，默认开启「退出时恢复游戏直连」，首次引导不增加模式选择。退出按钮的 Tooltip 按 activeSettings 展示当前策略，页脚提供退出设置入口，保存成功后该退出选择同时更新到 activeSettings 并用于本次退出，不等待重启；未保存的草稿不改变退出说明。已有托管接入尚未准备恢复权限时，首页仍允许点击「开始加速」并说明直接退出会保留接入；退出结果只确认请求已接受，不预报恢复成功。权限与异常边界以[hosts 契约](console.md#hosts)为准。

## 请求历史

历史默认查最近 24 小时，可使用本机时区的日期时间字段筛选，或选择全部保留期；每页最多 50 条，游标可遍历超过 500 条的记录，页面不累计无限列表。第一页未设置结束时间时每 5 秒刷新，后续页保持稳定；暂停只冻结展示，离开页面或浏览器不可见时停止读取。尚无结果时显示加载状态；后台刷新期间保留现有记录或空结果提示，历史与首正文统计的刷新操作保持可用，响应成功后更新内容。筛选草稿随应用内导航保留，切换存储重置游标；翻页和重新查询将焦点送到结果区域，刷新时保持请求 ID 对应的展开状态。读取失败移除过期行并回退焦点，提供重试。旧 #recent 锚点定位此页。

首正文分位数独立每 30 秒读取，提供显式刷新，不受历史日期范围和分页影响。Blocking、缓存／本地均同时展示 P50、P95 及样本数；无样本显示暂无数据，不用零值代替未知。首次采集和清理水位决定覆盖不足提示。行内只显示请求时已知歌曲 ID 和资源，当前关联不推断为历史身份；正文交付未知时显示 —，错误正文不计入视频字节。完整业务口径见[请求监控](console.md#最近请求监控)。

曲库的歌曲资料和需求分数与资源状态分开呈现，共享文件只在资源映射中读取一次。未知大小／实测时长显示未知；运行期块进度即使达到 100% 也不代表完整文件已保存。历史歌曲／资源链接执行精确查询，不在当前范围内时明确说明并保留原身份。删除和定位共用已有文件快照、确认及保护机制；列表每页最多 50 项，文件状态每 10 秒读取、下载观测每 5 秒读取，不可见时停止。单项与全量共用批量运行槽，结果标明本次范围，不建立追加待办集合。

设置和关于的标签选择写入 Hash 路由，刷新及前进／后退保留所属分类。VRCX 工具首次进入时加载，返回曲库或切页后保持已挂载的草稿及预览。资源视图保留最近请求排序，复用已有 GET 访问汇总。

常规主题提供跟随系统、浅色、深色，选择后单独自动保存到程序配置并立即应用于 Fluent 主题、图标、块需求画布及托盘，不需点击保存或重启，也不提交其他设置草稿；失败保持原主题并显示原因。多页面同步、默认值与系统跟随边界统一见[配置生命周期](settings-lifecycle.md)。「启动程序时自动打开 WebUI」默认开启，保存后下一次启动程序使用；托盘主动打开及已有实例激活独立于此设置，网页内重启沿用 -no-open 复用原页面。旧 #cache、#song-preferences、#recent、存储／下载／网络锚点及 /help、/about、/terms 保留对应归属。

首页当前 GET 与下载活动复用同一 /api/downloads 快照，每 5 秒读取，不可见时停止。GET 在处理期间存在，身份仅使用已验证的实际请求歌曲及资源，解析中字段保持未知；交付比例复用有效响应范围与成功写出视频字节。最多显示最早 50 个活动请求并给出总数，不查询当前关联来猜测播放歌曲。网关展示实际 80／443 状态；队列展示真实内容及日志未读取／尚未发现／正在读取／读取失败，不将配置勾选当作启用成功。
