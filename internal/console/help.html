使用帮助

播放网关、本地缓存与游戏接入

播放网关接收游戏播放请求，读取本地缓存或从上游下载视频，并兼容转发 HTTPS 连接。「本地缓存」管理已保存的视频；「上游通道」是直连或代理等连接出口。「启用游戏加速」会启动播放网关并完成游戏接入。

房间队列预缓存与播放网关独立启停，共用本地缓存。只开队列可以提前准备视频；游戏读取缓存仍需启动播放网关并完成接入。停止播放网关不会停止队列，下载补齐期间则会临时暂停队列。停止播放网关或退出应用不会恢复 hosts，停用前请先恢复游戏直连。

运行控制台时自动启用

「设置 → 控制台启动」提供播放网关和房间队列预缓存两个独立选项，默认均启用；已有配置中保存的关闭选择会保留。保存后下次启动控制台程序生效，重新打开网页不会触发，手动启停不会改变设置。自动启用需已同意使用条款；首次启动会等到引导最后「确认并应用」成功后执行，需要重启时由新进程执行。重新进入引导不会重新开启已手动停止的服务。自动启用不会修改游戏接入（hosts）。

解压、启动与退出

完整解压 Portable ZIP，把 SWD 文件夹放在当前用户可写的位置，再双击 SWD.exe；不要从压缩包内运行。无需安装 Go、Node.js 或其他运行库。普通启动和条款确认不要求管理员权限。

引导共四步：开始、存储、网络、启用。点击「完整条款」打开弹窗，在底部同意后立即保存，开始页绿色对勾表示已确认，再点下一步。之前的记录无法验证时会重新弹出条款。开始页下方「修复已有安装」默认收起，展开后可点击「恢复游戏直连」，请求管理员权限移除本程序的 hosts 映射。点击缓存位置文本框打开 Windows 文件夹选择器；勾选「导入已有视频」后才显示目录框和说明，再点击目录框选择来源，取消勾选即不导入。网络环境检测固定标注「直连」，刷新按钮统一重测歌曲列表、播放地址及视频下载，不验证代理节点；下方「连接方式」选择直连或代理。启用页可刷新 hosts、端口和日志检查，点击「接入／恢复」即时操作 hosts，悬停可查看影响；「确认并应用」保存配置，必要时自动重启并开始导入，成功后直接进入控制台。

「恢复本页默认」只恢复当前页，存储页也会清除本轮导入选择。「放弃更改并退出引导」丢弃草稿；已确认条款或已启用的游戏接入会保留。确认应用不额外修改游戏接入；如果需要重启程序，播放网关和房间队列预缓存按「控制台启动」的两项设置自动启用。失败会留在引导显示原因，恢复时不会重复应用或导入。更多网络、队列和日志选项在普通设置页。

网页是程序的控制界面。同意条款后关闭浏览器，程序仍在 Windows 系统托盘运行；从托盘菜单或再次双击同一份 SWD.exe 可打开控制台。未同意时关闭欢迎/条款界面约 60 秒后尝试自动退出，重新打开可取消。

退出请使用托盘菜单或网页「退出整个应用」。退出会停止服务和后台任务，导入/批量任务不会在下次启动自动续传。日常使用可直接打开普通控制台，无需每次走引导。

存储、容量与已有视频

默认数据位于程序旁 data，视频库默认 data/storage；仅在功能需要时创建。当前实际路径请看下方。视频位于库内 videos，歌曲资料与统计位于 storage.sqlite。外置存储必须保持可用，移动程序不会自动搬迁外置视频。

设置保存后需要主动重启才生效。存储目录变更只是选择另一套库，不迁移旧数据库或视频；需要搬迁时先备份，保存目标目录但暂不重启，退出整个应用后完整搬迁旧库，再启动。不要运行中只移动 videos 或 SQLite 主文件。

容量上限为 0 时不限，使用中的视频和临时文件可能暂时超限。容量收益图仅为历史回测参考，不保证每个人的命中率或速度。目录不可写时选择当前用户可写的位置；旧格式或未来格式被拒绝时保留原数据，选择新库或更新程序，不删除标记或手改版本号。

导入先刷新网络清单，再按 MD5 校验匹配视频。同卷优先硬链接、跨卷复制；重复内容跳过，默认保留源文件。硬链接共享内容，请勿修改源视频。清理源文件需要独立确认；旧库统计不随视频导入迁移。离线时可先配置网络，稍后重试。

导入固定使用开始时的生效目录；翻页或关闭浏览器不停止任务。在导入期间可继续编辑并保存设置，请等任务结束再重启，否则导入会中断且不自动续传。

网络与游戏接入

游戏 HTTP 视频可读写本地缓存；游戏 HTTPS 视频保持原站加密连接并直连透传，不读取或填充视频缓存，也不随应用回源的代理策略改变。首次下载速度仍取决于上游和本地网络。

直连可独立工作；需要代理时可选择外部 SOCKS5 或内嵌 Mihomo。强制代理的业务请求不会失败后直连；自动模式允许选路。向导重入会直接检测直连速度，即使业务使用强制代理，也不改变业务配置。完整测速沿用 Monitor 的有限样本，结果不能保证每首歌的持续速度。设置页和引导共用节点导入：选择本地文件或粘贴 YAML proxies、URI、Base64 URI 列表，检查并核对逐条结果，再保存或最终应用。接受的节点会替换整份旧库，重启生效；不自动获取或更新订阅。默认最多 5 个节点活跃，备用节点仍保留，初始集合不代表延迟最低的 5 个，失败时不会自动启用备用节点。需要改用备用节点时，重新导入所需的小规模节点集合、保存并重启。

「启用游戏加速」会检查并启动本地服务，按需请求 Windows UAC 修改 hosts。HTTP 80 和 HTTPS 443 均需可用。若被其他程序占用，请自行判断并处理，不要随意结束不认识的进程。hosts 冲突、UAC 拒绝会给出诊断，不覆盖第三方映射。

启用后进入 WannaDance 点歌，查看当前接入检测和运行状态。「收到请求」仅表示请求到达服务，音画和进度仍需在游戏里确认。未收到请求可尝试重进世界或重启游戏刷新 DNS；未找到日志时先运行游戏，或检查日志目录设置。

退出不会自动恢复游戏直连。停用或卸载前，请在「开始使用 → 高级接入设置」中点击「恢复游戏直连」，核对结果后再退出。 hosts 和系统目录中的 hosts.swd-backup 不随 Portable 文件夹删除；已有 hosts.stepstash-backup 保持原样。

备份、覆盖升级与卸载

  1. 退出整个应用，再备份完整 data。自定义配置须备份主 JSON 及对应实例数据根；外置媒体须另行备份整个库。
  2. 将新版 ZIP 解压到临时位置，把 SWD.exe、licenses/、README.txt、build-info.json 覆盖到原安装目录。保留原 data、外置库和未知文件，从原安装目录启动；不要误运行新解压目录中的另一套空配置。
  3. 条款变化时重新确认。遇到较新或不支持的配置/库格式时按诊断处理，不手改版本号；旧测试布局不自动迁移。

条款、代理凭据和整份导入节点快照由 Windows 当前用户保护。同用户在原环境中完整搬迁可保留；换用户或普通独立机器可能需要重新确认/配置。域账户漫游可能跨机器解密，不承诺绝对设备绑定。不要把个人凭据随发行包分享。

自定义配置名为 config.json 时，附属文件位于其所在目录；其他文件名使用「配置完整路径.d」。相对存储路径以主配置所在目录为基准。运行锁文件存在不证明进程仍存活，不要靠删锁解除占用。

卸载：先恢复游戏直连 并核对，再退出整个应用，备份需要保留的数据，然后删除自己的 Portable 目录。外置视频库不会自动删除，请自行决定保留或清理。
