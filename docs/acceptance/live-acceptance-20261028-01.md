# LIVE-20261028-01 VRC 实机验收报告

## 结论与版本

本轮选定场景已完成：独立未缓存 Seek 的带宽恢复、2 秒队列交接、离房撤销、歌曲拒绝后正常切歌、中途接入与直连恢复、多人非 owner 中途同步均取得实际音画反馈及关联证据。未发现这些场景中的新增 SWD 发布阻塞；不代表发行包、CI 或全部历史慢网根因已验证。

冷 Seek 超时后能自行恢复，但回到了较早位置。用户与 agent 均倾向于游戏播放器在 504 后重新加载所致；日志中的新加载与 `Range: bytes=0-` 与此相符，尚未确认归因。不把它单独列为 SWD 缺陷或发布阻塞。低于视频码率时卡顿是预期结果，本轮只据此验证恢复，不以低带宽下无卡顿为通过标准。

- 产品源码：`98e396175d876880bb4c57806263bd3574c57f0f`；构建时工作区干净，版本 `dev-live-20261028-01`，Go `1.27.3`，Windows amd64。
- 实际 `SWD.exe` SHA256：`d8c77ffe8dc538973074a0d59e6408f46170f9b33f9c1e77f540184ac8f562a4`。这是开发构建，没有测试发行包。原先运行的旧脏构建已正常退出，未用于本轮游戏结论。
- 2026-10-28，实际游戏样本约 18:10–18:39（UTC+8）；先在可控制的单人 WannaDance 房间验收，后追加多人非 owner 场景。Windows 11 Pro `10.0.26300`，VRChat `2026.4.1-1935-a61ceb9d89-Release`；未提取世界精确版本。用户操作游戏，agent 维护隔离服务及采集。
- 隔离空视频库、零持久容量、默认 300 秒本地保护；外部回环 SOCKS5 聚合限制视频上游，API 元数据豁免。1 Mbps 为 125,000 B/s，含 TLS 开销，不等同于单连接限速。
- 单人慢网阶段结束后解除限速；单人服务正常退出后，因用户具备多人条件追加同批次第二段，复用相同 EXE、改为正常直连上游并单独采集。没有中途换包或把两段时钟混用。
- Debug 应用日志持续转存、块事件流、1 秒状态采样、100 ms 游戏日志增量采样、2 秒进程 CPU/内存采样。CPU 采样不是游戏帧时间；日志开播回调不是精确首帧。
