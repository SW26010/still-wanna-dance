# #16 使用引导：最终实现与验证

开发完成，实机验收 **LA-029 / LA-030 待执行**。本记录只描述当前实现及最终检查结果；浏览器内存夹具不作为真实系统、网络或游戏验收通过依据。

## 当前行为

步骤顺序：**欢迎使用 → 使用条款 → 存储设置 → 导入视频 → 网络检测 → 上游设置 → 本机接入 → 核对应用**。

| 范围 | 最终行为与代码依据 |
| --- | --- |
| 页面与导航 | 独占安装向导式页面；左侧只标记当前步骤，不标记经过状态；欢迎直接显示 slogan 与运行边界，无折叠、跳过或品牌/连接顶栏。上下步与本页重置在底部，放弃退出在侧栏下方。`setup.html`、`assets/setup.js`、`assets/console.css` |
| 条款与步骤门禁 | 一次性「确认同意条款」按钮立即保存 DPAPI CurrentUser 记录；成功后停留条款页，显示禁用的「已确认条款」。上下步与侧栏不提交同意。欢迎、条款自由互访，后六页必须有服务端有效记录；切页同时要求当前页内容合法，两项检查独立。读取/保存失败不解锁，允许重试或返回欢迎。`terms.go`、`assets/setup.js` 的 `validPage()` / `canVisitStep()` |
| 草稿与重置 | 每轮从正式设置预填；切页校验后仅保留本轮草稿，普通设置草稿独立。非法内容留页，迟到响应不抢导航。重置只恢复本页出厂默认值，默认未改时禁用。`state/setup.json` 只存进度，不授予条款同意或保存业务配置。`setup.go`、`assets/setup.js` |
| 离开与放弃 | 草稿有修改时，浏览器返回/哈希导航等离开入口弹原生确认；取消保留页面与草稿，确认才丢弃。刷新/关闭使用 `beforeunload`；未修改或改回原值不提示。明确「放弃更改并退出引导」不重复询问，断连/非法输入也可放弃。放弃不撤销条款或已执行 hosts 操作。`assets/setup.js`、`assets/navigation.js` |
| 存储与导入 | 默认 Portable 内 `data/storage`；手动指定位置必须在 Portable 外，检查路径、可写性、库格式与 junction 边界，显示所选分区总量/可用量，检查不建库。导入方式直接显示；离页仅检查来源，目标可另行修改；最终确认才联合校验来源和目标并执行导入。`setup_storage.go`、`cacheproxy/storage_inspect.go`、`assets/setup.js` |
| 上游与测速 | 直连默认选中、SOCKS5 默认不选，两项独立且不可全空；对应 direct / socks5 / auto。首次同意记录保存成功立即后台测速；已有有效记录时从设置/帮助重入自动发起一轮，步骤往返/刷新/回执恢复不重复。私有 Monitor 检测直连速度，不改变业务代理。`terms.go`、`setup_network.go`、`upstreamstate/monitor.go` |
| 本机接入 | hosts 独立即时启用/恢复，强调 UAC 和退出后仍持久化；显示 80/443 占用。操作等待/失败不阻塞其他步骤。自动及手动检查当前生效的 VRC 日志位置，仅有界读取、不返回日志内容或启动监听；旧日志可读不代表游戏在线。`setup_logs.go`、`vrclog/tail.go`、`assets/setup.js` |
| 核对与应用 | 最后清单对照生效值列出实际变化、导入来源/目标和此前保存待重启的高级配置，不显示代理密码。唯一提交入口 `/api/setup/apply` 在锁内复核版本、合法性与活动任务；确认后保存，按需重启，再在确认的配置下导入。陈旧清单拒绝，部分失败明确显示，不承诺跨操作整体回滚。`setup_apply.go` |
| 回执与恢复 | 共享及逐 ID 持久回执绑定配置摘要、不含密码；响应丢失按原 ID 核对，不重复导入，中断不自动重放。重启 60 秒未就绪时向导内显示原因，开放「重新连接并核对」和退出；保留原 ID，恢复不重复 POST 应用/重启/导入。`setup_apply.go`、`assets/console.js`、`assets/setup.js` |
| 临时槽与帮助 | 配置锁内清理共享 `.setup-apply.json.swd-tmp` 和严格匹配 `.setup-apply-[0-9a-f]{64}.json.swd-tmp` 的逐 ID 槽；正式回执、未知文件及其他配置保留，异常目录/链接拒绝且不递归删除。内置帮助可离线阅读并重入引导。`desktop/config_lock.go`、`help.go`、`help.html` |

未在向导加入高级存储/网络、队列预缓存或日志配置；这些继续由普通设置负责。条款保存、hosts 开关及直连诊断是即时操作，其余清单内容在最终确认前不应用。
