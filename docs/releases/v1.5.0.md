**Still Wanna Dance v1.5.0**

- **房间播放与预加载**：根据房间播放进度安排下载，保留切歌期间下一首的预加载时限。弱网缺块时，只要仍有播放或预加载需求，下载就会继续尝试。
- **直连选路与测速**：视频下载与测速共用近期线路观测。临时线路故障时可尝试其他候选 IP，首页块详情显示当前尝试的 IP。
- **下载状态更清楚**：首页显示房间播放进度、视频可用状态和队列预加载失败。块时间轴在持续更新时更流畅。
- **缓存与日志**：修复部分缓存模式下临时块未按预期回收的问题。「设置 → 常规」可调整程序日志大小上限，保存后重启生效。

从 v1.2.3 升级时，先退出程序并备份配置和数据库，再将新版 `SWD.exe` 与整个 `licenses/` 覆盖到原安装目录。保留原配置、数据和视频，从原目录启动。
