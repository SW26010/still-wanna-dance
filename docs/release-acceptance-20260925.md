## 边界

- SHA 暂不支持；Auto 依游戏 API 的当次返回，不保证固定 CDN。
- 上游速度不足仍可能卡顿，无自动换源或分段加速。
- 本轮未重复多人中途加入，早期实机样本见早期服务验收；未做长时间浸泡、完整曲库下载、断电、磁盘满或 Windows race 检测。
- 在用视频保护等故障/并发边界另有自动化覆盖；本轮容量实测覆盖启动淘汰及真实后台下载完成后的淘汰，不据此宣称全部并发矩阵都已实机覆盖。
- 验收末尾的中段与 hosts 探测 GET 会计入请求需求，已用 `StepStash-Acceptance-*` User-Agent 标明；预缓存不增加热度的结论取自这些探测之前的数据库快照。
- 正常关闭 CDN 或退出不会自动恢复 hosts。退出前应在控制台恢复；这次已经实测恢复。原始基线 SHA256 为 `2D6BDFB341BE3A6234B24742377F93AA7C7CFB0D9FD64EFA9282C87852E57085`。

完整本机证据保留于被 Git 忽略的 `test-runs/full-live-c69e844-20260925`；程序日志位于本轮 portable 目录的 `logs`。仓库精简证据不包含完整游戏日志、实际 hosts 内容、玩家名单或用户路径。

最终收尾检查于 T+887.000s 完成：本轮进程为零，80/18081 无监听，临时 `.part` 为零，hosts 与原始基线一致。用户反馈“已退出，vrc未察觉异常”。
