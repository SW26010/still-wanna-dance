# Web UI 内容分类

控制台和文档统一从左侧导航访问。当前文案以 `207e431` 为基准；迁移标准组件不授权另行精简页面正文。组件选择和业务保留边界见 [Fluent UI](fluent-ui-migration.md)。

| 页面 | 内容 |
| --- | --- |
| 开始使用 | 产品用途、接入状态、下一步；高级接入设置包含播放网关、hosts、端口及错误 |
| 准备歌曲 | 房间队列预缓存、全曲库扫描/补齐、预算、进度和失败记录 |
| 本地缓存 | 文件数量/占用、搜索/排序/分页、受保护项、定位文件、删除确认；覆盖率和缓存效果统计 |
| 运行状态 | 当前下载、最近请求与加载更多、暂停展示、网络检测及线路技术详情、向导诊断 |
| 设置 | 使用引导入口、外部视频导入及源清理、存储/自动启动/网络/日志与队列设置、保存和重启 |
| 帮助、关于、条款 | 离线帮助、项目及许可说明、完整条款和恢复直连入口 |
| 使用引导 | 开始 → 存储 → 网络 → 启用；独立草稿、明确同意、手动检测、核对后一次应用 |

技术数据通过标准 Accordion 分层展示，不改变下载、检测、存储或保护规则。当前文件摘要独立于搜索/分页；请求次数不等于播放次数，分组耗时和速度为估算值；网络成功样本不保证每首歌曲可播放。接入、导入、永久删除、流量与空间成本的原说明继续可见。

本地存储故障使用控制台公共 MessageBar 显示，切页仍保留首个原因、影响和恢复步骤；生命周期以[配置与运行约定](settings-lifecycle.md)为准，不依赖请求明细中的 HTTP 状态码解释故障。

五页保留草稿及选择，旧锚点继续定位相关区域。设置以实际差异判断未保存状态，放弃更改恢复已保存值；保存成功后等新状态同步再解锁。真实游戏和系统集成仍见[待验收台账](live-acceptance-backlog.md)。
