# 前序窗口、失败和范围变更

以下均为 2026-10-29 晚的独立批次。它们用于解释当时的上游状态及实验演进，不与最终 329 地址、固定 1 MiB 块的单路验证合并统计。精简数据见[历史汇总](../evidence/wifi-ip-selection-20261029/legacy-summary.json)，更早默认路由与修正 Wi-Fi 的资料见[原报告](upstream-window-20261029.md)。

## 持续 Wi-Fi 观察

基础观察完成 26 轮，共 214 条请求记录，其中一条被窗口截止打断，主统计排除该条。资源片段为 256 KiB，不能当作整条线路总带宽；IPv6 使用已修正的全局源地址。Node 源地址绑定、实际本地地址核对与当时的源路由检查单列，不能冒充后续 Go socket 接口绑定的同一种实现。

| 请求 | IPv4 完整成功 | IPv6 完整成功 |
| --- | ---: | ---: |
| Udon 播放 API HTTP | 26/26 | 23/26 |
| Udon 视频 HTTP | 25/25 | 23/25 |
| Udon 播放 API HTTPS | 0/26 | 0/25 |
| Udon 视频 HTTPS | 0/25 | 0/25 |
| Cloudflare HTTPS 控制 | 4/5 | 0/5 |

Udon HTTP 合计 97/102，HTTPS 0/101。HTTPS 失败阶段分布为连接 71、TLS 29、等待响应头 1；HTTP IPv6 保留三次响应头失败及两次正文失败。不能从这组 Node 新连接样本推断整个窗口所有客户端都无法使用 HTTPS；更早的 Go 组件曾捕捉短暂恢复，后来的宽池也找到能完整交付的额外地址。[逐条观察记录](../evidence/wifi-ip-selection-20261029/README.md)保留失败与截止中断。

## 16 MiB 多路实验

先获得 16 个 1 MiB 块的内容参考，再对九个 IP 作两轮 1 MiB 初筛。18 次筛选中 10 次完成；冻结最快地址为 `104.26.4.28`，与指定 DNS 基线相同，前三级也都是原 DNS 地址。因此同 IP 的“best”与“dns”耗时差不能算 IP 优选收益。

较大对照计划按每组相同 16 MiB、1/2/4/8/16 路执行，最终保留 14 个完整结果记录：10 组完成、4 组失败。实验转向单路 IP 优选后停止，第二轮 `dns-1` 的在途组没有完整结果，明确排除，不能补造速度。

| 配置 | 完整成功 / 已记录组 | 成功样本 MiB/s |
| --- | ---: | --- |
| DNS 单 IP，1 路（两种同配置标签合看） | 0/2 | 两组均在 90 秒未完成 |
| 优选单 IP，2 路 | 0/2 | 两组均在 90 秒未完成 |
| 优选单 IP，4 路 | 2/2 | 0.311、0.489 |
| 三个 DNS IP，4 路 | 1/1 | 0.431 |
| 同一 DNS IP，8 路（两种同配置标签合看） | 2/2 | 0.752、0.791 |
| 三个 DNS IP，8 路 | 2/2 | 0.830、0.867 |
| 优选单 IP，16 路 | 1/1 | 0.678 |
| 三个 DNS IP，16 路 | 2/2 | 0.967、1.208 |

这些数据呈现多路改善的方向，但 4、8、16 路的多 IP 对单 IP 对照各自仅第一轮形成完整配对，未完成第二轮复核，不能宣布稳定的多 IP 收益。16 路的 16 MiB 组只有一波块请求，也不是长时间稳态测试。基础小流量观察和部分筛选同期运行，微小差异不能作严格归因。[逐组数据](../evidence/wifi-ip-selection-20261029/README.md)保留所有已记录失败。

同期另测同九地址 HTTPS 单路 1 MiB，每地址最多八秒，0/9 完整成功；有的已取得 206 并读到部分正文，不能都说成 TLS 失败。它和 HTTP 筛选有时间重叠，结果单列于[HTTPS 记录](../evidence/wifi-ip-selection-20261029/README.md)。

## 固定 16 路的短暂 IP 对照

每组 16 MiB、同一 IP，四个地址两轮反序，全部八组均产生结果：六次完成、两次失败。

| IP | 第一轮 MiB/s | 第二轮 MiB/s |
| --- | ---: | ---: |
| 104.26.4.28 | 0.883 | 1.193 |
| 104.26.5.28 | 1.238 | 0.647 |
| 172.67.69.58 | 1.102 | 0.583 |
| 104.24.0.1 | 未完成 | 未完成 |

最快 DNS 地址随轮次变化，只有两轮，不构成稳定选点证据。额外地址两次均读取部分正文后失败，不能写成完全没有收到内容。[固定 16 路记录](../evidence/wifi-ip-selection-20261029/README.md)独立保留。

## 两次预试验与范围变更

后续研究聚焦单路 IP 优选，扩大至至少 100 个候选，以固定 1 MiB 块采样，初筛从全串行改为四路并行。后续批次不沿用基础观察的固定截止。原始批次保留各自方法：

- 九候选单路预试验保留 14 条：12 次完成、1 次超时、1 次因扩池中断。未进入原计划的 4 MiB 后续验证。[原样本](../evidence/wifi-ip-selection-20261029/README.md)。
- 扩池的全串行版本保留 26 条：24 次初筛（6 完成、18 失败）、一个完成的 DNS 对照和一个因改为四路初筛而中断的对照。[原样本](../evidence/wifi-ip-selection-20261029/README.md)。

最后的四候选并行批次另有探针 403 误停及运行目录迁移暂停，两者共七条中断记录；接续后的全池、串行确认和六轮留出均已完成，详情见[最终报告](wifi-ip-selection-20261029.md)。
