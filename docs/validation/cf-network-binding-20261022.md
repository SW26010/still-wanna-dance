## 失败保留与边界

- 首次直接 `go test` 的相对输出路径按包目录解析，创建目录失败，尚未联网；改用绝对路径后 smoke 通过。最终 EXE 首次经 PowerShell 包装器运行时，未加引号的带点参数被拆分，参数解析失败且尚未联网；修正文档和命令中的引号后通过。两次调用错误的记录均保留。
- 沙箱内三包完整回归出现既有的 `renameat: The handle is invalid` 等存储操作错误，与[开发环境说明](../development.md)记载一致。经相同临时目录入口在沙箱外复跑，三包全部通过；没有修改产品存储代码或弱化断言。
- 网卡断开、缺地址族和绑定失败的停止行为由受控测试覆盖。本轮未物理断开网卡，未修改系统路由、hosts、防火墙或路由器，也未启动游戏。每秒轮询不能证明捕获了全部瞬时掉线。
- 本机绑定和 TLS 校验不能证明路由器绕过透明代理；仍需单独确认两种地址族的路由器处理。未做完整性能对照，未据此宣称裸连或吞吐收益，无需新增 VRC 待验项。

原始日志、失败回执、实际配置、连接记录、构建哈希及变更源码快照保存在忽略目录 `artifacts/cf-network-20261022/`；实际网卡配置在 `local/cf-network.json`，均已检查 Git 忽略生效。公开材料不包含本机网卡 GUID、MAC、接口索引、源地址或签名资源 URL。
