## 复现夹具

运行 `node scripts/setup-ui-fixture.mjs` 并打开其输出的本地地址；`SWD_UI_PORT` 可指定端口，`SWD_UI_RESTART_TIMEOUT=1` 可模拟重启未就绪。按 Ctrl+C 关闭，重启后内存状态清空。夹具路径使用虚构的 `C:\SWD-UI-Test`，不会保存真实配置、确认法律条款、连接上游或修改 hosts。
