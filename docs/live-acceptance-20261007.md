## 关键行为证据

### 首正文不等于起播

9073 预缓存后，API 探测首正文约 0.617 ms，播放器 Range 请求约 0.505 ms。这是收到请求至开始返回正文的服务端计时，不是点击至首帧，也不是所有请求的性能保证。

同次游戏日志明确记录加载 1.744873 秒，然后主动等待 8.255127 秒才播放，合计约 10 秒。完整传输完成时间、首正文和客户端首帧不能混为一谈。

### 下载中跳转

7628 以开始下载为 T+0 秒：T+2 秒起播，T+5–13 秒跳至约 82、130、192、222 秒，均为 206 MISS；T+16 秒才完整发布。28 另以跳至约 209 秒为 T+0 秒：T+2 秒回至约 50 秒，读取偏移由 62,701,568 回到 14,958,592 字节；T+7 秒切至 9073，旧下载在 T+14 秒校验发布。用户未察觉异常。

### 队列任务转前台

1345 以后台创建 `flight_id=4` 为 T+0 秒：T+6 秒前台探测和 Range 请求附着同一任务，只有一次 `download_started`。歌曲出队取消队列等待后，前台仍继续读取；T+15 秒起播，T+18 秒完整发布。用户未察觉异常。

1347 以后台创建 `flight_id=5` 为 T+0 秒：T+6 秒预览附着；T+9 秒和 T+12 秒中后段读取继续共享。T+14 秒完整发布，后续回拖为 HIT。该样本是预览，不记为正式队列播放。

### 双读取连接

1348 唯一任务为 `flight_id=1`，服务为 `DG5UT2AOOPOBZ3W3WDSXSXANAZ`。本场景以请求 3 开始为 T+0 秒，下表由 JSON 的 `t_ms` 相减得到。

| 请求 | 相对起止时间（秒） | 范围与结果 |
| --- | --- | --- |
| 3 | T+0.000–T+40.441 | `bytes=0-`，206，完整 29,899,909 字节，completed |
| 6 | T+6.032–T+7.931 | 从 4,145,152 字节读取，206 MISS，拖动时取消 |
| 7 | T+7.944–T+10.793 | 从 23,887,872 字节读取，206 MISS，拖动时取消 |

完整发布在 T+8.290 秒，因此不同 Range 的请求在下载未完成时确实重叠，并共享同一任务。预览旧请求取消未中断初始完整读取，MD5 正确。之后回拖为 HIT，不计下载中回拖。用户未察觉异常。

游戏记录过一次 `Rate limited, retrying` 后恢复；同期 SWD 未返回 4xx/5xx。日志不提供逐毫秒读指针或逐块上游轨迹，不据此宣称逐块绝无重复、两条上游连接上限已通过实网抓包验证，也不证明两个画面每一时刻同时呈现。

## 故障注入与恢复

### 上游不可用

仅修改验收版上游，不改变系统代理或游戏网络。初次本机拒绝代理实际表现为连接超时，因此记录为连接不可用，不宣称验证了 SOCKS 握手拒绝分支。9073 本地探测返回正文、播放器条件请求 304；后台 cf/nya 查询失败未阻塞播放。1343 在无缓存、无持久 URL 时返回 502，未生成完整视频；切回 9073 正常。

已有缓存实际走直接命中，不代表专门的“等待 API 失败后再降级”分支已测。

### 下载中断开

独立转发代理先验证可用，再在收到约 8 MiB 后切断并拒绝后续连接。1343 下载失败：收到 8,355,840 视频字节，当前 206 输出 3,932,160 字节后 aborted；无完整视频，tmp 清理。本场景以该次失败为 T+0 秒。

用户看到短暂播放后黑屏无明显提示；游戏日志有错误及重试。恢复连接后自动重新下载，T+126 秒以目标进度 0 开播，T+153 秒完整校验发布。用户确认恢复，不属于断点续播。

### 异常终止

核对 PID、可执行文件路径及启动时间后，仅在 5951 已收到正文时强制结束本次验收进程。没有完整视频，只留下一个 **0 字节** `.part`；两个数据库 `PRAGMA integrity_check` 均为 `ok`。

重启并记录 `removed_partials=1`，以此次重启为 T+0 秒：T+5 秒从 0 秒重播，T+24 秒完整校验发布；用户确认音画恢复。该样本不是非零磁盘半文件恢复或真实断电测试。

### 磁盘不足

新建独立 128 MiB VHDX，核对路径、磁盘号、RAW 状态及非系统/启动盘后格式化。复制元数据快照并仅在虚拟盘写占位文件，留下 12,582,912 字节；未填满实际磁盘。

1344 报真实写入错误 `There is not enough space on the disk.`，下载失败、流响应中止。本场景以该次错误为 T+0 秒。用户看到约三分之一处黑屏、一次从头重播，第二次再次黑屏。后台多次下载并在相同限制处失败；后台重试次数不等于画面重播次数。

隔离盘 videos/tmp 最终均为空，两个数据库完整性正常。恢复原验收存储后，T+170 秒自动从头播放、T+176 秒校验发布、T+209 秒整首传输完成，用户最终确认正常。该次重播发生在存储恢复后，不继续归为满盘失败循环。
