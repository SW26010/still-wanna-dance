## 准备失败与验证边界

- 旧实验中继仅允许 443，而当前歌曲 API 和返回的视频地址使用 HTTP 80，准备阶段导致 502 和持续加载。先放行 API 后仍有资源请求失败，最终放行 HTTP/HTTPS 80/443 后才取得有效样本。两次中继失败和所有游戏错误保留在原始日志；不计为本轮产品慢网失败，也不掩盖为已通过请求。
- 修正仅涉及 `experiments/live-get-probe`，没有改动产品实现；新增真实 SOCKS 握手检查覆盖 HTTP/HTTPS 目的地址、端口保留及其他端口拒绝。经隔离临时目录和依赖补丁入口运行整个实验包测试通过（2.773 秒）。工具补丁、三份中继日志及最终二进制哈希保留在[来源指纹](../evidence/live-20261113-01/provenance.json)。
- 旧应用采集脚本只跟踪当天首个日志文件，未自动切到编号续卷；完整产品日志三个文件仍在，最终导出使用这些原始续卷，保留源文件名和行号。游戏日志增量采集与块事件流持续运行，没有用不完整的首卷推断结果。
- 游戏日志精度为秒，采集约每 100 ms 观察一次；产品时间线保留毫秒。开播回调和人工反馈不等于精确首帧。本轮没有 CPU/帧时间测量，不作游戏性能结论。
- 用户最初的黑屏反馈发生在中继修复前；有效慢网阶段据真实请求截止判断，恢复后的音画依据用户明确反馈。手动重开是在自动恢复之后执行，没有制造并验证“恢复带宽后仍持续黑屏”的独立故障，也未做独立未缓存 Seek。
- 历史失败及过去结果边界不变。本轮覆盖当前 LA-040 所选的重请求、恢复和重新加载体验，不声称所有网络、播放器、多人条件或黑屏故障均已验证。
