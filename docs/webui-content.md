# WebUI 内容分类

本文维护界面文案、状态语义及具体展示要求。页面归属与交互、数据规则见 [WebUI 设计](webui-design.md)，组件选型、尺寸与主题样式见 [Fluent UI 约定](fluent-ui-migration.md)；历史验证结果不作为当前规则。

## 程序与界面术语

用户文案和技术文档统一使用「程序／SWD」指后台运行的整个应用，使用「WebUI」指浏览器中的操作界面。启动程序、打开 WebUI 和开启视频加速是三个不同动作。关闭网页不会等同于退出程序；打开或刷新网页不会重新触发启动时的自动加速。条款未确认时关闭页面的退出规则仍以[配置生命周期](settings-lifecycle.md)和[使用说明](console.md)为准。

「终端」「命令行」只用于实际的命令行操作及参数；只有明确指 Windows console 窗口时才称「控制台窗口」。产品界面不再用泛指的「控制台」。内部 `console` 包、类型、命令入口、协议标识、日志事件及历史文件名保持不变；历史报告保留当时文案。

| 场景 | 统一文案及含义 |
| --- | --- |
| 托盘打开入口 | 打开 WebUI |
| 常规设置分组 | 程序启动 |
| 启动选项 | 启动程序时自动打开 WebUI／启动程序时自动开启视频加速 |
| 网页首次读取状态 | 后台程序：连接中；正文首次读取显示「正在读取程序状态…」 |
| 状态读取成功 | 后台程序：已连接；只表示网页最近成功读取后台状态，不表示游戏已接入、加速已开启或播放成功 |
| 收到退出／重启回执或后台生命周期通知，停止读取状态 | 后台程序：未连接；覆盖托盘和其他 WebUI 发起的操作，使用中性色，不另设退出／重启中的状态文案 |
| 状态读取失败 | 没有已有状态时显示「后台程序：读取失败」；已有状态时显示「后台程序：更新失败」。详情提示无法读取程序状态并说明保留上次状态；不据此断言程序已退出 |
| 游戏连接 | 游戏连接：已接入表示连接配置就绪；接入失败／接入冲突为红色，映射仍保留但授权、回滚或退出恢复需处理时为黄色“需检查”；游戏请求与播放结果另行展示 |
| 视频服务运行 | 视频服务：运行中；表示本地服务正在运行 |
| 房间队列预加载 | 房间队列：监控中／已关闭／未就绪／需检查／启动失败；目录可读取且监控已启动即为绿色“监控中”，没有日志、没有当天日志或等待新同步不算异常；读取或处理异常为黄色，启动失败为红色；不表示已有块需求或视频已下载完成 |
| 视频需求状态展示 | 状态展示：读取中／更新中／重连中／待启动；分别表示正在读取或连接、观测流正常、连接异常重试、视频引擎尚未启动或已停止。“更新中”不表示游戏接入、队列日志读取或播放成功；没有需求时仍可正常更新 |
| 视频需求自动暂停 | 状态展示：已暂停；表示当前停止观测与展示更新，不表示后台下载已暂停 |
| 主导航的无障碍名称 | 页面导航；展开／收起按钮使用同一名称 |

后台程序、游戏连接、视频服务、房间队列及视频需求状态展示共用 StatusBadge 的尺寸、图标和颜色规则：绿色正常、红色故障、黄色待处理、主题色处理中、中性灰未启用或待确认；文案与图标始终可见。前四者使用“名称：状态”，视频需求使用“状态展示：状态”，具体文案与含义以上表为准，仅映射已有状态，不新增状态或改变判断逻辑。状态接口读取失败或程序正在退出／重启时，游戏连接、视频服务和房间队列显示“待确认”，不继续用绿色标记旧快照；需求事件流按自身连接与可见性展示状态。操作失败由操作反馈报告，不改变仍然正常的后台连接状态；后台存储故障和读取失败保留详情入口。

首页组件异常直接归属对应状态：UAC、hosts 校验、回滚与恢复权限问题归“游戏连接”；监听端口不可用及网关故障归“视频服务”；VRChat 日志目录、读取和队列处理问题归“房间队列”。普通原因通过标准 Tooltip 在悬停或键盘聚焦时显示，支持 Escape 关闭；无故障的游戏连接继续说明配置连接可能需要授权。已有正确 SWD 映射但缺少恢复权限时，黄色状态使用可交互 Popover，短句为“尚未取得恢复权限，停止或退出时无法恢复直连。”，蓝色文字“修复”仅准备恢复权限；悬停、点击及键盘均可操作，取消或失败后保留提示，不妨碍加速、不由开始加速重试 UAC。房间队列正常时同样提供详情：尚无日志时说明等待游戏生成日志；找到日志后显示当前文件名，以及等待新同步或当前队列数量；停止时说明监控未运行。状态待确认时只说明当前无法确认，不把旧故障当成当前原因。最近请求行仅展示请求结果并链接历史，不再附加“需要检查连接”和通用错误详情；历史请求失败不改变当前组件状态。具体错误来源与重试清理遵循[配置生命周期](settings-lifecycle.md)。

首页上游卡片与加速操作卡片宽屏等高并排，空间不足时上下排列。普通卡片标题显示「上游：直连／SOCKS5／Mihomo」；点击「上游」进入网络页的连通性检测，点击当前连接方式进入网络设置，两处链接保持标题颜色。右上角刷新按钮复用曲库和历史的图标与动画，启动与网络页相同的完整检测；自动或手动检测期间图标旋转并禁用重复触发，减少动态效果时保持静止。卡片使用当前生效的上游与该检测的共享结果，以相同 StatusBadge 样式展示歌曲列表、播放地址、视频下载的最新实际观测；多来源时选最近一次实际观测，有延迟时只显示数字，检测中不附带旧延迟，没有延迟时显示「—」。徽章自然排列，空间不足时换行。最底行显示三个项目中已有观测的最早时间，没有观测时显示「—」，悬停或聚焦时说明含义。悬停或键盘聚焦在各徽章旁显示该观测时间及连接失败状态，未检测时显示「尚未检测」；本轮未检测时提示上次观测时间，以中性色展示历史结果。点击或按键重测对应项目；检测期间禁用重复触发，连接断开时状态显示待确认，不插入状态提示框。手动操作失败通过不占布局的通知反馈，重连不会清除未确认提示；其他项目保留原结果和时间。检测过程与调度见[上游检测与测速](upstream-channels.md#上游检测与测速)。

页头只展示后台程序状态，与“退出程序”相邻排列；加速总状态、游戏连接、视频服务和房间队列集中在首页“加速”，房间队列状态紧接视频服务状态；事件连接／自动暂停状态位于“视频需求”标题行。队列内容作为需求来源展示，不再提供独立队列表格或日志读取详情；配置与日志目录仍在“设置 → 下载与缓存”管理。历史、曲库、网络、设置和关于的标题旁不重复展示加速状态。“退出程序”点击即提交退出，不再二次确认；停止服务和游戏接入处理说明由 Fluent Tooltip 在悬停或键盘聚焦时显示。

Windows UAC 说明使用 Fluent v9 Tooltip，位于“游戏连接”状态、自动加速和退出恢复选项，以及相关保存／重启按钮；加速图标按钮仅提示当前动作，组件与样式见[首页加速状态与按钮](fluent-ui-migration.md#首页加速状态与按钮)。“同意完整条款”不添加 UAC 悬停提示。退出恢复选项明确授权发生在开启并保存时；保存按钮仅在本次由关闭改为开启时提示，重启按钮仅在已保存自动加速时提示。复选框的小方框和文字标签均支持悬停，提示同时支持键盘聚焦、Escape 关闭及无障碍描述；只显示说明，不发起操作。

## 内容与交互

视频导入在同一面板显示当前批次的来源、目标、进度及暂停／继续操作。已有批次时锁定来源，结束或放弃需说明会移除恢复记录、保留源文件与已导入视频。重启不自动继续；清理仍需单独勾选与确认。具体规则见[视频导入与恢复](video-import.md)。

空间预估紧跟“外部目录”标签，未选择、检测中、同卷、跨卷和待确认状态原位更新，不另占一行；宽度不足时自然换行。提示与标签保持独立，输入框的无障碍名称仍为“外部目录”，操作提示不打开目录选择器。整条提示支持悬停和键盘聚焦，通过标准 Tooltip 解释共享内容或复制的原因，Escape 关闭；“请勿修改源视频”保持直接可见。预估依据与边界以[视频导入](video-import.md)为准。

临时状态、进度和辅助提示出现、更新或消失时，应尽量保持主操作及已有内容的位置稳定，避免通过临时插入或移除整行信息推动下方布局。优先更新已有标题、状态区，或按信息用途使用不占页面排版空间的标准 Tooltip、Popover、Toast。需要处理的错误、表单校验和重要结果仍须清晰可见，不为维持位置而隐藏、截断必要信息或预留大块空白。验证动态界面时检查信息出现、更新、消失前后的布局，并覆盖相关窄屏场景。

功能页面和文档统一从左侧导航访问。`207e431` 为历史迁移文案基准，现行体验修订见下文；存储术语按 2026-10-19 确认的[术语与命名](download-resource-design.md#术语与命名)统一；组件迁移本身不改变内容，2026-10-21 已授权的体验修订统一调整文案和层级。组件选择和业务保留边界见 [Fluent UI](fluent-ui-migration.md)。

侧栏提供加速、历史、曲库、网络、设置、关于六个入口。默认打开加速；未同意条款时自动弹出完整条款，成功确认后显示正常页面。功能页面与文档共用 Hash 路由和持续挂载的应用外壳；侧栏及文档内的站内链接使用同一地址规则，往返文档保留表单草稿和选择。文档正文直接使用启动数据，不等待状态接口；帮助中的数据库文件和完整视频目录以当前生效配置为准。原 `/help`、`/about`、`/terms` 可直接打开，已同意时在当前文档内规范为对应的 `/#/…` 地址，不增加重定向请求；未同意时帮助、关于仍独立可读，条款入口继续打开确认流程。导航使用 Fluent NavDrawer/NavItem/Hamburger，桌面默认展开、可收起，窄屏保持抽屉交互。

存储设置在位置选择后询问“是否保留下载的视频”，提供“不保留 / 限制为 / 不限制”单选（默认“不保留”）与“视频存储预算（GiB）”。不保留时直接说明普通视频不长期保存；下方收藏保留选项保持原勾选值但禁用并置灰，切回保留模式恢复可操作。位置设置分别称“数据库文件”和“完整视频目录”，完整视频在“曲库 → 按资源”管理，队列提前准备称“房间队列预加载”。请求 HIT 展示为“本地视频命中”，仅表示完整本地视频命中，不将运行期块复用混入该统计。

“激进的缓存回收策略”仅在设置的下载与缓存标签提供“自动（默认）／开启／关闭”单选，简短说明减少占用与重复下载的取舍。自动状态同时展示当前结果，随存储页已保存的“不保留／限制为／不限制”设置更新；手动选择保留。补充说明关闭后仍受视频存储预算约束，“不保留”下所有资源仅复用本次运行内的视频块缓存，收藏保留不生效。新配置默认 auto，切换预算保留所选策略。

存储设置先展示数据库文件和完整视频目录，再展示保留方式和预算，不重复展示当前生效路径。下载与缓存设置展示临时视频缓存目录、回收策略和本地延续保护时长。选择“不保留”仍允许选择位置。界面说明数据库优先备份、临时缓存不计入视频预算，以及保存后重启。选择位置或恢复默认后即使有冲突也保留草稿，在相关字段显示警告并禁用保存；调整位置后复查整组草稿，合法时清除警告，保存时后端再次检查。接入已有视频时在保存前确认其保留策略。切换不重置其他路径、不自动搬迁数据；缓存盘不可用时提示检查或更换位置并重启。回收策略和延续保护时长直接可见，不再放入高级折叠。

所有路径框只读显示路径，点击文本框或聚焦后按 Enter／空格直接打开 Windows 文件或目录选择器，旁边仅保留“恢复默认”。设置及相关导入预览、确认中的默认数据库和完整视频位置相对配置文件目录显示，默认临时视频缓存位置相对程序目录显示，并显式带上 `.\` 前缀（如 `.\work`）；自选的其他位置保持原路径。此显示规则不改变保存、选择器和实际文件访问的路径。默认路径使用主题次级灰色，自选路径使用正文色；数据库／视频按是否为默认位置判断，日志／VRCX 按是否启用手动选择判断，不新增持久化的颜色或来源字段。数据库在同一个系统窗口中选择已有文件或输入新文件名建库。日志目录选择后进入手动模式，恢复默认回到自动识别；视频导入没有固定默认来源，恢复默认清空所选来源；VRCX 恢复默认同时撤销旧预览。选择期间禁用关联保存／导入操作，取消保留原草稿，失败明确提示并允许重试。系统对话框使用 SWD 图标，生效边界统一见[路径选择契约](settings-lifecycle.md)。

曲库和历史共用紧凑 Fluent Table、排序表头和底部分页栏，每例一行展示；保留组件默认行高、单元格间距、排序箭头、aria-sort 与键盘交互，主次文字复用 TableCellLayout。列宽由浏览器按内容自动分配，短字段和行内操作保持单行；歌曲／资源列承接剩余空间并限制长内容，完整信息仍可在详情中查看。历史来源比例在同一单元格内紧凑并排，空间不足时换行；窄屏只在表格区域横向滚动，不缩小控件或截断状态文案。表头补充说明直接通过文字上的 Fluent Tooltip 展示，不放提示图标或为其预留列宽；悬停、键盘聚焦均可查看，Escape 关闭，可排序列复用排序按钮的焦点。分页栏左侧报告当前页及已知数量，右侧为上一页／下一页，只有一页时仍显示并禁用不可用按钮；曲库保留偏移量分页，历史保留游标分页。补充资料通过非模态 Popover 查看，短说明使用 Tooltip。曲库概览只展示占用、覆盖率与预算，版本提示、设置入口及导入／下载按钮的位置遵循[曲库概览与操作](webui-design.md#曲库概览与操作)。

曲库概览的刷新入口、最后检查时间和按需读取规则统一见[曲库读取与刷新](webui-design.md#曲库读取与刷新)；本地视频与曲库覆盖率使用标题后的 Fluent 小图标按钮，不再提供独立的大文字刷新按钮。

VRCX 建议在曲库以轻量 MessageBar 提供「导入历史 / 忽略」，只检查默认文件存在性后显示，不自动读取源库细节。空库建议跨重启保留，直到首次写入歌曲需求统计或用户明确忽略；忽略选择持久保存，资格随现有状态刷新更新。首次自动建库在其他页面检测到时，右下角普通 Toast 提供「前往曲库」链接；仅导航，不触发读取，进入曲库后撤去通知；不自动超时，等待用户点击链接或关闭，关闭／同标签页刷新／重启不重复弹出。用户点击导入后才读取，空统计直接导入，已有统计沿用预览与覆盖确认；具体触发与生命周期以[历史初始化契约](song-catalog-design.md#vrcx-历史初始化)为准。不增加引导或自动弹出的模态确认，导入成功使用本页 Toast。

首次运行期间的本地视频导入建议复用右下角普通 Toast，仅在同意条款后显示，不占正文位置。不自动超时消失，等待用户处理。首次运行按启动时配置文件不存在判断；还须当前 hosts 的 `api.udon.dance` 映射为 `127.0.0.1`、没有 SWD 托管标记且无冲突。其他域名、注释、冲突或读取失败不触发。文案为「已有本地视频？可以导入 SWD 复用，减少重复下载。原视频会保留，同一分区无需重复存储。」，不推测其他程序或宣传体验优劣。「前往导入」只定位曲库现有视频导入区域；它与「不再提示」、右上角关闭按钮均关闭本次运行的建议，多标签页共用，刷新不恢复。配置已在首次启动创建，后续启动不再提示，不额外保存界面字段；未处理就退出也不在下一次启动重复。提示不修改 hosts、不申请 UAC、不自动选择目录或开始导入。

曲库歌曲以“热度”展示需求分数，统一按内部值乘 100 显示，最多 2 位小数、最多 4 位有效数字；小于 100 时保留 2 位小数，较大数值按四位有效数字收缩小数位，例如 37.56、100.0、123.5、1,235。使用标准 Intl 数字格式，不封顶为 100，也不把显示舍入值用于排序。没有真实需求记录的初始分数使用 Fluent 次级灰色；真实分数使用正文色，浅色主题为黑色，深色主题随主题适配。表格单元格的无障碍名称及歌曲详情同时标明“真实分数／初始分数”。

“按歌曲”默认按热度排序：先按是否有真实需求记录分组，真实分数全部在初始分数前面，再在组内按未舍入分数降序、同分按歌曲 ID 降序；在后端全体结果中排序后分页。来源由现有需求次数是否大于零决定，真实分数衰减至很小或零也不变成初始来源。资源视图默认沿用分数排序。歌曲 ID、名称、热度、资源指纹和大小通过标准表头切换升降序；分数升序也保留真实记录在前的分组，未知大小始终放在最后。资源切换排序后可恢复默认分数排序。搜索保留当前排序，切换视图恢复默认排序；排序变化回到第一页。这一歌曲列表展示规则不改变下载补齐、视频保留的数值评分及共享资源汇总。

“曲库 → 按歌曲”依次展示 ID、名称、歌手、舞者/社团、热度、偏好、本地状态、操作。偏好使用 Fluent ToggleButton：红心表示收藏，屏蔽图标使用主题正文色（浅色为黑色）；收藏选中使用实心红心；屏蔽未选中使用 Fluent 空心圆圈图标，选中使用标准圆圈斜线图标，屏蔽按钮使用 transparent 外观，选中不产生底色，保留组件焦点提示。高对比度模式使用组件系统色。两者互斥，再次点击已选项回到普通，允许都不选。图标保留稳定无障碍名称、aria-pressed 和操作提示；预览、下载同样使用带 Tooltip 的图标按钮。支持本地查找和筛选。收藏标记与完整文件存在状态分开展示，明确标记不开始下载；屏蔽只影响新请求和新准备。零预算下保留手动补齐入口。详情中的共享资源和临时块说明遵循[业务设计](download-resource-design.md#8-歌曲屏蔽与收藏)，不在需求或块调度界面新增偏好操作。

下载与缓存设置在回收策略旁提供“本地延续保护时长（秒）”，使用标准数值输入，默认 300，范围 0～10000 的整数。说明最后一份需求结束后的保留用途、0 表示不延续保护，以及较长时长可能增加空间占用。运行语义以[本地保护](download-resource-design.md#本地保护)为准。

侧栏名称与页面主标题一致。取消独立运行状态页，其内容分别归属下载和网络；旧监控地址进入网络页，明确的下载／队列／参数锚点进入对应任务页并展开目标。完整操作只出现在所属页面，其他入口以摘要和链接连接。同一份存储、下载、网络字段仍由共用组件渲染。

各配置位置只保存本处草稿，将其合并到最新已保存配置，不提交其他位置的草稿。所有位置等待保存后的新状态再解锁；任何位置尚有草稿时禁用重启，提示先保存或放弃。退出策略保存即用于本次退出；其他运行配置保持重启生效，启动配置生效规则见配置生命周期。

首页加速卡片采用紧凑行间距，标题与开始／停止按钮保持同一行优先排列。同一个图标按钮随运行状态切换开始与停止动作；悬停或键盘聚焦仅显示“开始加速”或“停止加速”，无障碍名称与动作一致。未运行标题及按钮配色统一见[首页加速状态与按钮](fluent-ui-migration.md#首页加速状态与按钮)。仅在加速运行、游戏接入就绪且状态可确认时，于标题右侧显示小字“可关闭浏览器，减少资源占用”，不占用独立一行；卡片内容宽度不足 30rem 时隐藏这条辅助提示，避免挤动主按钮。未运行、操作中或状态待确认时不显示。加速标题下不按状态插入说明段落；启停进度由标题和状态徽标表达，标题变化保留无障碍播报，停止后的接入策略在「设置 → 常规 → 停止与退出」查看。不常驻展示尚未检测、等待请求、已收到或检测停止等提示，也不提供独立的“检查连接”“查看接入诊断”链接和游戏接入说明图标。异常原因在对应状态的悬停或聚焦提示中查看；「视频服务」提示始终提供 HTTP 80／HTTPS 443 的监听、转发或可用性，端口占用时保留进程信息，状态待确认时只显示无法确认的原因。恢复权限直接在游戏连接状态中修复，日志目录在设置页处理。网络页不再提供接入诊断、重新检测视频请求按钮或请求观测时间。自动与手动一键加速共用请求检测窗口，hosts 与网关均就绪后才开始等待请求。历史请求结果单独呈现。高级接入、帮助及条款均不提供独立网关启停、队列启停或 hosts 恢复操作；退出恢复是配置，结束运行使用退出程序。

技术数据在紧凑表格中扫读，补充明细通过标准 Popover 查看，不改变下载、检测、存储或保护规则。当前文件摘要独立于搜索/分页；请求次数不等于播放次数，历史按独立请求展示，交付比例不代表播放进度；网络成功样本不保证每首歌曲可播放。只保留帮助判断的短说明；永久删除等重要后果在操作确认时明确展示。

页面标题下不复述导航或功能清单。读取状态在所属区域显示一次；测速未开始时不叠加空样本提示，无历史批量任务时不显示空详情入口。设置操作区使用简短的未保存／同步中／待重启／已生效状态，重启中断等后果由原确认流程说明。曲库文件操作完成且无异常时使用 Toast；有跳过或失败项时，在列表前显示唯一的 MessageBar 与结果表，并将焦点移到结果区，保留原因供核对。

首页「视频需求」以常驻 Canvas 需求视图替代原当前 GET、下载和房间队列表格，不再轮询 `/api/downloads`。等待下载、正在下载、本地可用、延续保护的计数随图例仅在时间轴展开时展示，按唯一块统计，不重复累加共享需求；有正在结束的块时补充该状态。每行在标题后显示整数百分比，以本地可用块数／当前需求块数向下取整表示粗略就绪进度；只有全部就绪时显示 100%，不再显示进度条。该比例不表示播放进度或完整视频校验进度。图例仅在时间轴展开时显示；来源、视频内位置、配色和块详情沿用已有规则。原列表的额外字段不逐项迁入。

面板标题后紧接“状态展示”徽章，再依次显示总下载速度、“缓存”、块缓存大小、块任务与下载统计，尽量排在同一行；块任务与下载统计靠右排列，空间不足时按此顺序自然换行并保持右对齐，末端为 Fluent 图标按钮；悬浮或键盘聚焦显示「展开／收起时间轴视图」，保留可访问名称与展开状态。展开时间轴且有块时显示状态图例，有块或需求行时显示「需求视图」标题与需求数，窄屏自然换行；收起时隐藏这两行，需求列表继续显示与更新，不显示排序／空档说明。时间轴默认收起，展开后位于需求视图上方；收起停止时间轴排序和绘制，保留需求视图的共用 SSE。页面可见且面板处于视野时订阅；切页、标签隐藏、整个面板滚出视野后断开订阅并停止动画，恢复时重新取得完整状态。主时间轴单独滚出视野时停止其动画及事件重绘，需求视图继续更新；滚回后按最新状态和时间恢复绘制。缩放、跟随现在和「分层显示」开关仅在时间轴展开且存在有期限块时显示；「时间轴视图」标题位于延续／提前窗口标记前，与开关尽量同排。画布上下留白及需求行高度保持紧凑，保留读取急需标记、选中边框与刻度文字所需空间。时间轴移除横向滑条和操作说明文字，继续支持滚轮、拖动及键盘。

标题行统计格式为“块任务 已占用 / 容量 | 下载 执行中 / 并发软上限”。块任务按当前需求占用的唯一视频块统计；下载统计含收尾中的执行，分母取当前生效配置的“同时下载数量”（默认 16），不使用动态开放额度，也不读取尚未生效的已保存值。首次读取、视频处理未运行或程序退出后，当前计数显示“—”，分母保留已知容量及当前生效配置；暂停展示或连接重试时保留最后有效计数。统计文字上的 Tooltip 说明计数口径及播放急需时可能超出普通并发软上限。

总下载速度只显示数值与单位，默认 MiB/s，保留两位小数；点击或按 Enter／Space 在 MiB/s 与 Mbps 之间切换，两者均保留两位小数。MiB/s 由字节速率除以 2²⁰，Mbps 由字节速率乘以 8 再除以 10⁶；Tooltip 说明下一次切换的单位，无障碍名称包含当前数值和单位。单位选择按本次 SWD 运行保留，切页、刷新和在同一浏览器重新打开 WebUI 后保持，并在已打开的页面间同步；重启 SWD 后恢复 MiB/s，不写程序配置。浏览器存储只记录与当前进程标识匹配的 Mbps 选择，不延续到下一次运行；存储不可用时保留当前页面内的选择。总下载速度复用网络读取计数，由同一 SSE 连接的独立 `download-speed` 事件更新，约每秒采样一次，以实际采样时长内的字节增量计算；速度事件不重建块快照、不重新计算块差分、不触发需求 Canvas 绘制。短任务退出仍计入已经收到的字节；无新字节的下一次采样将速度归零并停止计时，新字节再唤醒。无订阅时不保留速度观察任务。自动暂停展示时保留最后数值，恢复订阅后使用新观测；不提供手动暂停复选框。后台状态和最近请求摘要保持各自已有刷新机制。

下载速度旁显示“缓存”，表示临时视频块文件总大小，不足 1 GiB 使用 MiB，否则使用 GiB；未取得计量、引擎结束或应用进入退出／重启流程时显示“—”，确认无块文件才显示零。计量口径以[本地资源管理](download-resource-design.md#6-本地资源管理接口与所有权)为准，悬停或键盘聚焦时通过 Fluent Tooltip 说明临时块，不增加缓存容量预算或进度条。缓存大小由同一 SSE 的独立 `block-cache` 事件更新，不触发需求 Canvas 绘制；隐藏暂停和连接中断保留最后数值，由既有状态说明展示暂停／重连，恢复后接受最新总量。

暂时不可见或连接中断只隐藏固定详情并释放详情订阅，保留固定选择；恢复连接并收到完整状态、确认块仍存在后再显示详情。工具栏操作不取消固定，关闭按钮和 Escape 仍可主动关闭。仅悬浮的详情不自动恢复。块退出最新状态或主动关闭详情会清除选择；收起时间轴只清除从时间轴选中的块，保留需求行的选择；不会为最新状态中已移除的块重新请求详情。保留选择不延长核心观测、文件保护或历史记录的生命周期。

有期限的块按 need-by 映射到连续时间轴，允许覆盖；现在指针在跟随模式默认位于绘图区中央，左右分别标示下载延续和提前窗口。时间轴的层间距、无期限区和总高度按固定块尺寸计算，绘制、命中与键盘定位使用同一布局；「现在」时间放在底部刻度带，标签外框按实际文字尺寸与主题小间距收紧，并依据可见字形边界居中；省略与其重叠的刻度文字，刻度标签按实际文字宽度保留间隔，避免随主题字号变化产生相邻重叠或超出画布。块始终是正方形，边长固定为 16 个 CSS 像素，选值与当前卡片标题字号相当，不随字号动态改变，不提供大小调节；放大时间轴可减少覆盖，时间完全相同的块仍保持真实位置，通过浮层切换，不为防重叠挪动时间坐标。重叠时，定位时间较小的块在上层；相同时按块标识保持稳定顺序，选中不改变层叠顺序。有期限区域可切换单层或三层，上到下为待下载、下载中（含正在结束）、本地；三层行距取读取圆点不进入上一行外框的最小整像素值，按方块尺寸、选中外框外扩量、圆点上移量及半径共同计算；当前 16px 方块对应 32px 行距、16px 净间隙，层名移到左侧独立标签列并与各层同行，保留读取圆点与选中边框空间；绘制、缩放平移及命中共用标签列之外的绘图区范围，层名称背景透明。无期限区域始终单行显示，不受分层开关影响；上方统一显示“无期限 · N 块”，按资源及块号排序，保留单行的左右边距和横向平移位置，不制造时间值。

只有无期限块时，仅显示紧凑的无期限行，隐藏空时间网格及分层、缩放和跟随控件；完全没有块且没有需求行时，仅保留一条“当前没有使用需求。”，隐藏零值图例和视图标题。用户选择的展开、分层和时间范围保留，数据恢复时自动显示对应区域。实时更新隐藏或移除当前焦点控件时，焦点回到所属区域；不抢走区域外控件的焦点。

无期限块的间距按可用宽度和块数动态收紧：空间充足时方块之间预留 6px，逐步压缩到最多覆盖半个方块；当前 16px 方块对应 8–22px 的左边缘间距。达到重叠上限后保留单行横向平移，通过拖动、横向滚轮、Shift＋滚轮及键盘选块查看其余内容；不显示滑条，也不为滑条预留高度。绘制、命中、平移边界和键盘定位共用这套间距；重叠时按资源及块号较早的块在上层，浮层可切换同一位置的其他块。没有命中块的区间返回空集合，空白处不显示重叠详情或建立详情订阅。

同一歌曲使用稳定配色，没有歌曲标识时按视频资源标识配色。视频仍在视图中时沿用首次分配的颜色，需求来源变化、歌曲标识补齐或断线重连不重新配色。颜色表示视频归属，状态使用空心、斜纹、实心；每块带略深于主色的细描边，区分同色重叠边界，不使用模糊阴影。需求结束后的本地延续保护保留视频配色，以 35% 不透明度绘制填充和边框，取代早期灰色表示。选中轮廓与读取急需标记保持清晰，读取急需另加边框与圆点。时间窗口颜色带只是参照，真正下载资格在属性中说明；本地可用不等于完整视频已校验发布。详情同时显示视频标题（无标题时歌曲／资源标识）及视频内编号 `13/45`，表示从 1 开始的第 13 块、完整视频共 45 块；总数未知时显示 `13/?`。时间轴选中标注和键盘选择使用同一编号，底层块索引和字节范围仍从 0 开始。

需求视图随需求数量自然增高，由页面统一滚动，不设置内部高度上限或滚动条；只为进入视口的需求行分配和绘制 Canvas，离开视口后释放绘图缓冲，行标题与列表语义保持完整。每个矩形对应一个来源对一个视频的需求；按读取（GET）、短期交接、队列位置 #1/#2…、手动下载排列；GET 来源在需求行及其可访问名称中显示为“读取 #编号”，保留现有分类和编号。同一歌曲的矩形边框同色，交接矩形外框固定白色，内部块及时间轴继续保留视频原色（forced-colors 仍由系统颜色优先）。交接标题复用观测期间已有的歌曲信息，首次打开时可从本地歌曲资料补齐。内部以完整视频总块数建立等距位置，方块放在其原始块号对应的位置，无需求的前缀、中间区间和尾部留空；需求撤销不让剩余块左移。同一视频的不同需求行共用相同位置规则。方块保持固定大小，位置随矩形宽度缩放，首尾方块保留内边距且完整可见，不设行内横向滑条；块间距不足时允许重叠，视频内位置较早的块在上层，选中不改变层叠顺序。总块数未知时暂按该行观测到的最大块号缩放，仍明确标注总数未知，待总数补齐后更新位置。悬浮或键盘查看同一套详情，空档不产生详情请求；重叠处先命中上层块，并可通过共用浮层切换被覆盖的块。相同块可以出现在多项需求中，容量仍按唯一块计算。只为可见需求行绘制 Canvas，复用时间轴 SSE 和单一选中块详情订阅；不为每行或每块建立订阅。

需求行的测量与绘制在浏览器显示前完成，标题、外框和块同时按实际宽度出现；列表缩短时同步修正滚动范围，避免先显示空白再补齐。列表与画布尺寸不做过渡，减少动态效果模式也遵守同一规则。需求内容仍随事件及时更新，不延迟真实的新增、撤销或状态变化。获得键盘焦点的需求行被移除、焦点落到 body 时，将焦点恢复到需求视图区域；下一次 Tab 可继续进入剩余行，不抢走区域外控件的焦点。

纵向滚轮围绕视图中心缩放时间范围，保持原有跟随／固定状态；按钮与键盘加减缩放采用相同规则。横向滚轮（或 Shift + 滚轮）左右平移，不改变时间缩放或跟随／固定状态；跟随时保留相对现在的时间偏移，时间继续移动。在有期限区域按住拖动时切为固定，“回到现在”恢复跟随并清除偏移、重新居中。在无期限区域拖动或使用横向滚轮（或 Shift + 滚轮）只平移该行块列表，保持有期限时间轴的中心、缩放及跟随状态，键盘选块继续自动定位，不为无期限块制造时间值。悬浮查看属性及当前来源，点击固定详情；被覆盖的块通过浮层切换按钮逐个选择。两个视图的未固定详情均随鼠标进入、退出重叠区同步完整命中集合，默认选择最上层块；集合不变时保持浮层稳定，已固定的详情不随悬浮移动改变。所选块上方显示时间性质与对应时间；need-by、下载截止、本地保护、读取者和来源详情保留准确语义。保护期块的历史定位规则以[按需块观测](block-scheduler-design.md#按需块观测2026-10-20)为准。

本地存储故障通过 WebUI 公共后台状态及详情显示，切页仍保留首个原因、影响和恢复步骤；生命周期以[配置与运行约定](settings-lifecycle.md)为准，不依赖请求明细中的 HTTP 状态码解释故障。

业务页面保留草稿及选择；普通导航（包括帮助、关于和历史前进／后退）回到页面顶部，明确的定位链接才滚到对应区域并移动焦点，旧锚点继续可用。操作反馈说明具体动作，只属于发起操作的页面，离开后清除；迟到的响应不把反馈带到新页面。连接中断、本地存储故障等全局状态仍持续展示。设置以实际差异判断未保存状态，放弃更改恢复已保存值；保存成功后等新状态同步再解锁。真实游戏和系统集成仍见[待验收台账](live-acceptance-backlog.md)。

未同意条款时自动显示 Fluent 模态条款弹窗，提供完整正文、纯文本和帮助链接，以及“同意完整条款”“不同意并退出”。条款读取或保存失败显示原因并允许重试；失败不开放业务接口，成功后关闭弹窗，按启动设置运行。Escape 和遮罩不关闭门禁；没有四步引导、独立草稿或最终统一应用。

条款弹窗在窄屏内限制最大高度并允许滚动，正文可聚焦阅读，键盘焦点保持在弹窗内。同意成功后焦点返回应用内容；已同意用户可在“关于 → 用户协议”再次阅读。

设置表单顶部的操作栏滚动时固定显示状态、保存、放弃与重启按钮；无需重启时按钮禁用。字段直接可见，原生校验定位无效输入。各配置位置只呈现所属字段，补充技术说明按需提供。“同时下载数量”“提前准备时间（秒）”使用任务语言，技术边界保留在提示中。

帮助按开始使用、播放失败、空间不足与视频保留、停止与卸载、日志与当前路径组织，直接展示各节步骤，不提供顶部重复导航、章节目录或底部返回首页链接。应用内不重复显示“帮助”标题，独立帮助页保留主标题。开始使用合并开启加速与游戏点歌步骤；“视频需求”链接直接定位首页对应区域。现有章节锚点及帮助内容在状态接口不可用时仍可访问。发行许可、重新分发和对应源码说明集中在“许可证与声明”。

下载速度测试默认展示单连接／多连接速度与可用性，CF 接口、连接数及 CPU 分位值在技术详情中。准备样本失败时显示“可用测速样本不足，请检查曲库与连通性后重试。”，不要求本地视频或预算；到时未取得完整采样时提示测速未完成。结果按当前生效上游展示，失败或未完成也显示本次测试时间；保留旧速度时另标其结果时间。

批量任务分别呈现本地检查进度、上次完成记录和在线曲库更新结果；使用已有清单时明确标注，原始在线错误收进详情。“重试更新”复用缺失检查入口，更新曲库并检查本地文件，不下载视频。没有可用清单时明确未开始本地检查，不把在线错误混入逐曲失败数量。

视频导入离线读取所有已知资源，按完整文件 MD5 匹配，无需清单水位或歌曲映射；文件错误和失败数量单独显示。资源表为空时明确未开始导入并提示更新曲库。覆盖率只统计当前清单成员，常态仅显示百分比；已覆盖与总数放入标题提示，缺映射等说明使用数值旁的小感叹号与 Tooltip，不增加说明行，交互规则见[曲库设计](webui-design.md#曲库)。没有有效完整清单时显示未知，预置映射不算完整清单。统计提示使用计算时的清单版本。具体范围见[本地快照规则](song-catalog-design.md#本地快照与当前成员)。

游戏接入停止／退出策略只在「设置 → 常规 → 停止与退出」中编辑，默认开启「停止加速或退出时恢复游戏直连」。“退出程序”按钮的 Tooltip 按 activeSettings 展示当前策略，保存成功后该退出选择同时更新到 activeSettings 并用于停止加速和本次退出，不等待重启；未保存的草稿不改变退出说明。已有托管接入尚未准备恢复权限时，可在首页游戏连接状态浮层点击「修复」；退出提示说明直接退出会保留接入，退出结果只确认请求已接受，不预报恢复成功。权限与异常边界以[hosts 契约](console.md#hosts)为准。

权限助手每次新授权成功并建立连接后，通过公共状态显示信息 Toast「可在退出后保留游戏接入」，说明关闭「停止加速或退出时恢复游戏直连」并保存，以及下次游戏前仍需启动 SWD。「打开退出设置」定位并聚焦该选项，只导航、不修改草稿。网页、托盘与自动加速共用这一触发来源；授权取消、失败和复用已有助手不触发。同一标签页刷新不重复提示，当前进程的新授权仍会提示；关闭网页期间已完成的授权在打开页面后显示一次。浏览器存储不可访问或读写失败时，仍显示通知并保持当前页面内去重，仅放弃刷新去重，不影响界面使用。该提示不替代操作结果或失败原因。

## 请求历史

首页最近请求摘要以“最近请求”文字作为历史页链接，空状态显示“最近请求：暂无记录”，不另设“请求历史”链接或悬停提示；有记录时继续显示结果、HTTP 状态与时间。

历史提供默认勾选的「隐藏相邻中断请求」，标签悬停或键盘聚焦显示说明，取消勾选可查看全部记录。选择仅在当前页面会话内有效；判定、分页和刷新边界统一见[历史查询范围](webui-design.md#历史查询范围)，不改变原始记录与统计。

历史支持按收到时间、请求时歌曲 ID 或资源指纹升降序排列；未知身份始终排在最后，同值按收到时间和事件 ID 同方向稳定排序。切换排序重置游标，从全体范围排序后读取第一页；表头保留键盘焦点。历史默认查最近 24 小时，可使用本机时区的日期时间字段筛选，或选择全部保留期；每页最多 50 条，游标可遍历超过 500 条的记录，页面不累计无限列表。最新页按数据库变更事件更新，具体订阅条件、恢复和合并规则见[历史查询范围](webui-design.md#历史查询范围)；移除“暂停请求刷新”和“刷新本页”，其他排序与后续页保持稳定。尚无结果时显示加载状态；后台刷新期间保留现有记录或空结果提示，已有结果的排序和翻页保持可用，响应成功后更新内容。筛选草稿随应用内导航保留，切换存储重置游标；翻页和重新查询将焦点送到结果区域，刷新时保持请求 ID 对应的展开状态。读取失败移除过期行并回退焦点，可通过“查询历史”重试；事件连接中断持续提示并自动重连。旧 #recent 锚点定位此页。

首正文分位数独立每 30 秒读取，提供显式刷新，不受历史日期范围和分页影响。Blocking、缓存／本地均同时展示 P50、P95 及样本数；无样本显示暂无数据，不用零值代替未知。不展示或推断采集覆盖时长。行内身份使用请求时已知歌曲 ID 和资源，当前关联不推断为历史身份；“请求歌曲”列以当前曲库名称为主、ID 为次，名称来源、缺失处理及完整名称入口遵循[历史身份与名称规则](webui-design.md#已有能力与共享资源展示)。正文交付未知时显示 —，错误正文不计入视频字节。完整业务口径见[请求监控](console.md#最近请求监控)。

曲库的歌曲资料和需求分数与资源状态分开呈现，共享文件只在资源映射中读取一次。未知大小／实测时长显示未知；运行期块进度即使达到 100% 也不代表完整文件已保存。历史歌曲／资源链接执行精确查询，不在当前范围内时明确说明并保留原身份。删除和定位共用已有文件快照、确认及保护机制；列表每页最多 50 项，文件状态与下载进度的读取规则统一见[曲库读取与刷新](webui-design.md#曲库读取与刷新)。单项与全量共用批量运行槽，结果标明本次范围，不建立追加待办集合。

设置和关于的标签选择写入 Hash 路由，刷新及前进／后退保留所属分类。VRCX 检测与导入共用应用内模型，返回曲库或切页后保持草稿及预览。资源详情的最近请求复用已有 GET 访问汇总。

常规主题提供跟随系统、浅色、深色，选择后单独自动保存到程序配置并立即应用于 Fluent 主题、图标、块需求画布及托盘，不需点击保存或重启，也不提交其他设置草稿；失败保持原主题并显示原因。多页面同步、默认值与系统跟随边界统一见[配置生命周期](settings-lifecycle.md)。「启动程序时自动打开 WebUI」默认开启，保存后下一次启动程序使用；故障触发、托盘主动打开及已有实例激活独立于此设置，网页内正常重启沿用 -no-open 复用原页面。启动失败的受限入口继续使用既有状态读取失败反馈及公开文档，并允许退出，不显示伪造的设置或改变现有错误文案。曲库视图通过 `#/library?view=songs|resources` 定位；#recent、存储／下载／网络区域锚点及 /help、/about、/terms 公开文档地址保留对应归属。

首页活动展示与订阅统一遵循上文“视频需求”的规则，原每 5 秒读取 `/api/downloads`、最多展示 50 个活动 GET 及独立队列日志状态的规则已被替代。请求身份及交付比例保留在请求历史中；网关的实际 80／443 状态在加速页「视频服务」的 Tooltip 展示。


网络页直接展示全部适用模块，连通性检测与下载速度测试常驻顶部；仅直连展示「当前连接」观测，两种代理均隐藏并停用这些观测。所有上游的自动／手动轻量检测共用当前生效访问方式，下载测速仅手动触发，没有检测上游选择器。Mihomo 在检测卡片下方显示原版代理面板，设置不再提供「打开代理面板」按钮，规则见 [Mihomo 与 zashboard](mihomo-dashboard.md#监测与界面)。网络配置草稿仅归设置页，「检测当前连接」只导航到检测区；往返保留编辑。检测卡片在宽屏并排，两项均显示最后测试时间；连通性逐行显示实际观测时间，初始化重试不刷新未检查行的时间。检测状态连接失败及操作未确认通过不占布局的通知反馈，连接中和应用关闭不额外插入提示框。表单沿用标准 Field、RadioGroup 与保存流程。

历史页的响应来源与首正文等待时间各自使用普通字号的一行摘要，窄屏自然换行；标题后提供与曲库同规格的刷新图标。历史与曲库共用刷新动画：读取期间图标持续旋转并标记忙碌，禁用重复提交但保留键盘焦点，完成或失败后停止；减少动态效果模式下保持静止，忙碌语义不变。所有补充说明通过文字上的 Tooltip 展示，不放提示图标；支持悬停、键盘聚焦与 Escape。响应来源同行显示下载／缓存／本地视频占比，不常驻“按块折算”或“累计”标签，累计折算字节在对应占比的提示中查看；首正文两组分位数同行显示，有效样本数在各组文字的提示中查看，“最近 72 小时”放在“首正文等待时间”的文字提示中。逐请求仍显示比例并在明细提供字节值。累计独立每 30 秒读取并可手动刷新，查询失败保留旧值与持续错误；无计入块显示空状态，未知保持未知。分类与计量统一见[设计口径](webui-design.md#响应字节来源统计)。

来源总览[现场汇总保留明细](storage.md#请求统计的计算方式)，标题为“响应来源”，提示用一句话说明保留范围。首正文仍显示最近 72 小时分组结果、样本数与空组状态，不展示覆盖不足提示。

历史时间筛选的“开始”“结束”标签分别位于对应固定宽度日期框左侧，与“查询历史／全部保留期”按钮同排并整体靠左，按钮与输入框底部对齐；窄屏按字段自然换行，短标签仍与各自日期框同行，日期错误由 Field 在对应输入框下方展示。查询仍包含开始时间、不包含结束时间。
