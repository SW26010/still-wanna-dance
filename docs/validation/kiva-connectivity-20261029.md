### 错误码与管理员定位信息

`503/1102` 表示一次响应的 HTTP 状态是 503、正文错误码是 Cloudflare 1102，不是两次独立错误。1102 表示 Worker 超出 CPU 时间或内存限制；`500/1101` 则是 HTTP 500 加 Worker 运行时异常。具体代码、依赖和资源原因需管理员查看 Worker 日志。[Cloudflare 1101](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1101/)、[Cloudflare 1102](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1102/)，2026-10-29 查阅。

两次 15 分钟窗口的 IPv4 请求共 159 次：10 次成功、148 次 500/1101、1 次 503/1102。后者占 1/159，约 0.63%；500/1101 占约 93.08%。IPv6 在握手前失败，没有 HTTP 状态，不能混入此分母。早期短时复现的 503 未取得正文，也不能直接计作 1102。
