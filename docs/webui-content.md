# WebUI 内容分类

## 程序与界面术语

用户文案和技术文档统一使用「程序／SWD」指后台运行的整个应用，使用「WebUI」指浏览器中的操作界面。启动程序、打开 WebUI 和开启视频加速是三个不同动作。关闭网页不会等同于退出程序；打开或刷新网页不会重新触发启动时的自动加速。条款未确认时关闭页面的退出规则仍以[配置生命周期](settings-lifecycle.md)和[使用说明](console.md)为准。

「终端」「命令行」只用于实际的命令行操作、参数及独立命令行服务；只有明确指 Windows console 窗口时才称「控制台窗口」。产品界面不再用泛指的「控制台」。内部 `console` 包、类型、命令入口、协议标识、日志事件及历史文件名保持不变；历史报告保留当时文案。

| 场景 | 统一文案及含义 |
| --- | --- |
| 托盘打开入口 | 打开 WebUI |
| 常规设置分组 | 程序启动 |
| 启动选项 | 启动程序时自动打开 WebUI／启动程序时自动开启视频加速 |
| 网页首次读取状态 | 后台程序：连接中；正文首次读取显示「正在读取程序状态…」 |
| 状态读取成功 | 后台程序：已连接；只表示网页最近成功读取后台状态，不表示游戏已接入、加速已开启或播放成功 |
| 收到退出／重启回执或后台生命周期通知，停止读取状态 | 后台程序：未连接；覆盖托盘和其他 WebUI 发起的操作，使用中性色，不另设退出／重启中的状态文案 |
| 状态读取失败 | 没有已有状态时显示「后台程序：读取失败」；已有状态时显示「后台程序：更新失败」。详情提示无法读取程序状态并说明保留上次状态；不据此断言程序已退出 |
| 游戏连接就绪 | 游戏连接：已接入；表示连接配置就绪，游戏请求与播放结果另行展示 |
| 视频服务运行 | 视频服务：运行中；表示本地服务正在运行 |
| 房间队列预加载 | 房间队列：监控中／已关闭／未就绪／需检查／启动失败；沿用队列实际运行、启用意图及错误状态，不表示已有块需求或视频已下载完成 |
| 块需求事件连接 | 事件已连接；只表示块需求观测流已连接，不表示游戏接入、队列日志读取或播放成功 |
| 块需求自动暂停 | 展示已暂停；表示当前停止观测与展示更新，不表示后台下载已暂停 |
| 文档返回主页 | 返回首页 |
| 主导航的无障碍名称 | 页面导航；展开／收起按钮使用同一名称 |

后台程序、游戏连接、视频服务、房间队列及块需求事件连接／自动暂停状态共用 StatusBadge 的尺寸、图标和颜色规则：绿色正常、红色故障、黄色待处理、主题色处理中、中性灰未启用或待确认；文案与图标始终可见。前四者使用“名称：状态”，块需求使用完整状态短句。状态接口读取失败或程序正在退出／重启时，游戏连接、视频服务和房间队列显示“待确认”，不继续用绿色标记旧快照；需求事件流按自身连接与可见性显示连接、重连、引擎未运行或自动暂停状态。操作失败由操作反馈报告，不改变仍然正常的后台连接状态；后台存储故障和读取失败保留详情入口。

页头只展示后台程序状态，与“退出程序”相邻排列；加速总状态、游戏连接、视频服务和房间队列集中在首页“加速”，房间队列状态紧接视频服务状态；事件连接／自动暂停状态位于“视频块需求”标题行。队列内容作为需求来源展示，不再提供独立队列表格或日志读取详情；配置与日志目录仍在“设置 → 预加载与下载”管理。历史、曲库、网络、设置和关于的标题旁不重复展示加速状态。“退出程序”点击即提交退出，不再二次确认；停止服务和游戏接入处理说明由 Fluent Tooltip 在悬停或键盘聚焦时显示。

可能请求管理员授权的入口使用 Fluent v9 Tooltip 说明 Windows UAC：加速与接入诊断按钮、“游戏连接”状态、自动加速和退出恢复选项，以及相关保存／重启按钮。“同意完整条款”不添加 UAC 悬停提示。退出恢复选项明确授权发生在开启并保存时，退出时不再请求；保存按钮仅在本次由关闭改为开启时提示，重启按钮仅在已保存自动加速时提示。复选框的小方框和文字标签均支持悬停，提示同时支持键盘聚焦、Escape 关闭及无障碍描述；只显示说明，不发起操作。

## 内容与交互

功能页面和文档统一从左侧导航访问。`207e431` 为历史迁移文案基准，现行体验修订见下文；存储术语按 2026-10-19 确认的[术语与命名](download-resource-design.md#术语与命名)统一；组件迁移本身不改变内容，2026-10-21 已授权的体验修订统一调整文案和层级。组件选择和业务保留边界见 [Fluent UI](fluent-ui-migration.md)。

侧栏提供加速、历史、曲库、网络、设置、关于六个入口。默认打开加速；未同意条款时自动弹出完整条款，成功确认后显示正常页面。功能页面与文档共用 Hash 路由和持续挂载的应用外壳；侧栏、页脚及文档内的站内链接使用同一地址规则，往返文档保留表单草稿和选择。文档正文直接使用启动数据，不等待状态接口；帮助中的数据库文件和完整视频目录以当前生效配置为准。原 `/help`、`/about`、`/terms` 可直接打开，已同意时在当前文档内规范为对应的 `/#/…` 地址，不增加重定向请求；未同意时帮助、关于仍独立可读，条款入口继续打开确认流程。导航使用 Fluent NavDrawer/NavItem/Hamburger，桌面默认展开、可收起，窄屏保持抽屉交互。

存储设置在位置选择后询问“是否保留下载的视频”，提供“不保留 / 限制为 / 不限制”单选（默认“不保留”）与“视频存储预算（GiB）”。不保留时直接说明适合边播边下载、普通视频不长期保存，开启收藏保留时完整收藏视频仍可保存，房间队列准备不受影响；实际占用超预算的补充说明使用 Tooltip。位置设置分别称“数据库文件”和“完整视频目录”，完整视频在“曲库 → 按资源”管理，队列提前准备称“房间队列预加载”。请求 HIT 展示为“本地视频命中”，仅表示完整本地视频命中，不将运行期块复用混入该统计。

“激进的缓存回收策略”仅在设置的存储标签提供“自动（默认）／开启／关闭”单选，简短说明减少占用与重复下载的取舍。自动状态同时展示当前结果，随“不保留／限制为／不限制”草稿更新；手动选择保留。补充说明关闭后仍受视频存储预算约束，“不保留”下普通资源仅复用本次运行内的视频块缓存，开启收藏保留时预算例外仍有效。新配置默认 auto，切换预算保留所选策略。

存储设置先展示数据库文件、打开／新建操作和完整视频目录，再展示保留方式和预算。选择“不保留”仍允许编辑两个位置。界面说明数据库优先备份、视频按需备份，以及保存后重启；接入已有视频时在保存前确认其保留策略。切换不重置路径、不自动搬迁数据，不新增临时块目录设置。回收策略和延续保护时长直接可见，不再放入高级折叠。

曲库和历史以紧凑 Table 每例一行展示，主次文字复用 TableCellLayout；补充资料通过非模态 Popover 查看，短说明使用 Tooltip。曲库概览只展示占用、覆盖率与预算；导入视频、VRCX 历史及按 ID 标记通过明确按钮进入任务区域。

VRCX 建议在曲库以轻量 MessageBar 提供「导入历史 / 忽略」，只检查默认文件存在性后显示，不自动读取源库细节。空库建议跨重启保留，直到首次写入歌曲需求统计或用户明确忽略；忽略选择持久保存，资格随现有状态刷新更新。首次自动建库在其他页面检测到时，右下角普通 Toast 提供「前往曲库」链接；仅导航，不触发读取，进入曲库后撤去通知，关闭／超时／同标签页刷新／重启不重复弹出。用户点击导入后才读取，空统计直接导入，已有统计沿用预览与覆盖确认；具体触发与生命周期以[历史初始化契约](song-catalog-design.md#vrcx-历史初始化)为准。不增加引导或自动弹出的模态确认，导入成功使用本页 Toast。

曲库歌曲的需求分数统一按内部值乘 100 显示，最多 2 位小数、最多 4 位有效数字；小于 100 时保留 2 位小数，较大数值按四位有效数字收缩小数位，例如 37.56、100.0、123.5、1,235。使用标准 Intl 数字格式，不封顶为 100，也不把显示舍入值用于排序。没有真实需求记录的初始分数使用 Fluent 次级灰色；真实分数使用正文色，浅色主题为黑色，深色主题随主题适配。表格单元格的无障碍名称及歌曲详情同时标明“真实分数／初始分数”。

“按歌曲 → 需求分数优先”先按是否有真实需求记录分组，真实分数全部在初始分数前面，再在组内按未舍入分数降序、同分按歌曲 ID 降序；在后端全体结果中排序后分页。来源由现有需求次数是否大于零决定，真实分数衰减至很小或零也不变成初始来源。名称、ID 和资源视图的排序保持各自规则；这一歌曲列表展示规则不改变下载补齐、视频保留的数值评分及共享资源汇总。

“曲库 → 按歌曲”使用标准选择控件设置普通、收藏、屏蔽；支持本地查找、筛选及按 ID 标记。收藏标记与完整文件存在状态分开展示，明确标记不开始下载；屏蔽只影响新请求和新准备。零预算下保留手动补齐入口，预算提示按收藏保留设置说明实际资格。详情中的共享资源和临时块说明遵循[业务设计](download-resource-design.md#8-歌曲屏蔽与收藏)，不在需求或块调度界面新增偏好操作。

存储设置在回收策略旁提供“本地延续保护时长（秒）”，使用标准数值输入，默认 300，范围 0～10000 的整数。说明最后一份需求结束后的保留用途、0 表示不延续保护，以及较长时长可能增加空间占用。运行语义以[本地保护](download-resource-design.md#本地保护)为准。

侧栏名称与页面主标题一致。取消独立运行状态页，其内容分别归属下载和网络；旧监控地址进入网络页，明确的下载／队列／参数锚点进入对应任务页并展开目标。完整操作只出现在所属页面，其他入口以摘要和链接连接。同一份存储、下载、网络字段仍由共用组件渲染。

各配置位置只保存本处草稿，将其合并到最新已保存配置，不提交其他位置的草稿。所有位置等待保存后的新状态再解锁；任何位置尚有草稿时禁用重启，提示先保存或放弃。退出策略保存即用于本次退出；其他运行配置保持重启生效，启动配置生效规则见配置生命周期。

首页加速总状态下仅在开启过程中显示进度；“加速运行中”下显示小字“可关闭浏览器，减少资源占用”，不常驻展示尚未检测、等待请求、已收到或检测停止等提示。异常继续提供错误反馈，检测开始与首个请求时间在接入诊断中查看。自动与手动一键加速共用请求检测窗口，hosts 与网关均就绪后才开始等待请求。历史请求结果单独呈现。首页提供到高级接入的诊断和重新检测入口，统一调用一键加速。高级接入、帮助及条款均不提供独立网关启停、队列启停或 hosts 恢复操作；退出恢复是配置，结束运行使用退出程序。

技术数据在紧凑表格中扫读，补充明细通过标准 Popover 查看，不改变下载、检测、存储或保护规则。当前文件摘要独立于搜索/分页；请求次数不等于播放次数，历史按独立请求展示，交付比例不代表播放进度；网络成功样本不保证每首歌曲可播放。只保留帮助判断的短说明；永久删除等重要后果在操作确认时明确展示。

页面标题下不复述导航或功能清单。读取状态在所属区域显示一次；测速未开始时不叠加空样本提示，无历史批量任务时不显示空详情入口。设置操作区使用简短的未保存／同步中／待重启／已生效状态，重启中断等后果由原确认流程说明。曲库文件操作完成且无异常时使用 Toast；有跳过或失败项时，在列表前显示唯一的 MessageBar 与结果表，并将焦点移到结果区，保留原因供核对。

首页「视频块需求」以常驻 Canvas 需求视图替代原当前 GET、下载和房间队列表格，不再轮询 `/api/downloads`。等待下载、正在下载、本地可用、延续保护的计数默认展示，按唯一块统计，不重复累加共享需求；有正在结束的块时补充该状态。每行在标题后显示整数百分比，以本地可用块数／当前需求块数向下取整表示粗略就绪进度；只有全部就绪时显示 100%，不再显示进度条。该比例不表示播放进度或完整视频校验进度。「块显示大小」控件及图例常驻；来源、视频内位置、配色和块详情沿用已有规则。原列表的额外字段不逐项迁入。

面板标题、总下载速度、连接／自动暂停状态、需求占用与执行额度尽量排在同一行，末端为 Fluent 图标按钮；悬浮或键盘聚焦显示「展开／收起时间轴视图」，保留可访问名称与展开状态。「块显示大小」控件与状态图例同排，窄屏自然换行；需求视图保留标题和需求数，移除排序／空档说明。时间轴默认收起，展开后位于需求视图上方；收起停止时间轴排序和绘制，保留需求视图的共用 SSE。页面可见且面板处于视野时订阅；切页、标签隐藏、整个面板滚出视野后断开订阅并停止动画，恢复时重新取得完整状态。主时间轴单独滚出视野时停止其动画及事件重绘，需求视图继续更新；滚回后按最新状态和时间恢复绘制。缩放、跟随现在和「分层显示」开关仅在时间轴展开时显示；「时间轴视图」标题位于延续／提前窗口标记前，与开关尽量同排。画布上下留白及需求行高度保持紧凑，保留读取急需标记、选中边框与刻度文字所需空间。时间轴移除横向滑条和操作说明文字，继续支持滚轮、拖动及键盘。

总下载速度复用网络读取计数，由同一 SSE 连接的独立 `download-speed` 事件更新，约每秒采样一次，以实际采样时长内的字节增量计算；速度事件不重建块快照、不重新计算块差分、不触发需求 Canvas 绘制。短任务退出仍计入已经收到的字节；无新字节的下一次采样将速度归零并停止计时，新字节再唤醒。无订阅时不保留速度观察任务。自动暂停展示时保留最后数值，恢复订阅后使用新观测；不提供手动暂停复选框。后台状态和最近请求摘要保持各自已有刷新机制。

暂时不可见或连接中断只隐藏固定详情并释放详情订阅，保留固定选择；恢复连接并收到完整状态、确认块仍存在后再显示详情。工具栏操作不取消固定，关闭按钮和 Escape 仍可主动关闭。仅悬浮的详情不自动恢复。块退出最新状态或主动关闭详情会清除选择；收起时间轴只清除从时间轴选中的块，保留需求行的选择；不会为最新状态中已移除的块重新请求详情。保留选择不延长核心观测、文件保护或历史记录的生命周期。

有期限的块按 need-by 映射到连续时间轴，允许覆盖；现在指针在跟随模式默认居中，左右分别标示下载延续和提前窗口。时间轴的层间距、无期限区和总高度随块显示大小共同变化，绘制、命中与键盘定位使用同一布局；「现在」时间放在底部刻度带，省略与其重叠的刻度文字。块始终是正方形，边长可调为 4–36 px；缩小块或放大时间轴可减少覆盖，时间完全相同的块仍保持真实位置，通过浮层切换，不为防重叠挪动时间坐标。重叠时，定位时间较小的块在上层；相同时按块标识保持稳定顺序，选中不改变层叠顺序。可切换单层或三层，上到下为未安排、下载中（含正在结束）、本地／已完成，层名称背景透明；无期限区域也沿用这一分层，不制造时间值。

同一歌曲使用稳定配色，没有歌曲标识时按视频资源标识配色。视频仍在视图中时沿用首次分配的颜色，需求来源变化、歌曲标识补齐或断线重连不重新配色。颜色表示视频归属，状态使用空心、斜纹、实心；每块带略深于主色的细描边，区分同色重叠边界，不使用模糊阴影。需求结束后的本地延续保护保留视频配色，以 35% 不透明度绘制填充和边框，取代早期灰色表示。选中轮廓与读取急需标记保持清晰，读取急需另加边框与圆点。时间窗口颜色带只是参照，真正下载资格在属性中说明；本地可用不等于完整视频已校验发布。详情同时显示视频标题（无标题时歌曲／资源标识）及视频内编号 `13/45`，表示从 1 开始的第 13 块、完整视频共 45 块；总数未知时显示 `13/?`。时间轴选中标注和键盘选择使用同一编号，底层块索引和字节范围仍从 0 开始。

需求视图的每个矩形对应一个来源对一个视频的需求；按 GET、短期交接、队列位置 #1/#2…、手动下载排列。同一歌曲的矩形边框同色，交接矩形外框固定白色，内部块及时间轴继续保留视频原色（forced-colors 仍由系统颜色优先）。交接标题复用观测期间已有的歌曲信息，首次打开时可从本地歌曲资料补齐。内部以完整视频总块数建立等距位置，方块放在其原始块号对应的位置，无需求的前缀、中间区间和尾部留空；需求撤销不让剩余块左移。同一视频的不同需求行共用相同位置规则。方块保持所选大小，位置随矩形宽度缩放，首尾方块保留内边距且完整可见，不设行内横向滑条；块间距不足时允许重叠，视频内位置较早的块在上层，选中不改变层叠顺序。总块数未知时暂按该行观测到的最大块号缩放，仍明确标注总数未知，待总数补齐后更新位置。悬浮或键盘查看同一套详情，空档不产生详情请求；重叠处先命中上层块，并可通过共用浮层切换被覆盖的块。相同块可以出现在多项需求中，容量仍按唯一块计算。只为可见需求行绘制 Canvas，复用时间轴 SSE 和单一选中块详情订阅；不为每行或每块建立订阅。

需求行的测量与绘制在浏览器显示前完成，标题、外框和块同时按实际宽度出现；列表缩短时同步修正滚动范围，避免先显示空白再补齐。列表与画布尺寸不做过渡，减少动态效果模式也遵守同一规则。需求内容仍随事件及时更新，不延迟真实的新增、撤销或状态变化。获得键盘焦点的需求行被移除、焦点落到 body 时，将焦点恢复到需求视图区域；下一次 Tab 可继续进入剩余行，不抢走区域外控件的焦点。

纵向滚轮围绕视图中心缩放时间范围，保持原有跟随／固定状态；按钮与键盘加减缩放采用相同规则。横向滚轮（或 Shift + 滚轮）左右平移，不改变时间缩放或跟随／固定状态；跟随时保留相对现在的时间偏移，时间继续移动。按住拖动时切为固定，“回到现在”恢复跟随并清除偏移、重新居中。无期限区域通过横向滚轮（或 Shift + 滚轮）平移块列表，键盘选块继续自动定位，不为无期限块制造时间值。悬浮查看属性及当前来源，点击固定详情；被覆盖的块通过浮层切换按钮逐个选择。两个视图的未固定详情均随鼠标进入、退出重叠区同步完整命中集合，默认选择最上层块；集合不变时保持浮层稳定，已固定的详情不随悬浮移动改变。所选块上方显示时间性质与对应时间；need-by、下载截止、本地保护、读取者和来源详情保留准确语义。保护期块的历史定位规则以[按需块观测](block-scheduler-design.md#按需块观测2026-10-20)为准。

本地存储故障通过 WebUI 公共后台状态及详情显示，切页仍保留首个原因、影响和恢复步骤；生命周期以[配置与运行约定](settings-lifecycle.md)为准，不依赖请求明细中的 HTTP 状态码解释故障。

业务页面保留草稿及选择；普通导航（包括帮助、关于和历史前进／后退）回到页面顶部，明确的定位链接才滚到对应区域并移动焦点，旧锚点继续可用。操作反馈说明具体动作，只属于发起操作的页面，离开后清除；迟到的响应不把反馈带到新页面。连接中断、本地存储故障等全局状态仍持续展示。设置以实际差异判断未保存状态，放弃更改恢复已保存值；保存成功后等新状态同步再解锁。真实游戏和系统集成仍见[待验收台账](live-acceptance-backlog.md)。

未同意条款时自动显示 Fluent 模态条款弹窗，提供完整正文、纯文本和帮助链接，以及“同意完整条款”“不同意并退出”。条款读取或保存失败显示原因并允许重试；失败不开放业务接口，成功后关闭弹窗，按启动设置运行。Escape 和遮罩不关闭门禁；没有四步引导、独立草稿或最终统一应用。

条款弹窗在窄屏内限制最大高度并允许滚动，正文可聚焦阅读，键盘焦点保持在弹窗内。同意成功后焦点返回应用内容；已同意用户可在“关于 → 用户协议”再次阅读。

设置表单顶部的操作栏滚动时固定显示状态、保存、放弃与重启按钮；无需重启时按钮禁用。字段直接可见，原生校验定位无效输入。各配置位置只呈现所属字段，补充技术说明按需提供。“同时下载数量”“提前准备时间（秒）”使用任务语言，技术边界保留在提示中。

帮助按开始使用、播放失败、空间不足与视频保留、停止与卸载、日志与当前路径组织；目录明确定位各节，安装、代理、搬迁和升级以直接可见的步骤说明。帮助目录及内容在状态接口不可用时仍可访问。

下载速度测试默认展示单连接／多连接速度与可用性，CF 接口、连接数及 CPU 分位值在技术详情中。准备样本失败说明缺少在线测速样本，先检查连通性再重试，不要求本地视频或预算；失败仅展示在对应连接方式下。

批量任务分别呈现本地检查进度、上次完成记录和在线曲库更新结果；使用已有清单时明确标注，原始在线错误收进详情。“重试更新”复用缺失检查入口，更新曲库并检查本地文件，不下载视频。没有可用清单时明确未开始本地检查，不把在线错误混入逐曲失败数量。

游戏接入停止／退出策略只在「设置 → 常规 → 停止与退出」中编辑，默认开启「停止加速或退出时恢复游戏直连」。停止与退出按钮的 Tooltip 按 activeSettings 展示当前策略，保存成功后该退出选择同时更新到 activeSettings 并用于停止加速和本次退出，不等待重启；未保存的草稿不改变退出说明。已有托管接入尚未准备恢复权限时，首页提供链接前往接入诊断修复连接，并说明直接退出会保留接入；退出结果只确认请求已接受，不预报恢复成功。权限与异常边界以[hosts 契约](console.md#hosts)为准。

权限助手每次新授权成功并建立连接后，通过公共状态显示信息 Toast「可在退出后保留游戏接入」，说明关闭「停止加速或退出时恢复游戏直连」并保存，以及下次游戏前仍需启动 SWD。「打开退出设置」定位并聚焦该选项，只导航、不修改草稿。网页、托盘与自动加速共用这一触发来源；授权取消、失败和复用已有助手不触发。同一标签页刷新不重复提示，当前进程的新授权仍会提示；关闭网页期间已完成的授权在打开页面后显示一次。浏览器存储不可访问或读写失败时，仍显示通知并保持当前页面内去重，仅放弃刷新去重，不影响界面使用。该提示不替代操作结果或失败原因。

## 请求历史

历史默认查最近 24 小时，可使用本机时区的日期时间字段筛选，或选择全部保留期；每页最多 50 条，游标可遍历超过 500 条的记录，页面不累计无限列表。第一页未设置结束时间时每 5 秒刷新，后续页保持稳定；暂停只冻结展示，离开页面或浏览器不可见时停止读取。尚无结果时显示加载状态；后台刷新期间保留现有记录或空结果提示，历史与首正文统计的刷新操作保持可用，响应成功后更新内容。筛选草稿随应用内导航保留，切换存储重置游标；翻页和重新查询将焦点送到结果区域，刷新时保持请求 ID 对应的展开状态。读取失败移除过期行并回退焦点，提供重试。旧 #recent 锚点定位此页。

首正文分位数独立每 30 秒读取，提供显式刷新，不受历史日期范围和分页影响。Blocking、缓存／本地均同时展示 P50、P95 及样本数；无样本显示暂无数据，不用零值代替未知。首次采集和清理水位决定覆盖不足提示。行内只显示请求时已知歌曲 ID 和资源，当前关联不推断为历史身份；正文交付未知时显示 —，错误正文不计入视频字节。完整业务口径见[请求监控](console.md#最近请求监控)。

曲库的歌曲资料和需求分数与资源状态分开呈现，共享文件只在资源映射中读取一次。未知大小／实测时长显示未知；运行期块进度即使达到 100% 也不代表完整文件已保存。历史歌曲／资源链接执行精确查询，不在当前范围内时明确说明并保留原身份。删除和定位共用已有文件快照、确认及保护机制；列表每页最多 50 项，文件状态每 10 秒读取、下载观测每 5 秒读取，不可见时停止。单项与全量共用批量运行槽，结果标明本次范围，不建立追加待办集合。

设置和关于的标签选择写入 Hash 路由，刷新及前进／后退保留所属分类。VRCX 检测与导入共用应用内模型，返回曲库或切页后保持草稿及预览。资源视图保留最近请求排序，复用已有 GET 访问汇总。

常规主题提供跟随系统、浅色、深色，选择后单独自动保存到程序配置并立即应用于 Fluent 主题、图标、块需求画布及托盘，不需点击保存或重启，也不提交其他设置草稿；失败保持原主题并显示原因。多页面同步、默认值与系统跟随边界统一见[配置生命周期](settings-lifecycle.md)。「启动程序时自动打开 WebUI」默认开启，保存后下一次启动程序使用；托盘主动打开及已有实例激活独立于此设置，网页内重启沿用 -no-open 复用原页面。曲库视图通过 `#/library?view=songs|resources` 定位；#recent、存储／下载／网络区域锚点及 /help、/about、/terms 公开文档地址保留对应归属。

首页活动展示与订阅统一遵循上文“视频块需求”的规则，原每 5 秒读取 `/api/downloads`、最多展示 50 个活动 GET 及独立队列日志状态的规则已被替代。请求身份及交付比例保留在请求历史中；网关的实际 80／443 状态在网络页游戏接入区域展示。


2026-10-25 简洁重构移除 Accordion 包装及网络二级标签。网络页直接展示线路结果、连通性与测速、游戏接入，使用页内链接定位；代理、回源线路和测速间隔留在设置的网络标签。两页共用同一份网络配置草稿，“检测此连接配置”跳转并选择对应检测上游，不保存或应用配置，往返保留编辑。相关字段或检测卡片在宽屏并排。表单使用默认上方标签的 Field 与横向 RadioGroup，按容器可用宽度排布。帮助按问题直接提供步骤，不再重复操作页的长解释。设置与导入草稿、校验和最终操作语义保持不变。

响应来源统计在历史页显示下载／缓存／本地视频占比与累计折算字节，逐请求显示比例并在明细提供字节值。累计独立每 30 秒读取并可手动刷新，查询失败保留旧值与持续错误；无计入块显示空状态，未知保持未知。分类与计量统一见[设计口径](webui-design.md#响应字节来源统计)。
