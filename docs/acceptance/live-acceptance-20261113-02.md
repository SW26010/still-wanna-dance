## 干扰、失败与限制

- 初次复制配置带有显式数据库路径，但新目录还没有数据库，正常启动校验拒绝启用网关。退出后去除这两个显式存储位置，由现有默认存储准备流程创建空库，再启动成功；没有复制旧数据库或旧视频。准备阶段 API 拒绝及采集短暂断连保留在本地原始材料。
- 用户虽确认已关闭旧预览，起播准备阶段仍收到上一首 6254 的残留 WMF GET；它在 T−109.2665 秒 取消，对应下载于 T−107.2665 秒 结束。实际拖动在 T−0.2665 秒，旧任务已退出，不将这段混合起播流量当成单首带宽样本。
- 第一次自动降速以开播回调为触发，早于用户实际看到画面；该操作导致准备期不满足“已有画面”的计划前置。T−43.2665 秒 的请求 6（Range 8,110,080）出现 504，游戏报错后重新加载，从零 Range 恢复。用户的“从开头放”已明确是拖动之前的状态，不记成 Seek 后跳回开头。
- 起播补充带宽后，目标部分已经缓存，未强行记为全冷落点。拖动后的块等待有独立证据；严格全冷目标的截止后恢复仍未由本批证明，作为结果边界保留，不自动增加重复游戏任务。
- 应用日志与块事件连续采集，最终导出依据原始日志及拖动前事件快照。游戏时间戳精度为秒，名义每 100 ms 采样；人工反馈的记录时间不是精确画面时刻。没有 CPU/帧时间、首帧收益或全部历史慢网根因结论。
- 零持久容量下没有发布正式视频文件，本轮未单独复算完整文件 MD5。既有缓存数据不等于正式文件 HIT。
