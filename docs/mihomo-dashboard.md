# Mihomo 与 zashboard 的职责

SWD 将外部 SOCKS5 和内嵌 Mihomo 都视为一个逻辑代理出口。代理模式不再展开节点候选、保留五节点活跃子集、按节点测速排序或维护节点吞吐历史。直连 IP 的发现、推荐、迟滞与自动测速保持原有规则。

## 配置和运行

SWD 继续负责导入、校验、DPAPI 节点快照和应用生命周期。原始订阅只提取受支持的节点，不执行其中的规则、分组、监听、TUN 或系统网络配置。显示名称保存在受保护快照中，公开导入报告仍只有数量和固定诊断。保存节点后重启生效，面板不能重载或覆盖 SWD 配置。

核心沿用受控内存配置 `ParseWithBytes → ApplyConfig`，不新增明文 YAML 副本。确认当前条款后才启动核心，避免原生健康检查提前联网。一个进程只初始化一次核心，失败或退出后通过应用重启恢复。

所有已加载节点都交给 Mihomo。`SWD` 选择组默认使用「自动故障切换」fallback 组，按生成配置中的节点顺序选择健康节点；原生检查地址为 `https://www.gstatic.com/generate_204`，间隔 300 秒，启用 lazy。首次检查仍会运行。此检查说明测试地址的可达性，不保证某一视频站点可达；业务校验和失败重试仍由 SWD 完成。所有节点失败也不回退直连。

面板的整组测速可能同时连接组内所有节点，节点较多时会产生连接高峰；原生健康检查也由 Mihomo 自己调度。这些检查不经过 SWD 的 160 个业务连接准入槽，用户可以按需只测试单个节点。

用户在 zashboard 的 `SWD` 组中选择节点，或选择「自动故障切换」。手动固定节点后，不再自动换到其它节点。切换作用于新连接；已有 HTTP 连接池和下载继续运行。首次打开面板将其「切换时自动断开连接」设置初始化为关闭；在同一浏览器和同一地址下保留用户后续修改。显式断开连接仍由面板提供。

Mihomo 的 `profile.store-selected` 将组名和选中的节点名称写入实例的 `data/state/mihomo/cache.db`，并按原生规则恢复，不回写 SWD 配置。无名节点使用「节点 1」一类名称，不由 SWD 拼入服务器地址和端口；导入的名称用于展示，可能本身包含地址。名称后附连接身份摘要用于区分同名节点；名称、无名节点的顺序、连接参数或密钥变化及节点移除后，旧选择可能无法匹配，按原生默认回到自动组。密钥损坏或不可读时界面提示，本次仅用临时身份，关闭选择记录的读取和更新，保留有效缓存中的原选择；这不阻止缓存文件初始化或原生修复。节点连接配置及凭据仍保存在受保护的 SWD 配置中，不为核心生成明文配置文件。出口只暴露单个进程内候选，不将核心内部节点选择映射成 SWD 状态。

`cache.db` 是明确交给 Mihomo 管理的可重建选择缓存，不是凭据备份或异常材料保全文件。文件缺失时原生初始化；Bolt 格式、校验或版本错误时允许原生删除并重建该文件，不增加备份、格式迁移或恢复机制。这个边界仅适用于这一已知组件缓存，不授权清理同目录其他未知文件、配置、密钥或业务数据库。启动时无法打开缓存，SWD 记录告警并在设置中提示本次节点选择不会保存；代理、面板选点与 Console 继续运行，选择只在本进程内有效，存储问题修复后重启再尝试打开。已打开缓存的后续写入失败仍按上游机制处理。

单一出口有 160 个无队列连接准入槽，沿用旧五节点合计的容量上限，覆盖拨号、连接和关闭完成；默认拨号期限 10 秒。退休立即拒绝新请求，核心、连接、提供者与缓存的关闭共用 3 秒退出预算。Mihomo 负责原生连接统计，面板可查看和手动断开这些连接。

## 监测与界面

SWD 保留清单、播放地址和资源的业务连通性检查、有效播放 URL 落库、资源验证和下载重试。代理模式只观测当前逻辑出口，不根据结果选择内部节点，不运行周期性吞吐测试，也不读取或持久化代理吞吐样本。手动测速仍可测当前出口；核心选择和长连接复用可能使样本覆盖不同出口，不能据此为节点排名。

设置中的已保存／已加载数量继续表示配置生命周期；活跃子集数量删除。设置 → 网络、网络 → 当前连接提供「打开代理面板」。保存设置仍需重启；面板中的节点选择即刻影响下一次建连。

## 本地控制与分发

zashboard 的原版固定静态包内嵌在 EXE，通过 `/proxy/ui/` 提供，打开 `/proxy/` 自动接入当前实例。原生控制器只监听随机回环端口并使用独立随机 secret，浏览器经 SWD 同源 `/api/mihomo` 转发。沿用实例 Host、条款与 token 门禁；普通 HTTP 用 Bearer token，WebSocket 用 token 参数。核心 secret 不传给浏览器。

应用重启会更换 token。若浏览器仍使用同一地址，面板入口刷新本实例已保存的连接记录并保留 UUID，避免 zashboard 因 secret 改变重复添加同一个后端；其他后端不受影响。面板偏好由 zashboard 保存在浏览器的 localStorage，按浏览器和完整来源（含端口）隔离；桌面默认随机端口，重启后偏好可能重置。节点选择由核心缓存保存，不依赖浏览器来源。

上游面板的 IPv6 检测启用并取得结果时，可能把节点显示名写入浏览器本地存储。显示名可能含地址；原生选择缓存和浏览器存储均不受 SWD 配置的 DPAPI 保护。

只开放节点/分组/规则/状态的读取与健康检查、`SWD` 组选择、连接查看和关闭。配置修改、GLOBAL 选择、TUN、核心/面板升级、重启、原始日志及任意文件/存储接口均不开放。GLOBAL 组固定指向 SWD 并隐藏；面板仍可能展示上游的通用设置，受管写入会明确提示到 SWD 设置修改。应用退出取消转发与流式连接。

固定的 Mihomo v1.19.32 在选择器和内存统计缓存中存在未同步读写，真实浏览器 race 验证可复现。接入层同步原生 Selector 的选中状态，拨号在取得原生选择后释放锁；自动组不暴露手动固定接口，避免健康检查重置无用的固定状态。`/memory` 使用同一个原生进程内存查询函数直接输出，绕过与 `/connections` 并发读写的缓存，因此连接快照中的可选 `memory` 字段为零，面板内存图表以 `/memory` 为准。上述兼容处理不修改依赖源码，也不新增选点算法；升级核心时需检查是否可以移除。

发行使用未修改的 zashboard v3.30.0 `dist-no-fonts.zip`；版本、提交及 SHA256 由 [release.json](../internal/dashboard/release.json) 固定。面板和核心随 SWD 更新。静态资源不依赖 CDN；上游面板仍会检查 GitHub 新版本，部分可选 IP/地理功能会联网。断网不影响本地选择、状态与连接控制；上游的更新检查可能留下 fetch 失败记录。不能将面板概览中的浏览器外网测试当成 SWD 出口测试。
