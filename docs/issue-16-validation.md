# #16 使用引导：当前实现与验收

开发完成，实机验收 **LA-029 / LA-030** 继续积攒；分阶段 CF 测速另见 **LA-045**。当前界面为 Fluent UI React v9，自动与浏览器检查统一见 [Fluent UI 验证](fluent-ui-migration.md#验证与待验收)。旧步骤数量、原生 HTML 控件布局和逐轮开发截图记录不作为当前要求。

## 当前行为与依据

| 范围 | 行为与代码 |
| --- | --- |
| 四步流程 | 开始、存储、网络、启用；左侧 NavItem 导航，条款与内容校验后才离页。草稿独立于普通设置，恢复默认仅影响本页；旧步骤名称映射到当前页。`webui/src/setup.tsx` |
| 条款与离开 | Fluent Dialog 阅读完整条款，明确同意后即时保存；失败不解锁，无法验证的旧记录要求重确认。草稿离开使用标准确认，刷新/关闭保留浏览器 beforeunload。`setup.tsx`、`internal/console/terms.go` |
| 存储与导入 | 默认存储、外部目录、容量及可选导入进入草稿；路径检查不建库，最终应用才执行。现代 Windows IFileDialog 使用浏览器 owner 和 Per-Monitor V2，选择/取消不写正式配置；离页/退出取消窗口。`internal/console/setup_{storage,folder,apply}.go`、`internal/desktop/folder_{windows.go,dialog.ps1}` |
| 网络与诊断 | 直连/代理不可全空；连通性和 CF 测速只能手动启动，使用选定直连或代理草稿，独立于业务配置。SSE 恢复状态，取消按同一上游恢复有效结果。`webui/src/{settings,diagnostics}.tsx`、`internal/console/setup_{network,connectivity,calibration}.go` |
| 应用与回执 | 摘要显示实际变化，唯一应用请求复核配置版本、路径及活动任务，按需重启并导入。逐 ID 回执绑定 HMAC 配置版本，密码参与版本但不外泄；刷新或响应丢失只查询原 ID，不重复应用。`internal/console/setup_apply.go` |
| 自动启用与接入 | 首次条款门禁跳过的网关/队列自动启用在应用成功后按各自设置补执行，需重启时由新进程执行；前端不追加启动或 hosts 请求。hosts 是用户明确触发的即时操作，放弃草稿不撤销它。 |
| 临时槽 | 配置锁内只清理严格匹配的共享/逐 ID 临时槽，保留正式回执和未知文件，拒绝异常目录或链接。`internal/desktop/config_lock.go` |

## 待实机验收 LA-029

在隔离 Portable 上逐项记录，联动 LA-004/009/016/017/028/032。保留源码/发行包哈希、脱敏配置/回执/请求时间线、文件清单、系统回执及清理结果；不提交密码、密钥或凭据密文。控件布局和提示行为以 Fluent 标准组件为准。

| 场景 | 可复现步骤与预期 | 关键证据 |
| --- | --- | --- |
| 29.1 条款记录 | 从无记录的真实 `/`、`/terms` 进入，关闭弹窗不授予同意；无效/跨用户记录要求重确认。覆盖读取、保护和写盘失败，只有保存成功才解锁；已确认后只能阅读。离开/返回及退出倒计时符合门禁。 | 入口、弹窗操作、保存时序、脱敏记录状态及退出日志 |
| 29.2 草稿与校验 | 修改存储/代理/导入并切换步骤；合法值留草稿、非法值留页，正式配置和任务不变。恢复本页默认不改其他页及普通设置草稿；迟到响应不抢导航或复活草稿。 | 草稿/正式/生效值及请求时序 |
| 29.3 离开挽留 | 修改后通过返回、其他导航、刷新/关闭离开；取消保留草稿，确认才丢弃。未修改/改回原值不提示，明确放弃不重复确认；重入从正式值开始。 | 各入口选择、路由和草稿前后值 |
| 29.4 存储与导入 | 检查中文/空格路径、默认/外部/junction 及不存在目标的祖先边界。选择/取消/超时/导航退出不写配置或启动任务；目录检查不建库。容量只接受不限或正数；导入勾选只展开，来源为空不能离页，取消勾选/重置清除来源。 | 选择器与请求时序、目录前后清单、容量和路径类别 |
| 29.5 核对应用 | 一次确认保存并按需真实重启，导入使用新目录；完成回执后进入控制台，自动启用按既有设置执行。覆盖另窗改配置（含仅密码变化）、活动任务、不可写、源消失和部分失败，同 ID 不重复导入。缺失密钥重建后旧版本失配，损坏密钥安全失败；API 不返回 targetVersion 或裸摘要，旧摘要回执不能续接。 | 配置/回执哈希、版本相等性、重启/导入/自动启用次数及错误 |
| 29.6 重启恢复 | 新实例超过 60 秒未就绪时保留核对和退出入口。另窗替换共享回执后仍查原 ID；查询失败保留 ID，确认不存在后主动退出才清除。刷新、重连、重入不重复提交应用/重启/导入。 | 超时时序、原 ID 查询次数及最终回执 |
| 29.7 临时槽 | 重启清理合法共享/逐 ID 临时槽后能再次应用；正式回执、未知文件及其他配置不变；异常目录/链接拒绝且不遍历。 | 文件前后清单、哈希和错误 |
| 29.8 hosts 与端口 | 展开修复说明不操作 hosts，明确点击才请求 UAC。分别拒绝/同意启用和恢复，慢确认等待与未确认提示不冒充成功；核对 80/443 占用原因和实际 hosts，放弃/退出不自动撤销映射。 | UAC/请求时间线、端口/hosts 差异和恢复校验 |
| 29.9 VRC 日志 | 检查默认/自定义生效目录、缺目录、旧/当前日志、不可读及误为文件；只读检测不创建目录、不启动监听、不泄露内容，旧日志不冒充在线。 | 路径类别、状态和目录/任务前后对照 |
| 29.10 页面与帮助 | 从托盘进入四步引导及离线帮助，核对左侧导航、旧进度恢复、条款门禁、一次应用与失败恢复。真实 Windows DPI/辅助技术按 LA-028 检查，不重复复刻旧圆点/固定外框/单行控件。 | 发行哈希、实际操作与系统/辅助技术记录 |

目录窗口（29.4/29.10）还须覆盖普通/最大化浏览器、100%/150%/200% 系统缩放和跨 DPI 屏幕移动；窗口应在浏览器前方且清晰，不永久置顶。选择、取消、超时、离页和退出后辅助进程关闭，浏览器恢复可用。浏览器视口模拟不能代替这些原生窗口检查。

## 待实机验收 LA-030

与 LA-005 联合检查真实出口，不用夹具速度或 HTTP 成功代替游戏播放。

| 场景 | 可复现步骤与预期 | 关键证据 |
| --- | --- | --- |
| 30.1 策略 | 仅直连、仅代理、两项自动分别应用；空选不能离页。检测使用所选上游及代理草稿，不应用草稿、不改业务选路；业务强制代理失效不得直连回退。 | 配置差异、检测及业务实际出口、游戏反馈 |
| 30.2 启动时机 | 未同意条款不能检测；同意、重入、切页、刷新和回执恢复不自动检测。手动点击只启动对应任务一次。 | 保存/启动时序和请求次数 |
| 30.3 后台与展示 | 连通性依次显示状态与响应时间；CF 速度/CPU/阈值及取消按 LA-045 核对。断线重连只恢复事件订阅，不重复启动；切页/关网页不取消后台任务，退出进程取消。线路详情区分当前失败、无资源地址、等待及过期历史样本。 | 脱敏事件、样本时间/字节、同上游恢复结果、配置及清理回执 |
