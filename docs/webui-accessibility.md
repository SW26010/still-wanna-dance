# Web UI 可访问性与浏览器验收

2026-09-27：控制台采用 Fluent 2 的蓝色强调色、Segoe UI 字体、间距、圆角、表面层级和状态样式。保持 Go 内嵌 HTML/CSS/JavaScript，无前端运行时依赖。

设计依据：[Fluent 2 accessibility](https://fluent2.microsoft.design/accessibility)、[WCAG 2.2](https://www.w3.org/TR/WCAG22/)、[WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/)。目标为 WCAG 2.2 AA；以下测试不构成完整符合性认证。

## 实现

- 原生页内链接、标题和区域组织导航；跳过链接直接聚焦主内容。设置按启动与存储、网络连接、扫描与队列分组，DOM 与视觉顺序一致。
- 原生 button、input、select、checkbox、details/summary、fieldset/legend 和 progress 提供交互语义。说明文字通过 aria-describedby 关联，进度条有名称，装饰符号对辅助技术隐藏。
- 全局可见焦点；常规按钮、导航和展开控件至少 40 CSS px 高。状态除颜色外同时使用文字。
- 颜色跟随 prefers-color-scheme；forced-colors 使用系统颜色和实体边框，保留浏览器自动颜色调整；prefers-reduced-motion 下关闭动画、过渡和滚动效果。
- rem 字号、可换行操作区和自适应网格支持缩放。长路径与错误信息可换行。
- 状态文本只在变化时写入，避免重复轮询触发重复播报。操作禁用按钮导致焦点掉到 body 时，完成后恢复至原控件或所属区域；用户已移动焦点时不抢回。
- 设置锁定、未连接、操作中和未保存更改均有文字说明，数值范围和必填使用原生校验。

## 已验证

在 Codex 内置浏览器打开真实 Go Console，配置与数据隔离在忽略目录 `test-runs/fluent-ui`。没有启动 CDN、修改 hosts 或运行下载任务。

- 系统深色主题渲染、浅色样式渲染；浅色通过仅测试服务禁用深色媒体分支验证，没有更改 Windows 主题。
- 320 × 800 CSS px 下概览及设置无横向溢出，所有字段保留在视口内。
- 浅色、根字体 200% 的测试样式下无横向溢出。此项是文字缩放测试，不等同 Windows 系统 DPI 或浏览器页面缩放实测。
- Tab 到跳过链接、Enter 聚焦 main；Space 展开原生说明。
- 队列数量 101 被原生校验拦截并聚焦；合法值保存成功，焦点回到保存按钮。
- 选择 SOCKS5 后地址字段启用；空地址保存被原生必填校验拦截。恢复直连后保存成功。
- 页面无重复 ID、无缺失说明引用、所有输入有标签；按钮、导航和 summary 无低于 24px 高的可见目标。
- Go 控制台测试 `go test ./internal/console` 通过。主要文字颜色组合的计算对比度为 4.94:1 或更高，控件边框最低 3.45:1。
- 浏览器控制台无脚本错误。前端 57 项回归测试通过，覆盖重复状态不重写、焦点恢复和尊重用户焦点移动。

## 2026-09-27 补充修复与验收

- 强制颜色分支为当前导航项增加 Highlight 实体边框与下划线，不依赖 box-shadow。
- 监控页新增原生「暂停监控自动刷新」复选框。暂停冻结下载和最近请求显示，后台任务与服务状态轮询继续；恢复立即刷新。暂停前发出的请求即使稍后成功或失败，也不能覆盖冻结内容；快速暂停/恢复同样丢弃旧响应。
- 下载任务或请求记录从列表消失、读取失败清空列表时，焦点回退至相应监控区域；加载更多按钮隐藏时也回退。原项目仍在时保留展开状态和焦点，不抢走列表外焦点。

本次实际操作 Codex 内置浏览器，真实 Go 控制台使用本地隔离预览；下载/请求消失场景使用仅预览服务器提供的 JSON 样例，没有启动 CDN、执行真实下载或修改 hosts。

- Space 勾选暂停；将服务端样例从一条改为空并跨过刷新周期，页面仍保留原下载速度和两份列表。再次 Space 恢复，立即显示最新速度和空列表。
- 键盘展开下载详情，再移除任务：焦点回到 downloads，浏览器计算焦点框为 2px solid；请求详情展开后清空记录，焦点回到 recent。
- 320 × 800 CSS px 视口：暂停控件可用，documentElement.scrollWidth = 305、innerWidth = 320，无横向溢出；验收后已恢复视口。
- 仅测试服务器激活 forced-colors 样式分支并移除所有阴影，浏览器确认选中导航有 3px solid 边框和 underline、box-shadow 为 none。这是样式分支验证，不等同 Windows 强制颜色实测。
- 浏览器脚本警告/错误日志为空。截图：本地忽略目录 test-runs/fluent-ui/a11y-monitor-paused.png。
- node --test scripts/navigation.test.mjs scripts/refresh.test.mjs：90 项通过；go test ./internal/console：通过；git diff --check：通过。

Windows 高对比度主题、系统 DPI、Narrator/NVDA 的待验收项仍然保留；本次不宣称完整 WCAG 2.2 AA 符合性。
