# 曲库重复刷新与直连检测调度验证

2026-11-12，基于 `d3061a75` 的工作区变更。现行规则见[上游刷新与交接](../upstream-channels.md#刷新与交接)、[曲库同步](../song-catalog-design.md#清单同步与增改不删)和[曲库读取与刷新](../webui-design.md#曲库读取与刷新)。

## 原因与修复范围

运行中旧构建的曲库检查时间在未手动操作时持续变化。直连 Monitor 把 DNS 租约裁剪后的有效期用于整轮检测调度，提前窗口为 63 秒；短租约会把下一轮压到完成后 1 秒。每轮清单和各 IP 的有效播放地址响应又无条件推进业务更新时间，前台据此读取曲库。

修复仅调整两处边界：Monitor 根据测量自身的观测寿命安排提前检测，DNS 仍独立续租、限制候选使用并通知成员变化；业务更新时间从 `catalogsync` 移到 Store 的映射事务提交处，仅实际改变记录且提交成功时推进。地址来源的运行期观测与有效期继续更新，旧清单补齐映射仍发布业务变化。不新增配置或持久化字段。
