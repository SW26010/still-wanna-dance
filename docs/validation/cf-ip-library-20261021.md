# CF IP 优选库检查与实测（2026-10-21）

**`fireinrain/cf-speedtester` 能完成单次优选实验，但 v1.1.2 不宜原样作为产品依赖。** 本轮独立复测中，它选出的 `103.21.244.1` 比预检选中的 DNS 地址 `104.26.5.28` 快约 26%；这是当前执行环境、单资源、单连接的三轮结果，不能外推为长期或产品下载调度下的收益。

本次仅检查和实验，没有接入产品、修改根模块依赖、配置、hosts 或正式媒体库，也没有启动游戏。测试进程均已退出；未 commit / push。不新增 VRC 台账项。

## 被测版本与实现问题

被测模块为 [`github.com/fireinrain/cf-speedtester@v1.1.2`](https://github.com/fireinrain/cf-speedtester/tree/114a1ad76e29c14d9357ff153ce3650cc7044dc0)，Go 模块代理查询的 latest 为此版本。提交为 `114a1ad76e29c14d9357ff153ce3650cc7044dc0`，模块校验和及本地探测程序、源码指纹见[精简证据](../evidence/cf-ip-library-20261021/summary.json)。使用独立工具模块、Go 1.27.1 / Windows amd64，`go vet` 和构建通过，未修改上游库源码。

| 检查 | 实际结果 | 影响 |
| --- | --- | --- |
| 空目录首次加载 | 成功进入 main；此前已联网获取 CF 网段、查询 GitHub GeoIP 发布并下载数据库 | import 就有网络和当前目录文件副作用；源码还会清理同名前缀的旧数据库，初始化失败可 panic / `log.Fatal`，调用方不能正常接收错误 |
| 固定速率校准 | 本地服务按 1 MiB/s 发包，5 秒内服务端写入 5,177,344 字节；库返回 **1.181 MiB/s** | 比配置速率高约 18.1%。源码按 Timeout/100 分片，最终却除以 Timeout/120，存在 1.2 倍换算偏差；短文件、建连及采样也影响读数，不能简单对任意结果统一除以 1.2 当作修复 |
| HTTP 503 | `task.TestDownloadSpeed` 返回 0 速度，但默认最低速度 0 时，合格结果仍有 **1 条** | 默认参数不能把入选等同于 HTTP 下载成功 |
| 丢包阈值 0 | `WithMaxLossRate(0)` 构造后的值为 **1** | 无法表达期望的“零失败率”；0 被当成未设置 |
| 共享 GeoIP 生命周期 | 首次测速前查询成功；之后查询返回 `cannot call Lookup on a closed database` | `DoSpeedTest` 无条件关闭全局数据库。未启用国家过滤的第二次测速仍返回结果，不能笼统称所有重复测速均失败 |
| 取消与错误接口（源码检查） | 测速入口不接收 `context.Context`、不返回 error；初始化使用后台 context / 默认 HTTP 客户端 | 不适合直接承接产品的取消、超时及失败反馈；本实验由外层子进程时限约束 |

上述控制实验仅使用回环服务，不将其作为公网测速证据。下载计量见 [`task/download.go`](https://github.com/fireinrain/cf-speedtester/blob/114a1ad76e29c14d9357ff153ce3650cc7044dc0/task/download.go)，初始化见 [`geoip/geoip.go`](https://github.com/fireinrain/cf-speedtester/blob/114a1ad76e29c14d9357ff153ce3650cc7044dc0/geoip/geoip.go) 与 [`cdn/cdn.go`](https://github.com/fireinrain/cf-speedtester/blob/114a1ad76e29c14d9357ff153ce3650cc7044dc0/cdn/cdn.go)。

## 实网方法

- 重新获取歌曲 1343 的 CF 播放资源，域名 `play.udon.dance`、资源大小 32,867,177 字节。复用已有实验预检程序获取新地址，预检实际远端为 `104.26.5.28`，HTTP/1.1、HIT、SEA。预检程序 SHA256 为 `2bf696a9dd7951b52eec6954e717d2005ad9fc48c6cb386bdabccccd60593fe4`，只负责目标准备，本轮测速另用独立程序。
- Windows `Resolve-DnsName -Type A -DnsOnly -NoHostsFile` 返回 `104.26.4.28`、`104.26.5.28`、`172.67.69.58`。另外从本次库加载的 15 个官方 IPv4 网段各取网络地址后的第一个 IP，共 **18 个候选**，没有全网段扫描。
- 库先以最多 6 并发、每 IP 三次 TCP 连接作初筛；18 个均有响应。取排序前六个，加上三个 DNS 地址，去重后 **7 个**进入下载测试。再调用原库 `DoSpeedTestForResult`，每 IP 最多 3 秒、最低速度 0.001 MiB/s、不启用国家过滤，返回四个非零结果。
- 原库报告的前四名依次为 `103.21.244.1`（9.833 MiB/s）、`104.26.5.28`（7.302）、`172.67.69.58`（5.750）、`104.26.4.28`（0.120）。这些是**存在计量缺陷的初筛读数**，不用于计算收益；没有把其余零速度结果解释为确定的网络故障原因。
- 独立复测固定预检基线及库排名最高的两个非基线地址，共三个 IP。每个先预热一次，再跑三轮；每轮循环轮换顺序。每次单连接下载同一个前 **16 MiB**，重新创建连接池，计入建连、TLS、请求、读取与 SHA256 计算；每个请求间隔一秒。
- 保留原域名 Host/SNI 和系统证书校验，关闭显式 HTTP 代理，钉住拨号 IP；逐次核验实际远端、206、Content-Range、Content-Length、identity 编码、强 ETag 和正文 SHA256。所有 12 个完整复测请求均通过，全部 HTTP/1.1、HIT。预热不进入性能统计。

## 失败保留、边界与结论

首次独立复测被实验外层 **60 秒总时限**截断，保存了 3 次预热、7 次正式完整观测及退出状态；整个不完整批次不进入主统计。随后保持相同资源、地址、参数及顺序，外层上限改为 250 秒，完整重跑成功，不删除或覆盖首次数据。两批累计验证正文 352 MiB；原库下载、被中断的请求、GeoIP 下载及协议开销另计，没有网卡级总流量统计。

首次 Go 模块下载遇到默认缓存目录权限拒绝，改用工作区独立 GOPATH/GOMODCACHE 后通过校验；保留错误记录。沙箱内 CIM 路由查询不可用，宿主只读查询显示目标走 `vEthernet (MyExternalSwitch)` 默认路由，活动接口为物理网卡及 Hyper-V 网卡。这不能排除网关透明代理；结果仅代表本机当前执行环境，不将约 2–3 ms 的 TCP 连接读数解释为到 CF 数据中心的真实公网 RTT。

本轮仅一次候选筛选、一个时段、一个视频、IPv4 和单连接；未独立复测第三个 DNS 地址 `104.26.4.28`，未证明胜过每个 DNS 地址，也未覆盖产品多路块调度、代理出口、长时间稳定性或 VRC 播放体验。测量期间没有并行编译或另一项测速，但未隔离整机其他流量。

**可以继续研究 CF IP 优选的收益，但不建议原样引入此库。** 如需产品化，应先解决初始化副作用、全局资源关闭、失败判定、计量及取消接口，并继续使用实际资源校验；当前没有实施这些修复。XIU2 CLI 未在本轮测试，不能据此宣称它已通过选型。

完整源码、模块锁定、成功与中断日志、原始数据及私密目标保存在忽略目录 `artifacts/cf-ip-library-20261021/`；Git 仅保存本报告和不含完整签名 URL、原始 ETag、私人路径的精简统计。`summary.json` 中 `localProvenance` 的哈希按实际本地文件字节计算。控制实验后工具增加了 live/verify 入口，最终程序指纹对应后续实网批次；不冒充控制实验原始二进制指纹。所有结论可从上述固定库版本和保留数据复核。
