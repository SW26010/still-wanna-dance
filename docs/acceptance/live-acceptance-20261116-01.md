# LIVE-20261116-01：播放器等待、重请求与下载延续观察

本报告整理 2026-11-15、2026-11-16 对 [issue #51](https://github.com/SW26010/still-wanna-dance/issues/51) 的正式播放实验。记录播放器 HTTP、世界重载、人工音画反馈和 SWD 执行成本；没有修改产品默认的 30 秒窗口。独立手动 Seek、跨媒体阈值和竞争用户延迟未测，不据本批次宣称这些问题已验证。

## 构建与记录口径

- 固定源码：`96d95141db7afbf7baaecb34601a33e339ca444d`。从提交快照构建隔离实验程序，不包含当前工作区的其他开发变更；本轮不是发行包验收。
- [构建身份](../evidence/live-20261116-01/provenance.json)列出 16 个实际 EXE 的 SHA256、七组实验差异补丁及构建参数。直接供数工具与真实 SWD 引擎分开记录；不同构建仅在各自样本范围内引用。
- 环境：Windows、本机回环受控来源；游戏日志记录 VRChat `2026.4.1p1-1937-299983b13b-Release`、世界版本 `20261115135121`。没有逐笔独立核验 Windows 和世界版本。
- 媒体：4598，35,169,662 字节，MD5 `ba52593f9a238a486df91a1bf23b9248`，时长 133.167 秒。owner 与非 owner 分组；角色切换涉及房间／会话变化。
- 各样本以首个正式播放器 GET 为 `t=0`，单位为秒，零点互相独立。服务器日志保留毫秒；人工反馈约秒级，不能据两者的小差值判定先后因果。未特别报告的音画情况按操作者约定记为“未报告异常”，不等于逐帧检查。
- HTTP 请求结束、播放器接替 GET、世界 `Retrying load`、`OnVideoStart` 和人工恢复分别记录。服务器成功 Write 不证明客户端已消费；没有以文件传完代替播放完成。

真实引擎采用两个普通下载槽、1 MiB 块、无限缓存、`growInterval=0`。默认先供完整的前 2 MiB。受阻块只返回 128 KiB 前缀后等待，尚未 EOF，不能发布完整块。“后续全阻塞”作用于前缀后的每一块；“单缺块”仅作用于第 2 块（2–3 MiB），后续块可正常读取。恢复点按首个播放器 GET 后 66 秒或 20 秒设置，不按人工起播时刻设置。

非 owner 的 fresh、clock、hole 夹具去除播放器 GET 的 `If-None-Match`、`If-Modified-Since`，保留 `Range`、`If-Range`，避免 304 无正文干扰。此行为属于实验夹具。P16 将可读前缀增至 16 MiB；其他差异见各样本及补丁。

P16 的人工可见卡顿在 t=55.015，首 GET 取消发生在其之前约 10.4 秒；取消距离最后成功 Write 为 32.570 秒。D75 对应间隔为 31.022 秒，距离人工卡顿则约 14.966 秒。这些样本区分了读取过程与可见停顿的时刻，但没有取得播放器内部定时器实现。

H30 首请求先被客户端取消，接替请求则先触发 SWD 截止。相同 30 秒窗口在两次请求中有不同的先后顺序，不能仅按窗口数值判断哪一端先结束等待。

## 未完成样本与验证边界

[sample-limitations.json](../evidence/live-20261116-01/sample-limitations.json)保留排除和限定理由：

- 首个非 owner 准备样本命中 304，没有播放器视频正文；夹具不支持的其他歌曲出现 404／加载失败，不并入窗口故障。
- 真实引擎低速夹具校准在上游 2 MiB、客户端 1 MiB 后脚本超时，未用于正式游戏样本。RATE1 是直接供数观察。
- O20 媒体观察结束后服务未及时退出，稍后触发 15 分钟看门狗；该运行没有以 PASS 退出。
- 旧进度 N10R、起始重叠 H5、提前切离 S5、不完整 D75a 以及 HO5 后段卡顿均保留，不改写为完整成功样本。
- 未测独立正式手动 Seek 的完整等待阶段、跨媒体／平台的最小有效截断阈值、竞争用户实际延迟。未直接测量恢复首帧位置；owner 回零和非 owner 跟随进度依据游戏同步事件及人工反馈，不等同逐帧位置验证。

这批数据覆盖起播等待头／正文、开播后低速／停供、请求计时与 need-by、不同窗口的 HTTP 范围及执行成本，以及两种角色的重载表现。没有据单次样本选择最优窗口，也没有把未测边界登记为本轮通过。
