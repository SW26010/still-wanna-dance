## 发现、修复与验证

1. 01 的内嵌条款仍称退出不恢复 hosts，并引用已移除的恢复按钮、旧凭据路径和旧同意按钮。按当前实现纠正，条款版本同步为 `2026-10-26.1`，CLI 示例一并更新。02 真实首次启动已展示新文本并由操作者确认。此场景没有旧版本已确认凭据，不能当作“旧条款升级后的重新确认”证据。
2. 02 的真实 UAC 取消暴露 Windows PowerShell 本地代码页乱码和脚本错误堆栈。权限启动器显式设置 UTF-8，并捕获异常只输出原因；不改变提权入口、参数、命名管道身份校验或退出策略。03 的真实取消和同意两条路径均复测通过。错误中仍可能包含系统提供的英文原因及进程退出码。

01/02 打包入口的 `go test -tags=no_easytier ./cmd/... ./internal/...`、`go vet`、嵌入页面一致性及 111 个可执行模块许可覆盖检查通过。03 的 hosts／权限助手／恢复策略／接入定向控制台回归、控制台 vet 和标准桌面构建通过；实际 UAC 复测覆盖脚本的失败与成功分支，没有用自动测试代替用户点击。

环境限制单列：首次沙箱内 CIM 读取失败，随后在普通 Windows 用户权限下只读采集成功。文件选择器辅助进程已启动，但自动化工具未枚举其窗口；由操作者确认实际出现并完成取消/选定，前后 UI 与程序状态分别核对。原生冲突窗口首次截图被前台窗口遮挡，激活实际返回的 SWD 窗口后重新核对；不将遮挡截图作为产品失败。
