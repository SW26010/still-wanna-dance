## 功能与兼容范围

相对 beta.4，当前功能包括首页与侧栏整理、程序日志查看和导出、可配置的视频块位置与存储路径校验、视频覆盖率估算、收藏保留预算修正、完整 Mihomo 配置导入及摘要、SOCKS5 服务检测、设置字段反馈、故障时打开 WebUI 和稳定版更新检查。网络诊断与共享引擎的生命周期整理保留既有业务行为。

配置仍为 v8，数据库仍为 v9。打开受支持的 v8 数据库会按现行契约迁移至 v9；升级前退出并备份，迁移后旧程序不能直接打开该库。完整配置、数据库及视频升级边界见[存储约定](../storage.md)。更新检查只提示稳定 Release，RC 从发布页手动下载。
