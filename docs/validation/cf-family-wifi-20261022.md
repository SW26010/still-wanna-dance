## 修复归因

`test_candidate_removed` 是实验工具合并多种错误后的标签，不能直接判定 IPv4/IPv6 线路断开。产品同时存在可确定的租约缺陷：60 秒旧答案在第 30 秒遇到同 IP 的 1 秒或零 TTL 刷新，会丢失原本还有效的租约；遗漏的 IP 却保留旧租约。修复前新回归在短 TTL、零 TTL、遗漏 IPv6 三例失败，长 TTL 对照通过。

修复保留旧租约与新答案到期时间的较晚者，查询缓存和下一次刷新仍按新 TTL；全都真实到期后候选照常退出。没有为首次零/短 TTL 引入兜底，没有放宽固定候选的 Host/SNI/TLS 或换址边界。实验现在记录具体错误类别、实际候选及 DNS 前后快照。旧失败没有这些记录，仍不能确定其具体根因。

构建基于 `b9d88fd` 加本次修改；具体源码、检查日志、构建指纹和原始证据保存在忽略目录 `artifacts/cf-family-wifi-20261022/`。冻结 EXE SHA256：`cc9198a7d4b358ffb1adbea2250a155b8530f7bb1eb0ea5cc1d48970bf7e05ff`。

DNS/DoH、固定候选及实验夹具定向回归通过；租约与候选诊断的 Windows `-race` 通过；console/upstreamrequest 带实验标签 `go vet` 通过；7 项统计测试通过，覆盖新旧方法拒绝混算和中断训练保留。首次新错误分类夹具误用了被静态池拒绝的域名，修正夹具目标后通过；首次 Python 直接运行受沙箱临时目录权限限制，经项目统一临时目录入口通过。失败日志保留，没有修改产品以绕过测试环境问题。

## 本次停止点已经定位

第二轮训练准备获取 IPv4 `104.26.5.28` 时，失败快照给出：

1. T+285.9823901s 进入候选获取，六个旧租约均于 T+284.2972856s 到期，已过期约 1.69 秒；没有可继续保留的旧有效租约。
2. 前台解析耗时约 243 ms，返回相同三个 IPv4、三个 IPv6，`LastError` 为空；不是地址从答案中消失或 DNS 查询报错。
3. 新缓存到期与本次观测时刻相同（T+286.225313s），六个租约也均到该时刻。即产品合并后的有效 TTL 为 **0**，固定候选池遵照现行有效期规则返回空集，实验在下载前停止。

因此，本次属于**真实租约已过期后的零 TTL 候选可用性边界**，影响两个地址族。它不是已修复的“把尚未过期的旧租约缩短”，也不是本次 Wi-Fi 绑定或媒体 TLS 失败。这里记录的是合并后 TTL，未保留本次逐提供者 DNS 报文，不能进一步归因于某个 DoH 服务、A/AAAA 或 CNAME 记录。普通直连即用解析和产品其他候选回退与本固定单 IP 实验不同，不能把整个产品的下载失败率等同于窗口停止率。

零 TTL 的候选执行语义是另一项设计议题；本实验未通过人为抬高 TTL、重新选址或重跑来绕过。原三次统一错误的历史记录没有现场证据，根因仍未知。

## 已取得的数据与结论边界

16 次训练完整加载均干净成功，512 个请求全部通过 206/长度/远端及训练逐块 SHA256 一致性复核；正文共 **525,874,832 字节，约 501.5 MiB**，训练加载累计约 134.8 秒，整窗约 232.6 秒。Monitor/API/预检另计，只有两轮前置 Monitor，正文理论上限 160 MiB。当前没有三次训练全部成功的赢家，也没有预热或正式加载，extra/auto、extra/v4、extra/v6 的正式配对数均为 0；训练耗时不代替收益证据。
