- 受影响的桌面入口、Console、缓存、网络检测、桌面和故障中心 Go 整包测试通过；后续对生命周期、退出、取消和故障中心的变更另做定向测试及 Windows race 检查。`go vet`、WebUI build/check 和桌面构建通过。
- 队列日志连续失败、恢复与再次失败，以及连通性检测的来源回退、手动请求和自动重试，另以定向测试和 race 检查覆盖；日志写入失败恢复后可重新报告。
- 针对管理响应的错误链回归先注入真实数据库写入故障：修复前，同一故障经歌曲偏好、缓存删除和曲库预览各重复触发一次；修复后还覆盖接口先报告的相反顺序、VRCX 脱敏响应、取消以及无关故障，确认同因去重且保留原响应文案。
- 隔离子进程分别加载损坏 JSON 和字段矛盾配置，使用真实嵌入资源及 Edge 验证受限 WebUI、现有状态、退出、条款真实性和原配置不变；截图及浏览器结果位于忽略目录 `artifacts/recovery-webui-20261104/final/`。
- Windows 桌面定向检查使用真实实例锁、发现记录和托盘；使用隔离 `LOCALAPPDATA`、有效的当前用户条款记录及关闭自动打开的配置，确认工作区故障仍触发浏览器打开请求。浏览器打开器为测试替身，不影响日常浏览器。
- 单独注入浏览器打开失败，确认真实 Windows 原生对话框包含启动原因和浏览器失败原因，并只关闭本次测试进程的对话框。首次测试的对话框关闭方式失败，改为点击其确认按钮后通过；原始现象保留在 `artifacts/recovery-webui-20261104/verification-history.txt`。

浏览器打开调用的真实默认浏览器可见性不由这些测试保证；测试未启动游戏或修改系统 hosts，也不需要 VRC 验收。
