# WebUI 设计

本文是 WebUI 设计的 canonical 文档，维护设计原则、页面归属、用户操作及展示语义。已实施范围及浏览器、隔离服务和性能验证见[开发验证记录](validation/webui-validation.md)；历史记录保留当时规则，现行设计以本文及下列专门约定为准。真实游戏与 Windows 原生环境验证按既有机制跟进，明确暂缓的事项仍不实现。

现有界面与交互见[内容约定](webui-content.md)，组件及可访问性继续遵循 [Fluent UI](fluent-ui-migration.md) 与[可访问性约定](webui-accessibility.md)。实施本文已确认的变化时同步修订相关现行文档，避免保留互相冲突的规则。实现采用 Fluent UI React v9 官方组件，复用现有业务机制。下载、配置和存储的业务契约由对应设计维护，本文只说明界面要求及需要同步调整的边界。

## 设计理念与原则

目标是让首次使用者一眼看出页面的主要用途、当前状态和下一步操作。以“简洁优雅、标准规范、最小必要、可维护”为取舍依据，减少理解和操作成本。

- **按任务组织内容。** 每页突出主要任务；配置、即时操作和结果各有明确归属，日常配置保持唯一编辑位置，其他页面通过摘要和链接连接。全局状态只显示一次，局部状态留在所属任务中。
- **先做内容取舍，再安排层级。** 删除重复提示、无意义容器和已失效入口，常用功能直接可见；折叠只用于真正按需查看的内容，不用层层折叠容纳所有信息。
- **优先使用标准组件。** 采用 Fluent React v9 的组件、属性、语义色和间距 token，保留原生焦点与键盘交互；容器负责布局，不覆盖组件内部结构。相同业务复用机制，只为实际重复建立必要的共享组件。
- **文案服务于判断。** 标题、状态和操作直接说清事实，不复述功能清单，不堆叠防御性解释或实现细节。说明与当前任务和上下文一致，帮助用户判断。
- **反馈真实且有唯一位置。** 按结果的时效和处理需要安排反馈，保留失败原因和可执行的下一步；未知不写成零，未确认不写成成功，不用重复提示强化同一结果。
- **布局自然，动态更新稳定。** 内容适应实际可用空间；临时状态、进度和辅助提示出现、更新或消失时，应尽量避免推动主操作及已有内容，优先复用现有状态区或标准浮层反馈。后台刷新保持阅读和操作连续，真实错误清晰可见，不为维持布局而隐藏或遮挡反馈；具体展示与验证规则见[内容与交互](webui-content.md#内容与交互)。
- **操作连续、结果可预期。** 页面切换保留草稿与进行中的操作，不暗中保存、应用或重复发起任务。确认与后果说明按具体操作约定执行；支持键盘、焦点恢复、窄屏及高对比显示。
- **重构处理完整链路。** 在授权范围内统一入口、状态、组件和业务机制，清理被替代的代码、样式、测试预期和文档规则；不在旧结构上不断增加特例。保留配置与业务契约，用适当的浏览器和自动检查验证结果，历史失败与证据仍可追溯。

具体页面排布与交互见下文[设计说明](#设计说明)。

## 各页排布与内容

本节记录各页展示的内容、排布与基本操作。控件实现和样式见 [Fluent UI 约定](fluent-ui-migration.md)，详细行为及数据规则见下文[当前界面规则](#当前界面规则)。

全局页头显示后台程序状态与“退出程序”；主导航依次为加速、历史、曲库、网络、设置、关于。

### 加速

#### 运行条件及状态

- 加速总状态；“加速未运行”显示为灰色
- 游戏连接、视频服务、房间队列状态徽章，同排依次显示
- 最近请求摘要及历史页链接

#### 交互

- 开始加速／停止加速使用同一个图标按钮：未运行时显示向右三角形，运行时显示正方形
- 悬停时显示主题色背景；悬停或键盘聚焦仅提示“开始加速”或“停止加速”

#### 视频状态

- 总下载速度、块缓存大小、唯一块状态计数及块任务／下载统计
- 常驻需求列表，展示读取、短期交接、队列和手动下载需求；各需求行标题后显示就绪百分比
- 展开时显示状态图例及「需求视图」标题／数量
- 「时间轴视图」默认收起，展开后位于需求视图上方

### 历史

#### 统计摘要

- 第一行：“响应来源”、刷新图标、下载／缓存／本地视频占比
- 第二行：“响应时间”、刷新图标、等待下载与缓存／本地两组 P50／P95
- 文字提示：来源统计口径及各类折算字节、响应时间定义、各组有效样本数

#### 时间筛选

- “开始”“结束”标签分别在固定宽度的日期时间框左侧，与“查询历史”“全部保留期”按钮同排；整组控件靠左，日期框不随页面拉伸
- 按钮与输入框底部对齐，窄屏按字段自然换行；校验错误在对应输入框下方

#### 请求列表

- 列顺序：收到时间、请求歌曲、视频资源、结果、交付、来源、详情
- 收到时间列：收到时间及结束时间
- 请求歌曲列：当前曲库名称为主、请求时歌曲 ID 为次，ID 保留曲库链接；长名称截断，完整名称在详情中查看。表头提示说明名称来源及按 ID 排序
- 视频资源列：请求时资源标识及对应曲库链接
- 结果列：七类结论（完成、请求中断、歌曲已屏蔽、等待超时、信息获取失败、处理异常、结果未知），下方直接显示 HTTP 状态，未记录时显示“HTTP 未返回”；结果文字的 Fluent Tooltip 补充原因说明及 HTTP 状态，支持悬停、键盘聚焦与 Escape
- 结果语义：`completed` → 完成；`canceled` → 请求中断（客户端取消或断开）；`blocked` → 歌曲已屏蔽；`expired` → 等待超时（仅 SWD 下载截止到期主动结束）；`playback_info_failed` → 信息获取失败（有效播放地址或必要信息最终无法取得）。`failed`／`aborted`／`incomplete` 及旧 `timeout` 统一显示处理异常，Tooltip 只说明记录中已知事实，不将其一概描述为程序缺陷。无法识别或缺失的结果显示结果未知。首页、列表和详情共用映射；HTTP 状态指 SWD → 客户端，不表示上游状态，200／206 也不能单独证明完成。技术异常细节留日志，不在提示中要求用户排查。
- 历史兼容：不改写原始结果，不按 HTTP 状态、当前歌曲偏好或耗时补推原因；旧 `timeout` 提示未记录具体超时类别。新记录的结果判定与存储边界见[存储契约](storage.md)。
- 交付列：交付比例、已写出字节及响应范围字节
- 来源列：下载／缓存／本地视频占比
- 详情：结果及其说明／HTTP 状态、已知歌曲 ID 对应的完整当前曲库名称、请求范围、处理耗时、首正文耗时与分组、完整资源标识、各类按块折算字节
- 底部分页栏：左侧显示页码、当前页条数及自动刷新状态，右侧为上一页／下一页

### 曲库

#### 概览

- 左侧依次为本地视频数量与占用、曲库覆盖率、视频存储预算；本地视频与覆盖率标题后各有刷新图标，预算标题为设置链接
- 刷新图标的文字提示包含操作名称与最后检查时间；覆盖率标题的文字提示显示已覆盖／总数及统计所用清单版本
- 概览行右侧依次为“导入视频”“下载视频”，窄屏自然换行

#### 查询与视图切换

- 左侧为“按歌曲／按资源”标签，右侧依次为“搜索曲库”“筛选”“查找”，窄屏自然换行
- 搜索框提示：名称、ID、歌手、舞者或资源
- 搜索曲库、搜索框、筛选及下拉框同行，标签位于对应控件左侧；搜索输入框固定宽度，整组控件靠右，不随页面拉伸；窄屏按字段换行，输入框可收缩以保持标签与控件同行
- 「搜索曲库」标签同行左侧另显示「共 N 首歌曲／个资源」，数字加粗，「共」与单位保持普通字重；复用底部分页栏的结果数量、单位及数字格式。只跟随成功查询更新，输入草稿不改变数量，查询格式有误时保留上次成功结果，尚无结果、读取失败或待确认存储时显示「—」。数量与搜索字段保持同行，窄屏收缩输入框，其余筛选及查找按钮沿用自然换行。
- 筛选项：全部、已保存视频、缺失视频；歌曲视图另有普通、收藏、屏蔽
- 普通文字保持原有模糊搜索；精确查询只支持 `id:2367` 与 `md5:完整资源标识`，关键字和 MD5 不区分大小写，忽略查询首尾空格。ID 使用无前导零的正整数（不超过有符号 64 位范围），MD5 使用完整 32 位十六进制；已识别关键字但值不合法时使用标准 `SearchBox`，将共用错误图标放在框内清空按钮左侧，只在有错误时占用图标宽度并保留 Tooltip，无错误时文字区延伸到清空按钮左侧，保留搜索字段的错误语义和无障碍描述，原因只在悬停／键盘聚焦图标时显示，不增加文字行。允许直接修改后重试，不退回模糊搜索，不将查询拒绝显示为存储检查失败；已有本地视频统计及上次成功查询对应的分页摘要保留，页码与单位均取自该查询，避免提示出现、更新、消失时推动控件、结果和分页。未知前缀仍作普通文字，不增加联合条件、布尔运算或别名。
- `id:` 在歌曲视图匹配指定歌曲，在资源视图匹配该歌曲当前关联的资源；`md5:` 在资源视图匹配指定资源，在歌曲视图匹配当前关联该资源的全部歌曲。无关联的歌曲在资源视图可以没有结果，资源范围沿用原有规则。
- 歌曲／资源链接（含历史入口）直接生成相应视图及字段查询，清除旧筛选并回到第一页，不再增加隐藏的对象限制、禁用另一标签或提供“返回完整曲库”。切换视图保留已提交的查询词、清除筛选、恢复默认排序并回到第一页；修改或清空查询后提交即可继续浏览。
- 已提交的查询词、视图、筛选、排序与页码同步到 URL，刷新和浏览器前进后退恢复相应查询；输入草稿不逐字写入历史。旧 `song`／`resource` 链接在进入时替换为同一字段查询 URL，不额外增加历史记录；跳转导入／下载模块不重建曲库或丢失模块草稿。
- VRCX 历史导入建议出现在列表上方，含“导入历史”“忽略”操作

#### 按歌曲

- 列顺序：ID、名称、歌手、舞者、需求分、偏好、本地状态、操作
- ID、名称、歌手及舞者分别成列；歌手与舞者列最小宽度均为 6rem，舞者列仅显示舞者，不拼接社团。名称承接剩余空间，窄屏沿用表格横向滚动。长名称和人员资料单行截断，名称、歌手、舞者及资源视图的关联歌曲可悬停或键盘聚焦查看全文，使用标准 Tooltip 并支持 Escape 关闭；详情继续提供完整资料
- 偏好列：红心收藏与屏蔽图标；未屏蔽为空心圆圈，已屏蔽为标准圆圈斜线图标，使用正文色，选中不产生底色；互斥选中，重复点击取消，都不选表示普通
- 本地状态列：单个状态徽章，按受保护、下载中、已保存／未保存的优先级显示
- 操作列：预览使用图标按钮，可用时不显示 Tooltip；下载歌曲、定位文件、删除本地视频使用带 Tooltip 的图标按钮，详情保留文字入口
- 详情：完整歌曲资料、分数来源、资源链接、最近请求

#### 按资源

- 表格上方：非默认排序时显示“恢复默认排序”；删除通过行内操作，不提供多选或批量删除入口
- 列顺序：视频资源、大小、本地状态、操作
- 视频资源列：资源标识、关联歌曲摘要及数量；大小列仅显示文件大小
- 本地状态列：与歌曲视图共用单个状态徽章及相同优先级
- 操作列：预览使用图标按钮，可用时不显示 Tooltip；下载资源、定位文件、删除本地视频使用带 Tooltip 的图标按钮，详情保留文字入口
- 关联歌曲摘要中的每首歌曲可点击，复用歌曲 ID 字段搜索链接；数量保持显示，无关联歌曲时显示普通文本。
- 详情：完整资源标识、关联歌曲及 ID 链接、最近请求

#### 分页与导入、下载

- 列表底部分页栏：左侧为总歌曲／资源数与页码，右侧为上一页／下一页
- 分页栏下依次常驻 VRCX 历史导入、视频导入、下载缺失视频模块
- 视频导入与下载模块顶部：存储预算提示及存储设置链接
- 下载模块：检查缺失视频、下载缺失视频、停止批量任务、当前进度、上次任务及结果详情

### 网络

- 同一页直接展示全部适用模块，不提供页内入口栏或视图切换；未应用的草稿不提前切换连接模式
- 仅直连显示当前连接及线路观测、手动检查
- 连通性检测与下载速度测试常驻页面顶部，宽屏并排、窄屏换行
- Mihomo 生效时，在检测卡片下方显示原版 zashboard 代理面板
- 不再展示游戏接入模块；HTTP 80／HTTPS 443 端口状态在加速页「视频服务」的悬停或键盘聚焦提示中查看，配置仍在设置的网络标签编辑

Mihomo 面板与 SWD 检测在同一页纵向排列，保留独立窗口打开。面板承载、加载与独立打开规则统一见 [Mihomo 与 zashboard](mihomo-dashboard.md#监测与界面)，Fluent 和第三方面板的样式边界见 [Fluent 约定](fluent-ui-migration.md)。

### 关于

#### 介绍/使用帮助

介绍底部不重复提供用户协议链接和软件／内容授权说明；相关信息集中在“用户协议”和“许可证与声明”中。

使用帮助按五个主题使用单列标准 Panel 卡片，标题与步骤复用 Subtitle2；不嵌套卡片或添加章节分隔线，页签与首张卡片间保留标准留白；具体内容以[帮助内容约定](webui-content.md)为准。直接展示各主题正文，顶部不重复提供“关于”“使用条款”和章节目录链接，底部不提供返回首页链接；应用内不重复显示“帮助”标题，独立帮助页保留主标题。正文中的操作入口及现有章节锚点继续保留，“视频需求”链接直接定位首页对应区域。安装步骤合并开启加速与点歌操作，发行许可和重新分发要求集中在“许可证与声明”。

#### 用户协议

标题下直接显示条款版本、纯文本入口和完整条款，不重复展示已确认状态、返回首页链接或内容授权提示。

#### 许可证/第三方声明

#### 日志

程序日志相关界面沿用「关于 → 使用帮助 → 日志与当前路径」的目录路径展示，以及「设置 → 常规」的日志级别设置。只保留路径信息和级别设置，不提供日志目录按钮、专用接口或操作反馈。VRChat 日志目录仍在「设置 → 下载与缓存」管理。

不提供日志页签、查询、筛选、分页、展开或导出，清理原 `#/logs` 入口。文件本身可人工和 AI 离线读取；格式及职责边界统一见[日志说明](logging.md)。

## 当前界面规则

### 导航、页头与运行状态

程序、WebUI 及命令行的命名统一遵循[程序与界面术语](webui-content.md#程序与界面术语)。网络页常驻连通性检测与下载速度测试，其余模块随生效上游变化；仅直连显示「当前连接」的歌曲列表、播放地址解析、视频资源加载，代理隐藏且不启用这些观测。所有上游的连通性检测由自动周期和手动入口共同触发，下载测速继续仅手动执行，测试当前生效上游，不提供上游选择、不读取草稿。连通性共用曲库补齐流程，只展示本次请求的响应和耗时；访问能力由应用组装，不在检测模块选通道、不挑最快值、不平均历史。两项检测显示最后测试时间，失败也更新时间；连通性逐行显示实际观测时间，初始化重试只更新清单行；取消恢复上次结果及对应时间，测速失败同时区分本次测试时间与保留结果时间。配置字段留在设置的网络标签；从侧栏进入网络页检测，往返保留编辑，不保存、应用或启动检测。

六个主页面共用页头与标题容器，切页时导航与正文保持对齐，不因长短页面的滚动条变化产生横向偏移。侧栏按内容自然占高，短页面不产生额外滚动范围，长页面保留正常滚动；不靠隐藏滚动条或硬编码高度补偿掩盖布局问题。标准滚动槽与响应式布局见 [Fluent 页面排版](fluent-ui-migration.md#页面排版)。

布局按实际容器宽度换行，不为假想状态设置固定宽高、绝对定位或空白占位；校验错误随文档流自然展开，不为维持坐标而隐藏或遮挡反馈。

页头只展示后台程序状态及其持久故障摘要，与“退出程序”相邻排列，按内容宽度和标准间距自然换行，不预留固定宽度。加速总状态、游戏连接、视频服务和房间队列集中在首页“加速”；房间队列状态紧接视频服务状态，沿用原有队列状态判断。块需求事件连接／自动暂停状态位于“视频需求”标题行，其他页面不重复显示“加速运行中”。后台连接成功只表示成功读取程序状态，块需求事件连接成功只表示观测流已连接，两者均不证明游戏接入或播放成功。退出或重启后停止读取状态时显示中性色的“后台程序：未连接”，不另设“正在退出或重启”状态。读取失败与待确认等具体语义遵循[程序与界面术语](webui-content.md#程序与界面术语)，持久故障的详细原因从状态处查看。

后台程序、游戏连接、视频服务、房间队列及视频需求状态展示复用同一 StatusBadge，统一使用 Fluent Badge 的尺寸、图标及语义色，并保留可见文字。前四者采用“名称：状态”格式；需求面板采用“状态展示：状态”格式，文案与含义遵循[程序与界面术语](webui-content.md#程序与界面术语)。采用官方 `tint` 外观的浅色填充与描边，避免大面积实心色过度抢占注意力；尺寸、颜色、状态播报与组件属性沿用 [Fluent 页面排版](fluent-ui-migration.md#页面排版)。

全局退出按钮统一命名为“退出程序”，点击直接提交退出，不再二次确认。按钮默认保持标准中性外观，可用时悬停使用 Fluent 危险色填充与白字，按下加深；通过 `makeStyles` 和主题 tokens 定制颜色，保留组件默认焦点、禁用及强制高对比度样式。停止服务与游戏接入处理的说明通过 Fluent Tooltip 在悬停或键盘聚焦时显示，并与当前已保存的退出策略一致。帮助、关于、条款等文档页同样保留退出操作的进度、失败、未确认及成功反馈，按实际结果展示。

### 曲库、历史与反馈

#### 共用表格与分页

曲库和历史共用 RecordTable、SortHeader 与 TablePagination，采用 Fluent 紧凑 Table，一行一首歌曲、一个资源或一次请求。保留官方组件默认行高、单元格间距、排序箭头、`aria-sort` 与键盘交互，主次文字使用 TableCellLayout。列宽由浏览器按内容自动分配（`table-layout: auto`），短字段及行内操作保持单行，歌曲／资源列承接剩余空间并限制长内容，完整信息在详情中查看；历史来源占比在同一单元格内紧凑并排，空间不足时换行。窄屏只在表格区域横向滚动，不缩小控件或截断状态文案。

表头补充说明直接使用文字上的 Fluent Tooltip，不放提示图标或为其预留列宽；悬停、键盘聚焦可查看，Escape 关闭，可排序列复用排序按钮的焦点。补充资料使用非模态 Popover，已展开的详情内直接显示短注释，不再要求二次悬停。

排序作用于符合查询条件的全体结果，再读取当前页，每页最多 50 项；不只重排当前页。曲库使用偏移量分页，历史使用游标分页。曲库、历史的分页栏左侧统一显示「第X/Y页 · 共 N 条」（如「第1/13页 · 共 601 条」），曲库按查询对象使用「首歌曲／个资源」；数量为 0 时只显示对应的「共 0 条／首歌曲／个资源」，不显示页码。总页数按当前筛选后的可浏览数量向上取整。右侧为上一页／下一页；只有一页时仍显示，禁用不可用按钮。

#### 曲库概览与操作

概览只展示本地视频占用、曲库覆盖率和当前生效的视频存储预算。本地占用按完整视频资源去重计量，包括仍受使用保护而尚未回收的视频。覆盖率常态仅显示百分比，分母为全部当前清单成员；“曲库覆盖率”文字的 Tooltip 显示已覆盖数量／总数和统计所用清单版本，未取得版本时显示“未知”。缺映射时在百分比后显示小感叹号，Tooltip 说明“资源待识别”数量及其仍计入分母、尚未计为已覆盖；尚无有效完整清单或无法检查本地视频时显示“—”并由感叹号提示原因。首次读取或更新尚无结果时不提前提示缺清单。感叹号使用 Fluent v9 small transparent 图标 Button、ErrorCircle 图标及 Tooltip，支持悬停、键盘聚焦和 Escape 关闭；正常时不显示，不增加说明行或统计详情入口。“视频存储预算”标题链接到设置的存储区域，不再单列“存储设置”链接。曲库不提供“打开视频目录”按钮，仍可从具体文件行定位文件。

概览行的两个导入／下载按钮只滚动并聚焦到列表末尾的对应常驻模块，不读取历史或启动导入／下载；列表保持显示，搜索、筛选、分页和导入草稿不变。VRCX 导入沿用已有需求统计初始化与覆盖确认流程，不导入或覆盖收藏／屏蔽标记。

视频导入与下载模块标题下常驻次要文字“本地视频：已用 X / 预算 Y”，同行提供“前往设置”链接，直接定位并聚焦视频保留选项。两个模块与顶部概览共用同一次本地占用读取，不分别请求；预算始终取当前生效配置。“不限制”和“不保留普通视频”直接替代数字预算；占用未取得、读取失败或视频目录不可用时显示“已用未知”，不以零代替。文字上的 Tooltip 说明仅计受管完整视频、同一资源只计一次、不含临时文件和数据库、不代表磁盘实际占用，并显示该数值的最后检查时间；使用中的视频可能暂时超过预算，不因此新增操作限制。

当前生效的存储预算为“不保留”时，共用占用提示沿用“不保留普通视频”，保留“前往设置”链接，不另加 MessageBar，也不显示收藏仍可保留的例外说明。提示始终使用当前生效配置，不随未生效设置变化。

#### 曲库封面视图

“按歌曲”在每次程序启动会话中默认使用封面视图，页签右侧的单个 Fluent 图标按钮切换列表／封面视图；选择与首页速度单位共用运行会话偏好机制，绑定本次程序令牌保存在浏览器中，同源标签页同步，页面导航、刷新及关闭后重开均保留，程序重启后恢复封面视图，不写入程序配置；“按资源”保持表格并隐藏切换按钮的交互，预留其原位置。切换显示方式保留搜索、筛选、排序和当前页，概览、页签与搜索栏位置不变；窄屏沿用原有自然换行。封面视图共用歌曲分页，每页最多 50 首，不改变查询或下载补齐的排序规则。

图片按 4:3 在 Fluent v9 small Card／CardPreview 中排列，CardFooter 左侧显示 ID、中间显示单行省略的歌曲名称、右侧三点 Menu。封面内部右上角由上至下排列收藏／屏蔽 ToggleButton，收藏常显；未屏蔽时的屏蔽图标仅在鼠标移入按钮区域或键盘聚焦该区域时显示，已屏蔽时常显；无悬停能力的触屏设备保持可见。两者与列表共用行为，透明外观直接叠在图片上，不加图标组底色，图标以轻微同色描边增强辨识；直接标记及状态互斥规则不变。封面悬停或键盘聚焦时显示小播放图标，不增加文字提示；不可播放时不显示该标记。点击封面在现有 LibraryPreview 弹窗中播放；菜单提供与列表相同的预览、下载、定位文件、删除及详情，按同一资源状态禁用，文件操作继续使用原有确认和结果反馈。卡片非操作区域持续悬停 500ms 后显示非模态 Popover，经过收藏、屏蔽及菜单按钮不触发；离开卡片和浮层后延迟 250ms 关闭，移入浮层可继续阅读。同一时间仅显示一首歌曲的详情，新详情替换旧详情；菜单打开的详情即时显示。搜索或分页查询切换时，取消旧卡片的悬停计时，新查询完成前禁用旧卡片详情及操作菜单；切换视图或离开页面时关闭详情。浮层背景使用当前主题表面色的 85% 不透明度，文字保持不透明；高对比度模式保留系统实色背景。详情包含名称、歌手、舞者／社团、ID、需求分与来源、偏好、本地状态、资源及最近请求；键盘和触屏可从菜单打开详情。悬停不移动焦点，菜单和弹窗沿用标准键盘操作与焦点恢复，Escape 或外部点击关闭详情；可用封面和预览操作不显示“预览视频”提示，不可用时保留具体原因说明。

仅显示封面视图时，分页请求增加 `covers=1`，后端随本页歌曲一次性返回 `covers[歌曲ID]`：`source` 为 `local` 或 `category`，已有图片仍需本次程序会话更新检查时另带 `refresh:true`。该选择复用本地 JPEG 校验，不联网，也不创建目录；列表与资源视图不检查封面。前端不再另发批量状态请求，不根据图片加载速度决定封面来源。当前页已有文件先读取，网络加载依次处理当前页缺图、下一页缺图、当前页已有图片的待完成更新检查，最大并行四路；页内读取遵循歌曲展示顺序。会话更新记录由后台统一管理，切换视图、刷新页面及多标签页不重置；本会话新下载的图片不重复检查。下一页分页或封面选择不可用时仅跳过预取，不影响当前页图片与更新检查。切页／切回列表／离开曲库／隐藏标签时取消当前请求，迟到结果不能覆盖新页。存储和网络边界统一见[封面缓存](storage.md)。

无论选定曲目图还是类别图，尚未就绪时都显示当前主题的低对比度中性底色，保持 4:3，不插入错误文字。后端确认没有可用本地曲目图时，才按完整子类别名选择内嵌类别图；实际本地读取失败时也可回退类别图，未知类别使用游戏中的通用舞者图。类别图保持 4:3：适合的官方横版直接采用，其余方图完整居中，侧边以同图预合成的模糊暗背景补齐，不在浏览器实时模糊。当前缺图下载成功后可以替换类别图，已有图片更新失败继续显示原图。类别映射、来源与处理依据见[来源核对](research/category-cover-sources-20261112.md)及[成品来源清单](research/category-cover-assets-20261112.json)。

浏览器在当前页面文档内复用曲目图片的 Blob 地址；优先保留当前页，此外保留的图片正文总计最多 8 MiB，全部条目最多 150 张，先淘汰较久未使用的非当前页条目。8 MiB 约束额外保留的编码正文，不等同于浏览器总内存；当前页最多 50 张为正在显示的工作集，解码像素由浏览器管理。下一页已有图片也提前只读并解码。分页已选定本地来源且浏览器缓存命中时，直接用于新页首次渲染，不先清空再等 effect 发布；普通 React `<img>` 在挂载和首次绘制前各检查一次自身加载结果，已就绪的图片同步显示，后续 load 事件也同步提交显示状态，避免图片已经就绪但事件尚未处理时仍隐藏一帧。绘制前检查在节点移除或候选变化时取消，不持续轮询。缓存未命中或浏览器尚未完成图片加载时继续允许中性占位。更新候选在加载成功后替换原图，不手动搬动或长期持有图片 DOM。淘汰／替换后的地址在界面更新后释放，曲库组件卸载时全部释放，不跨浏览器刷新持久化。

#### 曲库读取与刷新

首次曲库初始化期间，覆盖率数值保持原来的“—”；右侧小感叹号的 Fluent Tooltip 说明正在获取、失败原因与自动重试时间，支持悬停、键盘聚焦和 Escape。实际获取时标题后的刷新箭头沿用既有旋转和忙碌状态，退避等待时停止旋转并允许手动更新，遵循系统减少动态效果设置。初始化、等待与成功切换保持概览、预算、操作按钮和列表的位置，不增加状态文字或提示行。初始化成功后跟随既有监测完成刷新取得首次覆盖率，不要求点击更新，不新增前端轮询。已接受清单但尚无统计时提示“尚未计算覆盖率”，不误报缺少完整清单。初始化调度与本地统计边界见[曲库同步规则](song-catalog-design.md#清单同步与增改不删)。

曲库列表、本地占用和已有覆盖率结果在进入页面时读取一次，停留期间不定时刷新；查询、分页、明确操作及任务完成后按需读取。后台提交曲库实际变化时同步读取曲库和清单检查状态，正常呈现后台接受的更新，不再次发起联网扫描；重复成功检测但数据未变时不触发这次读取。页面隐藏时不读取，返回页面再获取当前结果。

“本地视频”和“曲库覆盖率”标题后分别使用 Fluent v9 small subtle 旋转箭头图标按钮，悬停及键盘聚焦提示“检查本地视频”和“更新曲库”，不保留原文字按钮。前者只读取本地列表与占用，后者复用清单更新及覆盖率统计；更新任务运行期间跟踪至完成，随后停止读取。两个按钮的 Tooltip 第二行各自显示“最后检查时间”，不在概览中常驻一行：本地视频用成功读取时间，覆盖率用实际统计时间，不用读取旧快照的时间冒充重新检查。失败保留已有检查时间并显示错误。

检查或更新期间，原 20px Fluent 刷新箭头在按钮内匀速旋转，采用 Fluent Spinner 的 1.5 秒线性循环节奏，完成后停止；系统要求减少动态效果时不旋转，仍保留 `aria-busy`、禁用状态和 Tooltip。按钮保留焦点并阻止重复提交，不替换成 Spinner，不增加“更新中／检查中”文案。已有数值留在原位，不用固定高度或空白占位维持布局；真实错误仍明确展示。

同一查询的后台读取保留已成功取得的列表、封面、展开状态和焦点，不因读取中而统一禁用行内操作、排序、查询和分页，避免控件颜色反复变灰。表格或封面列表继续标记忙碌，刷新入口保留自身反馈。首次读取、查询条件或页码切换、提交后的版本变化，须等匹配查询与版本的结果到达才能操作保留的旧条目；读取失败和实际业务禁用条件仍生效。文件删除继续核对确认前后的文件身份、歌曲关联、保护状态与存储身份，并由后端检查可用性。

分页等待期间保留旧页及其滚动位置；匹配查询和版本的新页结果提交后，在绘制前定位到曲库开头并转移焦点，避免先滚到旧页开头再替换内容。失败、停止或离开目标查询时取消这次定位意图；同一查询的后台刷新不触发定位。

批量任务运行期间每 5 秒读取下载进度，包括准备清单和视频之间暂时没有活动下载的阶段；任务停止后仍跟踪尚未结束的共享下载，直到批量任务和活动下载都结束，再停止读取。已观察到的任一下载结束时，读取曲库列表与本地占用，更新文件状态和行内操作；其他下载仍在进行也不延后这次读取，不重新发起联网扫描。进入任务或任务状态变化会立即读取，页面不可见时暂停。

视频导入复用每 5 秒的公共状态读取，发现成功导入数量变化时合并刷新曲库列表与本地占用；跳过、失败或检查进度变化不单独触发读取，整批导入结束仍刷新。顶部概览和两个模块同步呈现同一结果，不为导入或占用提示增加轮询；切页或浏览器页面隐藏时暂停本地读取，返回后取得当前结果。

已读取到曲库更新或下载仍在进行时，后续查询超时或暂时失败保留最后一次成功确定的查询间隔，继续跟踪，直到成功读取到任务结束。失败仍显示错误并保留已有结果；首次读取失败、尚未观察到活动任务时不自行启动定时查询。

#### 曲库排序与需求分

歌曲和资源默认按需求分（需求分数）降序排序；歌曲 ID、名称、需求分、资源指纹和大小通过 Fluent 表头切换升降序；ID 按数值排序，首次点击升序。歌曲按分数排序时始终将真实需求记录放在初始记录前面，未知大小始终放在最后。搜索保留当前排序，切换视图恢复默认排序，排序变化回到第一页；资源改变排序后提供“恢复默认排序”。分数显示、精度、来源分组及同值顺序统一见[内容约定](webui-content.md#内容与交互)。

需求分数随时间衰减，用于下载补齐排序和视频保留取舍；歌曲屏蔽由独立偏好决定。列表排序不改变下载补齐、视频保留的数值评分及共享资源汇总。资源纳入范围、本地状态与删除边界见[已有能力与共享资源展示](#已有能力与共享资源展示)，手动下载沿用[当前能力与暂缓范围](#手动下载与队列预加载)。

#### 历史摘要与筛选

响应来源与响应时间各自使用 Fluent Subtitle2 小标题字阶的一行摘要，标题及同行占比、分组名称、P50／P95 数值和读取／空状态文字保持相同字阶，窄屏自然换行；标题后提供与曲库同规格的刷新图标。所有补充说明通过文字上的 Tooltip 展示，支持悬停、键盘聚焦与 Escape，不放提示图标。响应来源不常驻“按块折算”或“累计”标签，各类折算字节在对应占比的提示中查看；首正文有效样本数在各组文字的提示中查看，“响应时间”标题提示为“从收到请求到首次返回视频正文的时间”。统计口径分别见[响应字节来源统计](#响应字节来源统计)与[首正文等待时间](#首正文等待时间)。

历史时间筛选使用本机时区的日期时间字段，短标签始终与各自日期框同行；日期错误通过 Field 的校验区在对应输入框下方展示，不以占位或绝对定位隐藏布局变化。默认范围、区间边界、排序、分页与事件更新统一见[历史查询范围](#历史查询范围)。

#### 预览、定位与反馈

歌曲与资源行提供播放图标按钮，可用时不显示预览 Tooltip；屏蔽或当前无资源映射的歌曲禁用，通过 Tooltip 说明原因。预览不计入历史和需求分。点击后在一个 Fluent Dialog 中使用原生 video controls，准备成功才设置媒体地址，列表不预加载视频。浏览器拒绝自动播放时提示使用原生播放按钮，准备或媒体失败在弹窗内反馈。关闭、离开曲库、通过定位链接切换内容、程序停止或存储身份变化时取消准备、暂停并清除媒体源；迟到结果不能恢复旧预览。固定资源及统计边界以[下载需求设计](download-resource-design.md#曲库预览)为准。

媒体网络错误及浏览器的“来源不支持”错误会按 1、2、4 秒间隔自动重试，最多连续 3 次；浏览器可能将响应头前的 HTTP 504 也归为“来源不支持”，因此不能据此直接断言编码错误。重试沿用同一个固定资源地址，由原生播放器重新发起 GET、取得新的请求时钟并复用运行期完整块；保留播放位置及暂停意图。恢复后播放位置前进超过 1 秒，重新取得重试次数。明确的解码错误直接反馈；连续失败耗尽重试后明确提示。关闭或切换预览时取消重试计时器，不创建额外预览会话或保活来源。

列表中的多个预览按钮共用一个受控 Dialog，按钮通过 Fluent `useRestoreFocusTarget` 接入标准焦点恢复。正常关闭后回到本次触发预览的按钮，不手写全局焦点历史或替换 Dialog 的焦点管理。

曲库的字段搜索仍可叠加普通筛选，零结果只表示当前查询没有匹配项，不能据此断言对象已经消失。与普通搜索统一显示“没有匹配项，请调整搜索或更新清单。”，可直接修改查询、筛选或切换视图继续查找。

曲库定位链接（包括 `#/library?view=resources`、`#/library?view=songs`、`#vrcx-import`、`#video-import`、`#batch`）应显示并聚焦目标。导入目录草稿、VRCX 数据库选择与预览在页内定位和切页后继续保留。普通导航与明确定位的滚动、焦点规则沿用[内容与交互](webui-content.md#内容与交互)。

短补充说明使用 Tooltip，完整帮助放在帮助页。删除仍需确认，数据校验与共享文件语义不变。

无异常的短时完成反馈使用固定角落的 Fluent Toast。曲库文件操作有跳过或失败项时，在列表前单独显示唯一的 MessageBar，按需附逐项结果表，并将焦点移到结果区；保留数量及原因供核对，离页后清除，不同时重复弹出 Toast。持续故障保留状态提示；字段校验使用 Field 自带的校验区，随内容自然展开，不预留空白或使用绝对定位维持坐标。具体交互遵循[内容约定](webui-content.md)。

后台刷新保留已有记录或空结果提示及操作位置，成功返回后再更新，不周期性替换成加载画面。曲库、设置和关于的标签关联对应内容面板，字段错误关联输入控件，遵循[可访问性约定](webui-accessibility.md#当前约定)。

### 加速、设置与帮助

首页用加速状态与直接操作作为首要区域，主按钮按网关状态显示“开始加速／停止加速”，处理期间禁用并在状态区说明进度；停止后再次开始复用既有助手和启动流程。HTTP 80／HTTPS 443 端口状态移入「视频服务」的 Tooltip，网络页不再提供游戏接入卡片或重新检测请求按钮；已有正确 SWD 映射但恢复权限尚未准备时，不阻止加速，游戏连接的黄色状态浮层直接提供蓝色“修复”，仅主动准备恢复权限，不启动网关或重置检测。其下为“视频需求”，以常驻 Canvas 需求视图替代原当前 GET、下载和房间队列表格，不再保留视频活动与队列并排布局。队列按来源及位置呈现在需求行中，日志目录在“设置 → 下载与缓存”管理。

需求面板标题行按标题、状态展示徽章、速度、缓存、块任务与下载统计、时间轴展开箭头的顺序尽量并排放置；块任务与下载统计靠右对齐，空间不足时自然换行并保持右对齐；状态图例在展开时显示，收起时隐藏图例行及“需求视图”标题／数量，需求列表继续显示与更新。时间轴默认收起，展开后在需求视图上方，“时间轴视图”标题与延续／提前窗口、分层开关尽量同排；控件在窄屏自然换行。需求行以标题后的整数百分比表示当前需求的块就绪比例，画布及行高按固定块尺寸计算，保持紧凑并保留标记和边框空间。具体布局、块状态与交互以[内容约定](webui-content.md#内容与交互)为准。

设置直接展示字段与短说明，宽屏按相关性并排。网络直接展示线路表格及并排检测卡片，不提供二级标签、页内入口栏或线路折叠；无结果时各项仅展示名称、未检测与直接操作，有结果后直接呈现表格，日期仅在有值时显示。帮助按问题直接提供步骤。保存、重新启动等操作保持稳定位置；待处理操作的通知持续到结果返回。

设置中的说明直接表达条件，不指向当前入口不存在的“下方选项”等内容。

### 已有能力与共享资源展示

除本文明确调整的行为外，沿用已有能力和契约；设置在所属页面保留唯一编辑位置，其他页面通过摘要和跳转连接。首次未同意条款时自动弹出确认，四步配置引导已移除。未逐项展开的帮助、诊断和高级字段不视为删除授权。

首次运行若发现未由 SWD 托管的本地 API hosts 映射，条款确认后在右下角以普通 Toast 提供视频导入建议，仅导航到现有导入模块；触发、关闭及不重复规则见[内容约定](webui-content.md#内容与交互)。

歌曲和资源视图分别表达歌曲资料与实际视频资源；共享资源的本地状态保持一致。本地状态徽章在受保护时只显示“受保护”，否则有活动资源任务时显示“下载中”，没有任务时按完整文件状态显示“已保存／未保存”，避免多个状态撑宽列；保护原因仍通过 Tooltip 说明。行内不再显示阶段、百分比、进度条或字节速度提示。“下载中”覆盖已有共享任务从准备到校验、保存的生命周期，不区分手动下载、播放或队列来源；任务结束后读取实际文件状态，不能仅因任务消失就视为已保存。未知大小明确显示未知，不用零值冒充已知结果；资源列表暂不展示时长。

资源列表的纳入条件是“本地存在”与“存在当前歌曲关联”二者至少满足其一：无当前关联但本地存在的资源仍可查看和管理；当前已关联歌曲的资源即使本地缺失也保留展示。两项都不满足的资源不显示；无当前关联的资源在本地删除或丢失后，也不再属于列表范围。这只是展示过滤，不删除底层资源记录，也不恢复历史歌曲关联。第一版不为列表范围外的孤立缺失资源新增下载入口。

“本地存在”仅指完整本地视频。曲库首版不展示运行期视频块缓存的细分状态，不将可读的完整块或下载中的未完成块显示为已保存的本地视频。

歌曲行和资源行的删除均指删除对应的本地视频文件，不删除歌曲资料、资源关联、偏好或统计。沿用现有删除确认与保护检查，说明共享文件会影响哪些关联歌曲，受保护文件跳过并给出原因；不另建歌曲专属的视频副本或删除机制。

请求的明确歌曲身份与资源的当前关联分开展示。只有关联信息时标明“关联歌曲”，没有可靠归属时保持未知；不凭唯一关联或多个关联中的第一首推断实际播放歌曲。现有请求记录不具备的身份信息需要由实现补充，不能通过修改展示标签获得。

历史行的请求歌曲 ID 与资源身份保存请求处理时的事实，不随之后的曲库映射变化。曲库链接用于查看当前对象，不将当前关联写回历史；对象不在当前列表范围内时仍保留历史身份，不跳转成其他资源或将当前关联冒充历史事实。

请求歌曲列按记录中的歌曲 ID 展示当前曲库名称，便于辨认请求；名称不保存为历史快照，曲库改名后重新查询显示新名称。后端在历史分页后按该 ID 关联歌曲资料，随请求结果返回，不要求当前清单成员资格、不按资源反推歌曲，也不由前端逐行查询。有 ID 但没有名称或曲库记录时显示“未知名称”并保留 ID；无 ID 时整列显示“未知”。这不改变请求身份、歌曲 ID 排序、游标或历史自动更新的触发条件。

请求结果展示统一遵循[请求列表](#请求列表)的七类结论；底层保留传输不完整和中止等已知证据供提示使用，不将原因不明的断连归为客户端取消；交付比例独立按[有效视频响应范围](#请求交付比例)计算。

### 历史查询范围

历史页支持查询请求明细保留期内实际存在的全部请求记录，不再限制为最近 500 条。默认查最近 24 小时，开始时间包含、结束时间不包含；“全部保留期”清空时间限制并重新查询。每页最多 50 条，通过游标遍历更早记录，不一次读取或渲染全部历史。

`/api/history` 的 `total` 是当前时间范围及相邻中断过滤后的全部可见 GET 数量，不受游标、每页数量或排序影响；总数与当前页在同一个数据库读取事务中取得，空结果也返回 0。分页和自动更新成功时一起更新总数与列表，不在前端累计或估算，也不改变首页最近请求接口的有限窗口读取。

默认按收到时间降序；收到时间、请求时歌曲 ID、资源指纹均可升降序排列，未知身份始终放在最后，同值按收到时间和事件 ID 同方向稳定排序。切换排序重置游标，从全体查询范围读取第一页，并保留表头键盘焦点。筛选草稿随应用内导航保留，切换存储重置游标；翻页与重新查询将焦点送到结果区域，后台更新保持请求 ID 对应的展开状态。

历史查询不改变请求明细的保留期，也不补造未记录或已清理的数据。首正文等待时间统计仍使用本文规定的最近 72 小时滚动窗口，不随历史列表的筛选或分页改变。

历史默认勾选「隐藏相邻中断请求」，位于「全部保留期」所在操作行的右侧，向右对齐；空间不足时自然换行。只保留在当前页面内存中：应用内切页保留，刷新或重新打开恢复勾选，不写配置或浏览器存储。标签悬停与复选框键盘聚焦均通过 Fluent Tooltip 说明「同一视频的前一次请求中断、后一次完成，通常是游戏播放器的正常行为。」Escape 关闭提示。

隐藏规则按仍保留的 GET 明细的收到时间、事件 ID 升序判断，不按表格当前排序配对：本条为 `canceled`，紧接着的下一条 GET 为 `completed` 且 HTTP 200／206，两者已知资源 MD5 相同、收到时间相差不超过 1000 毫秒（含边界），且已有歌曲 ID 不明确冲突时，隐藏本条。HEAD 不参与相邻判断；中间的其他 GET 会阻断配对。没有后续完成记录时仍显示中断；后续完成写入后沿用现有事件刷新重新查询。不隐藏 `failed`、`aborted`、`incomplete`，不据此确认播放成功或中断原因。

该规则在后端查询的时间筛选、排序和分页之前求值，因此跨页及筛选边界保持一致；每页最多 50 条指过滤后的可见记录。切换选项回到第一页、保留当前时间查询和排序，键盘焦点留在复选框；空结果表述为「当前筛选条件下暂无请求记录」。`/api/history` 以可选布尔参数 `hideAdjacentCanceled` 接收选择，省略时返回全部原始请求；页面明确传入当前值。此选项不删除或改写记录，不改变统计、保留期或首页最近请求摘要。

请求列表仅在按收到时间降序、第一页且未设置结束时间时自动更新：通过 `/api/history/events` 订阅当前数据库的变更，GET 明细写入或保留期清理成功提交后通知，再复用已有分页查询读取当前页；不定时轮询，不在浏览器维护另一份历史数据。事务回滚、仅需求统计写入及没有实际删除的清理不触发更新；批量提交只通知一次，正在读取时收到多次事件合并为一次后续读取。

首次订阅和断线重连均先通知读取最新结果，避免漏掉离线期间变化；切页、标签隐藏和页面离开时断开订阅，恢复可见时重新读取。订阅只观察应用已有数据库，不启动视频引擎或后台清理；数据库关闭时终止订阅。后续页、其他排序或指定结束时间保持稳定，仍可通过查询和翻页重新读取。不提供“暂停请求刷新”和“刷新本页”；连接中断提示自动重连，查询失败移除过期行、回退焦点，并通过“查询历史”重试。尚无结果时显示加载状态，后台刷新保留已有记录或空结果提示及可用的排序、翻页操作，成功后再更新。累计来源和首正文统计仍保持各自每 30 秒读取与手动刷新，不跟随列表事件。

### 设置选项与操作控件

设置选项用于配置行为；UI 中的即时操作按钮或开关用于直接启动、停止或执行动作，两者按作用区分，不按控件外观区分。不提供独立关闭操作，不代表取消相应的设置选项。设置选项需说明何时生效，不能一概要求重启。

### 一键加速与成功判定

“一键”指用户只点击一次即可发起完整流程：未配置 hosts 接入时先走接入流程，接入就绪后启用视频网关；已有正常接入和已运行的网关复用。

一键加速统一判定整体结果，对用户只有成功、失败两个最终结果，不提供部分成功结果。只有 hosts 接入正常且视频网关已正常运行、接入就绪，两项同时满足才显示成功；执行期间可展示各步骤进度，尚未就绪不提前报告成功。手动和自动加速遵循同一规则。

任一步骤失败时，自动撤销本次操作产生的接入及网关变更，恢复操作前状态；原先已有的正常接入和已运行网关不因本次失败被撤销或关闭。界面报告整体失败、失败原因及撤销后的真实状态。若撤销本身失败，仍归为整体失败，明确说明未能恢复的项目，不将其显示为部分成功或声称已恢复直连。

已取得 UAC 授权且仍可用的权限助手在本次程序进程内持续留存；加速失败或撤销接入不关闭助手，下次重试直接复用，避免重复申请 UAC。助手留存不表示接入仍然有效，也不将失败结果改为成功；程序退出时按既有生命周期清理。

开始／停止加速由首页与托盘共用同一编排。停止时关闭 HTTP 视频网关、HTTPS 透传及队列预加载；按当前生效的恢复直连选项决定是否移除本程序 hosts 映射。未随网关启用的队列保持关闭。助手持续驻留、停止不再请求 UAC，独立下载及共享引擎不受影响；恢复 hosts 失败时仍停止服务并显示真实结果。选择保留接入时明确提示继续播放前需开始加速。外部 HTTP 提供开始／停止加速、退出及重启，不另开 hosts 或队列控制入口。

### 停止加速或退出时恢复游戏直连

设置保留“停止加速或退出时恢复游戏直连”选项，默认启用。它统一配置停止加速与退出时的行为，保存本身不修改 hosts。停止后重新开始复用同一权限助手。默认情况下，正常退出恢复直连，下次启动自动加速时重新配置接入，需要 UAC 授权；用户关闭该选项后，退出保留接入。

该选项保存成功后即决定停止加速和本次退出的行为，无需先重启；未保存的草稿不改变退出行为。界面中的退出说明应与该选择一致，不能继续提示必须重启才能生效。

勾选或取消勾选该选项只修改草稿，不触发权限准备、UAC 或退出策略变更。将该选项从关闭改为开启时，仅在用户点击“保存”提交后，保存流程才一并准备当前托管接入所需的退出恢复权限；已有权限直接复用，确实缺少时才请求 UAC。授权取消或权限准备失败时，本次保存失败，同次提交的其他设置也不保存；保留草稿并说明原因，原已保存设置和本次退出策略保持不变。没有需要恢复的托管接入时，不为保存选项额外申请权限，后续接入仍按既有流程准备。

仅在权限准备及设置保存均成功后，界面显示保存成功并更新本次退出说明。退出时沿用已准备的权限，不再临时申请 UAC。权限已准备不保证后续 hosts 写入一定成功，助手故障、文件写入失败等仍按实际结果报告。

保存即用于停止加速及本次退出的行为已实现；具体生命周期见[配置生命周期](settings-lifecycle.md)及[hosts 契约](console.md#hosts)。

### 自动加速与用户协议

“启动程序时自动开启视频加速”默认关闭，启用后在程序启动时执行一次，与手动一键加速共用流程和成功判定。重新打开或刷新 WebUI 不重复触发。

执行加速前必须确认存在对当前用户协议的有效同意记录。未同意、记录无效或协议更新需要重新确认时，先进入协议确认流程，不因启用自动加速而绕过协议确认、修改 hosts 或启动视频网关。协议校验复用[现有条款确认机制](console.md#首次使用与条款确认)。

启动时机统一遵循[配置生命周期](settings-lifecycle.md)：未同意时自动弹出条款，成功确认后按启动设置执行本进程的一次自动加速；刷新和重复确认不重复执行。失败显示实际状态和原因，由用户处理后手动重试。

自动启动已扩展为完整一键加速，使用 autoAccelerate 和 queueWithGateway，不迁移旧字段；当前配置版本与生效规则统一见[配置生命周期](settings-lifecycle.md)。

### 队列预加载随视频网关启用

“设置 → 下载与缓存”提供“随视频服务启用队列预加载”配置项，默认选中，替代原“控制台启动时自动启用房间队列预加载”设置。选中时，队列预加载随视频网关启用，网关停止或因加速失败被撤销时，随之停止并撤销队列来源的需求；未选中时，启用网关不启动队列预加载。仅启动程序、打开或刷新 WebUI 不单独启动队列预加载。

该选项遵循现有配置生命周期：勾选或取消勾选只修改草稿，保存后重启应用生效，不作为运行中的即时开关。首页在视频服务状态后展示房间队列状态徽章，通过队列来源的需求行展示实际块需求，不再另列队列内容或日志读取详情。徽章沿用队列实际运行、启用意图及错误状态，具体语义见[程序与界面术语](webui-content.md#程序与界面术语)。启用配置不等于已经成功读取队列；需求为空也不能据此判断日志读取成功或失败。队列预加载异常不改变一键加速由 hosts 接入及视频网关就绪共同决定的成功判定。

### 实时视频状态的性能边界

首页复用现有块需求 SSE，展示唯一块计数、按本地可用块比例计算的粗略就绪百分比，以及共享下载的总网络速度；不再轮询 `/api/downloads` 或维护平行的活动表格。就绪比例不代表请求交付、播放进度或完整视频校验结果。速度由实际网络读取计数约每秒采样，通过同一连接的独立事件更新，不因测速重建块快照或重绘需求画布。

时间轴收起时停止其排序与绘制，需求视图继续订阅；切页、标签隐藏或整个面板离开视野时自动断开需求订阅并停止绘制，不提供手动暂停复选框。后台状态及最近请求摘要保留原有刷新机制。新增观测信息前仍须核对已有数据及采集开销，不补造进度或重复采集；采样、归零及可见性边界见[内容约定](webui-content.md#内容与交互)。

### 手动下载与队列预加载

弃用手动下载与队列预加载之间旧的暂停／恢复行为。逐歌曲、逐资源下载及全曲库补齐均不再暂停队列预加载，任务结束后也不执行恢复；各来源统一交由需求管理调控。

当前按最小必要处理手动下载：复用现有下载侧能力和状态，只提供必要的发起操作、执行状态与结果反馈，不建设统一待办集合、持续追加、统一开始／暂停或新的任务进度管理机制。歌曲及资源行使用已有活动资源任务显示“下载中”，不显示百分比或进度条，不新增任务模型。

手动入口继续共用需求管理与资源机制，按实际视频资源复用下载，不打断 GET 或队列等其他来源的共享下载。下载错误、内部重试、终止条件及普通补齐的单轮预算沿用下载侧契约，界面不另设策略。统一集合及其预算周期的疑问不阻塞当前 WebUI 实现。

手动下载成功以完整视频校验并发布为准，沿用[下载侧完成条件](download-resource-design.md#3-get-读取与急需信息)。块下载进度达到 100%、运行期块可读或 GET 交付完成，均不能单独作为“已保存”的依据。

界面只呈现实际需求和任务状态，不再提供“暂停预加载并下载”等操作或展示由旧互斥流程产生的暂停状态。需求管理的具体实现不属于 WebUI 设计范围，实施时同步[队列预加载](queue-prefetch.md)、[配置生命周期](settings-lifecycle.md)及相关运行说明。

#### 后续集合与任务进度设计（暂缓）

统一待办集合、集中进度展示及开始／暂停作为后续方向，暂不实施。此前讨论的集合细节不作为当前交付要求；后续实施前再核对必要范围，不提前增加轮次、额度或任务管理操作。

保留已讨论方向供后续设计使用：各入口共用按资源去重的集合，仅在程序进程内保留；不提供单项取消或清空。空集合首次成功添加时开始，非空集合追加时保持原运行／暂停状态。暂停撤销手动来源需求并保留目标，再次开始按资源现状提交需求，不恢复旧块执行、不额外保护缓存。成功完成的目标退出待办，完成记录可保留，后续文件缺失需要重新添加；暂停后继续不重置本轮预算，回收不恢复已消耗额度。这些方向均不改变下载侧对错误、重试和终止的职责。

后续再确定：持续追加目标的预算归属、预算耗尽后的剩余目标处理、本轮结束及新预算周期的触发条件，以及统一任务进度的统计与展示方式。当前不选择预算耗尽后移除还是保留剩余目标。

### 收藏视频保留选项

设置中的“优先保留收藏视频”默认开启，仅在“限制为／不限制”时生效。“不保留”时控件禁用并置灰，保留原勾选值；切回保留模式后恢复原选择。生效时，收藏歌曲对应的完整视频沿用收藏保留资格，在同一视频存储预算内优先保留，空间不足时仍可能被清理；收藏内部沿用现有评分及同分规则；关闭或不生效时，收藏仅作标记，对应视频按普通预算、持久化准入和淘汰规则处理。

关闭该选项不取消歌曲的收藏标记，也不直接强删视频；选项生效后由既有资源管理按普通规则取舍。开启、关闭或重新开启均不触发下载、补齐或恢复已删除的视频。该选项属于存储配置，沿用[配置生命周期](settings-lifecycle.md)，保存后重启应用生效。

该设置已实现；收藏规则见[歌曲屏蔽与收藏](download-resource-design.md#8-歌曲屏蔽与收藏)，保留资格条件已与该选项同步。

### 首正文等待时间

页面以“响应时间”为标题展示首正文等待时间，指标指从服务端收到 GET，到首次成功写出视频正文首字节的耗时，包含期间的解析、调度和读取等耗时；不表示客户端实际收到首字节或开始播放的时间。

按首字节交付前是否实际等待缺块分为两组，两组均展示中位数（P50）、P95 及各自的有效样本数：

- **等待下载（Blocking）**：交付首字节前，实际因所需视频块不可用而等待过下载。
- **缓存／本地**：交付首字节前无需等待下载，直接使用可读的视频块或完整本地视频。

P50 表示通常的等待水平；P95 表示约 95% 的有效样本等待时间不超过该值，界面提供简短说明。两组使用相同的计算口径，无有效样本时不显示为 0 毫秒；摘要与提示的展示统一见[历史摘要与筛选](#历史摘要与筛选)。

首正文等待时间统计采用最近 72 小时的滚动窗口，以服务端收到 GET 的时间判断样本是否处于窗口内，两组使用同一时间范围。该范围不随程序重启清零，也不是从本次启动起累计；不改变请求明细的既有保留期设置。仅统计窗口内实际保留且符合口径的样本，不补零或混入旧口径累计值；无有效样本时显示“—”，提示中显示样本数 0。

首正文没有采集覆盖状态，不展示“数据不足 72 小时”。最近 72 小时只表示选取样本的时间条件，保留 P50/P95、样本数和空组状态。

分类只看首字节交付前的情况；之后因缺块等待，不改变本次分类。GET 到达时块尚未就绪，但读取前已准备好且没有实际等待的，也归“缓存／本地”。不能用完整本地视频的命中／未命中直接代替这两组。

没有返回视频正文就失败或取消的请求，不记为 0，也不计入首正文等待时间统计；请求结果仍保留在历史中。首正文等待时间的分组不决定下述按块折算的响应来源统计口径。

原实现按完整本地视频命中／未命中累计部分成功 GET 的首正文耗时，不能直接作为上述分组的数据。现已调整采集、保存与窗口汇总，旧累计数据不能仅改名后混入新分组，也不能用旧的总耗时与样本数推算 P50 或 P95。旧记录缺少新口径字段时明确显示未知，不补造数据；新统计仅使用符合上述口径的样本，存储格式及旧数据处理遵循[存储契约](storage.md)。

上述“旧记录显示未知”只适用于受支持存储格式中可正常读取的记录，不构成兼容或迁移不受支持旧库的承诺，也不授权在页面读取时补建存储结构。

### 请求交付比例

交付比例沿用[GET 字节交付规则](download-resource-design.md#3-get-读取与急需信息)：分子是服务端写入成功的视频正文字节数，分母是本次实际 200／206 视频响应应交付的字节数。完整响应按整视频长度，部分响应按实际有效范围计算；不能用原始 Range 文本直接代替服务端最终采用的响应范围。该比例不表示整视频下载进度，也不证明客户端已收到、解码或播放。

已确定有效范围但未写出视频正文时可显示 0%；范围未知、无视频正文响应或不适用时显示“—”，不将错误页字节计为视频交付，也不把无法计算视为 0%。请求结果独立展示，不能仅凭比例判断取消或失败原因。

### 响应字节来源统计

> 来源总览[汇总当前保留明细](storage.md#请求统计的计算方式)，标题为“响应来源”；不保留明细时没有来源数据。单次计量、先加字节再算比例、刷新及错误反馈遵循原有机制。

历史页展示累计与逐 GET 的下载／缓存／本地视频占比，界面不附加折算口径说明。业务分类、整块计入时机、尾块及取消规则统一遵循[响应来源观测](download-resource-design.md#响应来源观测)：当前请求读取时实际等过的块算下载，直接复用运行期块算缓存，从已发布完整文件读取算本地视频。它不等同于实际交付字节或节省的上游流量。

累计摘要与文字提示的展示统一见[历史摘要与筛选](#历史摘要与筛选)。

每类占比使用该类已固化字节数／三类字节总和；累计占比先加字节再相除，不平均逐请求百分比。普通块在计入时按当时块大小折算，尾块按实际长度，修改块大小不重算历史。

来源总览属于当前数据库，汇总全部保留明细，不受列表筛选和分页影响；清理明细会减少贡献，重启从剩余明细重算。页面可见时每 30 秒读取，另提供手动刷新；读取失败保留已有累计值并显示持续错误，切换数据库清除旧值。无计入块时总览及逐行均显示“—”；缺少事实显示未知，不补造比例。逐行仅显示非零类别及占比，纯单一来源直接显示类别名；详情提供各类折算字节。交付比例保持原有精确字节口径，具体字节数通过悬停或键盘聚焦查看。
