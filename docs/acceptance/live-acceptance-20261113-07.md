# LIVE-20261113-07 黑屏加载中的手动刷新

公开事件时间均以本批次 T=0 归一化；负值表示基准之前，换算不提高原日志的时间精度，绝对时刻映射仅留本地。

## 结论

非 owner 的 11577 正式播放停顿、SWD 504、WD 自动重试后，用户单击本机刷新。日志有按钮点击，但没有紧随的 `OnUSharpVideoReload`、旧 GET 取消或新 HTTP 请求。约 18 秒后出现下一次 `Retrying load`，与先前自动重试相隔约 30 秒，不能把这次重载归因为按钮。

后续 Range 从 5 MiB 回到零，再前跳至 `bytes=16171008-29096091`。用户确认音画恢复并跟上好友。重载和同步目标约 114 秒的日志早于解除限速，实际恢复反馈晚于解除限速；不写成“解除限速触发重载”或“手动刷新必然生效”。正常播放时的按钮对照见 [LIVE-20261113-08](live-acceptance-20261113-08.md)。
