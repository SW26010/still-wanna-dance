## 评审后收尾

复现确认三个问题：数据库或视频盘离线时另选缓存目录被误报为“临时缓存目录不可用：The system cannot find the path specified”；已知缓存故障时加速流程先执行 `enable,rollback`；修复原目录后页面只提示重启，但未修改配置时重启按钮不可用。原始定向回归均先失败，修复后通过。

其他数据路径无法核验时保留当前工作区锁并延后块清理，不把该情况报告为缓存故障；所有已可解析路径仍检查重叠。路径恢复后，在任何游戏接入操作前复核并清理；未通过时保留文件。Windows 定向检查使用未分配盘符模拟数据库及视频盘离线，并用隔离目录联接验证即使另一路径离线也不能漏过重叠别名；同一测试检查当前及旧位置的延迟清理。实际子进程分别覆盖数据库盘和视频盘离线的启动。加速回归使用 hosts 替身，验证已有／没有接入时均不会触碰 hosts；浏览器回归验证修复原目录后的退出并重新打开提示。

收尾后的桌面入口、缓存引擎和 Console 三包完整 Go 回归通过，包含 C／D 双向跨卷发布；相关 Windows race 和 vet 通过。Edge 故障提示回归及真实 Console／SQLite／Edge 的选择和恢复联调通过，原生路径选择仍使用替身；`pnpm --dir webui check` 与实际桌面入口构建通过。离线盘使用未分配盘符模拟，没有物理拔插磁盘或验证真实 UAC 窗口。

没有启动 VRChat 或修改系统 hosts。路径变更及跨卷数据行为由隔离测试和浏览器覆盖，未发现必须依赖 VRC 的新验收场景；本次没有测量真实播放体验或缓存盘速度。
