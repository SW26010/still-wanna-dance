# 配置与运行生命周期

配置可以在服务或任务运行时保存。保存只校验、写入配置文件并更新已保存快照；当前 Console 的配置、网络连接、共享缓存引擎、监测策略、扫描与任务保持不变。

所有设置统一在应用重新启动后生效，包括没有任务运行时保存的设置。单独停止、启动 CDN 或任务不会应用待生效配置。

状态接口中的 `settings` 是已保存配置，`activeSettings` 是当前运行配置，`restartRequired` 是两者规范化后的差异。两份配置均不返回代理密码；密码差异仍参与待重启判断。保存请求省略密码时保留最近保存的密码，显式空串清除密码。

设置表单展示已保存配置；运行信息、缓存列表与监测展示当前配置。保存失败不会更新已保存快照；把配置改回当前值会清除待重启提示。
